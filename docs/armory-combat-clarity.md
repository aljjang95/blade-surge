# 장비와 전투 식별 개선 — 검토 후보

신규 유니크 장비 24종을 무기·방어구·반지·신발에 6종씩 추가했다. 기존 유니크 장비 보상 풀에서 획득하거나, 영웅 화면의 세트 제작에서 부위마다 세트 조각 30개로 제작할 수 있다. 기존 드랍 등급 확률과 강화 비용·확률은 그대로다.

같은 세트 2부위에서 고유 효과가 열리고, 4부위에서 그 효과가 강화된다.

| 세트 | 2부위 | 4부위 강화 |
|---|---|---|
| 정박자의 맹세 | 회피한 자리에 닻을 남겨 0.6초 후 적을 끌어온다. 재사용 4초 | 흡인 반경 3 → 4.5 |
| 잔향의 결투 | 같은 적에게 3회 명중한 뒤 회피하면 공격력 60%의 표식 피해 | 표식 피해 100% |
| 등불의 순례 | 명중 5회 후 일반 스킬을 쓰면 최대 체력 2% 회복 | 회복량 4% |
| 매의 사냥 | 거리 4 이상에서 명중하면 0.8초 둔화. 재사용 3초 | 지속 1.4초. 보스는 항상 0.4초 |
| 길쌈의 기예 | 세 번 연속 서로 다른 적에게 명중하면 궁극기 게이지 3 회복 | 회복량 6 |
| 보루의 약속 | 일반 스킬 후 3초 안에 회피하면 1초간 피해 감소 15% | 피해 감소 25% |

표식은 4초간 유지되며 대상과의 거리가 8 이내일 때 터진다. 닻은 보스를 이동시키지 않으며 한 번에 최대 12명에게 작용한다. 잔향·등불·길쌈의 축적 상태는 전투 HUD에 표시된다. 전투를 끝내면 축적과 예약 효과는 초기화된다.

장비마다 별도 아이콘과 3D 장식이 있다. 검사와 광전사는 새 무기 모델을 들고, 마법사·도적·궁수는 기존 직업 무기에 새 장식을 부착한다. 흉갑·왼팔 고리·좌우 각반은 관절을 따라 움직인다. 기존 얼굴과 머리, 직업 리그와 원본 자산은 보존한다.

영웅의 발밑에 밝은 테두리와 방향 화살표가 나타나며, 다른 물체에 가려진 신체 부분에 옅은 청록 실루엣이 표시된다. 적 밀도와 공격 판정은 그대로다. 피격으로 화면 전체가 움직이거나 확대되지 않는다.

직접 명중한 경타·강타·마무리·보스 타격의 짧은 정지와 접촉 효과를 구별한다. 직접 접촉 효과는 약 0.06초 간격으로 제한하며, 화면 전체 섬광이나 추가 조명을 만들지 않는다. 동작 줄이기에서는 새 접촉 파티클과 명중 정지를 생략한다. 소환수와 지속 피해에는 새 직접 접촉 효과를 겹치지 않는다.

현재는 로컬 검토 후보다. 880×400과 640×360의 데스크톱 Chromium 화면, 제작·장착·재실행과 반복 출격을 검사했다. 실제 모바일 기기의 성능·멀티터치·오디오 청취, 전체 층의 밸런스와 독립 검토는 별도 확인이 필요하다.
