# 게임물 내용설명서 — 블레이드 서지

- 게임물명: 블레이드 서지 (Blade Surge) · 플랫폼: PC 온라인(웹 브라우저) · 접속 주소: https://blade.tllhouse.com
- 제작·배급: 더럭셔리로드 (사업자등록번호 849-09-03410) · 희망 등급: 15세이용가(폭력성) · 언어: 한국어
- 작성일: 2026-10-31


**줄거리.** 무한의 성에 봉인된 재앙이 깨어나, 다섯 영웅(검성 아르카·광전사 드라칸·대마도사 리아·암살자 카인·바람추적자 실바)이 동행 정령 네브와 함께 20곳의 던전을 정화하며 6장으로 이어지는 이야기를 따라간다.

**조작·플레이.** 가로 화면 3D 쿼터뷰. PC는 WASD 이동, J/스페이스 공격, K/Shift 회피, 1~6 스킬. 모바일은 왼쪽 조이스틱·오른쪽 공격·회피·스킬 버튼. 던전 구역을 정화하면 보스 봉인이 풀리고, 보스를 쓰러뜨리면 장비·재료를 얻는다. 자동 전투(AUTO)를 켤 수 있다.

**성장.** 영웅 레벨·스킬 트리·초월, 장비(무기·방어구·반지·신발) 드랍·세트 효과·강화·제작. 장비를 바꾸면 영웅 외형이 바뀐다.

**전투 표현(폭력성).** 상대는 판타지 몬스터(해골 병사·늑대·정령·골렘·보스)뿐이다. 타격 시 흰·금빛 섬광, 데미지 숫자, 넉백이 나오고 쓰러진 적은 빛 입자로 사라진다(시체가 남지 않음). 신체 절단·훼손 표현은 없다. 선혈 표현은 한 곳: '흡혈' 장비 4세트를 맞춘 상태에서 피격되면 약 0.5초 동안 붉은 핏방울·파편 입자가 캐릭터 주변(반경 약 4m)으로 터진다(양식화된 3D 입자, 바닥에 남지 않음, 신체 훼손 없음).

**공포.** 어두운 던전과 해골 몬스터가 있으나 깜짝 놀래기·고어 연출은 없다.

**언어.** 게임 대사·자막에 욕설·비속어가 없다. 이용자 채팅은 금칙어(공용 9개 + 게임 36개)를 별표로 가리고, 인터넷 주소를 '[링크]'로 바꾸며, 차단·신고·도배 제한(10초 5회)을 둔다. 1:1 대화는 친구끼리만 가능하다.

**사행성(유료 확률형 아이템).** 보석(유료/무료 분리 저장, 무료 먼저 소비)으로 영웅·장비 소환을 한다. 등급별 확률·천장(영웅 80회, 장비 60회, 초보자 20회 확정)·픽업 규칙을 게임 안 '확률 정보'와 https://blade.tllhouse.com/odds.html 에 같은 설정값으로 공개한다. 획득물은 계정에 귀속되며 이용자 간 거래·현금 환전·경품 교환 기능이 없다.

**선정성·약물·범죄.** 해당 없음(갑옷·로브 의상, 회복 물약은 판타지 소품).

**가격(유료일 경우).** 결정서를 받기 전에는 판매하지 않는다. 판매 예정 후보: 스타터 팩·월정액 카드·시즌 패스·광고 제거. 금액은 판매 시작 전 확정해 내용수정신고 대상이면 신고한다.
