## 원인 확인 (마법사 t2·t3 회색 피부, 야만전사 t2 어두운 얼굴)
- 셋 다 Tripo 출력이 금속·거칠기 텍스처(metallicRoughnessTexture, 금속도 계수 기본 1)를 갖지만, 게임 마감(0.22 상한)과 금속도 0 강제 렌더를 나란히 찍으면 얼굴이 같다(`work/mat/metal_compare.png`). 금속 마감은 원인이 아니다.
- 원인은 기본색 텍스처 자체: 마법사 t2·t3는 얼굴 피부가 회백색으로 구워졌고(1단계는 살구색), 야만전사 t2는 붉은 전투 문양이 얼굴 대부분을 덮고 어두운 갈색 톤이다.
- 조치: 재질 수치로는 못 고친다. 궁수 v5 경로(컨셉 원화 → Tripo Studio 재생성 → `blender_swap_body.py` + `swap-library-body.mjs`)로 다시 만들거나, 임시로 얼굴 UV 영역만 색 보정하는 텍스처 패치를 검토한다. 우선순위는 궁수 t1 → 궁수 t3 → 마법사 t2·t3 → 궁수 t2 → 야만전사 t2.
