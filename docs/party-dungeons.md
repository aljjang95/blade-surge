# 시나리오 던전과 협동 원정

캠페인은 6장, 60개 스테이지다. 장례길·쌍화구·서고·환초·심판정·합류 수로의 여섯 구조를 사건에 맞춰 배치한다. 기존 5-10 결말은 유지하며 완료한 저장에서는 6-1 귀환로가 열린다.

일반 구간 각인 보상은 자동 적용한다. 직접 고르는 체크포인트는 원정당 최대 두 번이며, 닫아 둔 각인 선택은 8초의 활성 전투 시간이 지나면 기본 선택으로 적용된다. 각인 보상 여섯 번은 유지된다. 기록 선택은 이후 각인 메뉴에서 확인할 수 있다.

로비의 **파티**에서 영웅을 고르고 파티를 만든 뒤 친구에게 초대 링크를 전달한다. 2~4명이 준비하면 방장이 출격한다. 방장이 던전을 바꾸면 모두에게 같은 선택이 표시되고 준비가 해제된다. 파티원은 미니맵의 하늘색 점으로 표시된다.

성역·빙결 폭풍의 마법진, 번개, 참격, 폭발과 기둥 등 주요 전투 연출을 동료 화면에서도 볼 수 있다. 방장이 실제로 그린 위치·색상·크기·수명을 전달하며 손님은 시각 효과만 재생한다. 모든 개별 입자와 카메라 연출을 복제하지는 않는다. 모션 감소 설정에서는 회전 없는 지면 표식을 유지하고 번개·폭발·이동 참격을 생략한다.

협동 원정은 Lv.20과 해당 던전 능력치로 보정한다. 에너지와 개인 물약을 소비하지 않으며 캠페인 진도, 개인 장비, 경험치와 재화 보상은 지급하지 않는다. 쓰러진 동료는 생존자가 있으면 5초 뒤 합류하며 전원 쓰러지면 실패한다. 방장 또는 파티원의 연결이 끊기면 원정을 종료한다. 결과 화면에서 새 파티로 다시 시작할 수 있다.

## 운영 구조

한 방장 브라우저가 적, 피해, 방 개방, 보스와 승리를 시뮬레이션한다. 나머지 브라우저는 입력을 보내고 공통 스냅샷을 표시한다. Cloudflare Durable Object가 초대, 인원, 역할, 준비, 실행 ID, 메시지 형태·크기·빈도와 종료를 검증한다. 피해 수치 자체를 서버가 계산하는 경쟁 게임용 권위 서버는 아니다. 방장 교체와 진행 중 참가를 지원하지 않는다.

방은 최대 45분 유지된다. 방장 티켓은 초대 링크에 포함되지 않는다. `/api/party`는 같은 origin의 요청만 허용한다. 공개 방 목록이나 사람에게 메시지를 발송하는 기능은 없다. 지역 기믹과 보스 광역기는 방장에서 모든 생존 파티원에게 판정하고, 최대 48개 경고를 재사용하는 풀로 손님 화면에도 표시한다.

시각 효과는 허용된 10개 렌더링 연산의 숫자·벡터·로컬 텍스처 이름만 받는다. 스냅샷당 최대 24개, 손님 렌더링 가중치 48, 수명 최대 8초로 제한하며 지면 표식용 여유를 남긴다. 이미 만료된 이벤트는 재생하지 않는다. 구버전 캐시 클라이언트가 접속하면 서버가 새 `visuals` 필드만 제외해 기존 전투 스냅샷을 전달한다. 퇴장 시 캡처를 해제하고 기존 FX 정리 경로로 자원을 반환한다.

## 로컬 검증

```sh
bun run check
node tools/party-relay-proof.mjs
node node_modules/wrangler/bin/wrangler.js dev --local --port 5198 --var APP_ORIGIN:http://127.0.0.1:5198
```

`check`가 만든 정적 빌드를 두 브라우저 탭에서 연다. WebSocket 증명 스크립트는 실제 local workerd와 SQLite Durable Object를 실행하고 종료 시 정리한다. 원격 배포는 기존 `bun run deploy`의 D1 잠금·조상성·rollback 검증을 따른다.
