# 종락 회랑 심층 — 종문 역순 공명

심층 종락 회랑(`bellfall_crypt` / `deep`)의 방 2·3·5에 종문 3개를 둔다. 일반(standard)의 순차 종문 3개와 이어 읽되 규칙이 다르다. 이 문서는 BUNDLE-04의 제품 계약이며, 수치의 근거와 측정 방법, 그리고 보물방 공명 2곳을 종문으로 바꾼 사실을 함께 적는다.

## 제품 계약

- 종문 방의 적을 모두 처치하면 그 종이 켜진다(점등, 금색). 순서는 자유다. 방은 아직 정화되지 않는다.
- 세 종이 모두 켜지면 1초 뒤부터 1.4초 간격으로 하나씩 꺼진다(소등): **2번 종문 · 북동쪽 종탑 → 3번 종문 · 남쪽 납골실 → 1번 종문 · 북쪽 예배실**. 종마다 소등 음높이가 달라 소리로도 순서를 들을 수 있다. 마지막 소등 1초 뒤 공명 단계가 된다(전체 4.8초).
- 공명 단계에서는 마지막에 꺼진 종부터 거꾸로(1번 → 3번 → 2번) 각 종 중심 반경 3 안에 2초 머물러 공명한다. 다른 종으로 옮기면 유지는 처음부터 다시 쌓인다. 2초 유지라서 복도를 지나며 종 원을 스치는 것(최대 약 1.1초)으로는 오답이 나지 않는다.
- 틀린 종에서 2초를 채우면 **불협**: 최대 체력 6% 기준의 마법 피해(방어력으로 줄어든다), 공명한 종이 모두 다시 켜지고 소등을 처음부터 다시 들려준다. 불협 2회부터는 목표창이 다음 종을 알려준다(guide).
- 3/3 공명 순간에만 세 방이 정답 순서로 정화되고 방 보상이 방마다 한 번 나온다. 그 순간 방에 적이 남아 거부되면 적이 정리된 첫 프레임에 다시 한 번 정화한다. 모든 구역 정화 뒤 봉인이 풀린다.
- 결과 화면 한 줄: `종문 역순 공명 n/3 · 불협 k회`(승리·완료일 때만 ` · 완료`).
- 일시정지 중에는 소등 시계와 유지가 멈추고(유지는 0으로 돌아간다), 재개하면 같은 시각부터 이어진다. 사망·포기·보스 처치·전투 종료면 판정을 멈추며, 패배를 완료로 보고하지 않는다.
- 범위 밖: 보스의 "마지막 울림 직후에만 반격"(보스 피격 조건). 보스 `glass_hour_sovereign`의 패턴·시그니처는 그대로다.

### 공명 2곳을 종문으로 교체

기존 심층 종락 회랑은 보물방 2·5에서 순서 자유 2초 공명을 했다. 이 묶음은 그 두 방과 방 3을 종문 방으로 쓴다. `mechanics.attunement` 데이터는 바꾸지 않고, 컨트롤러가 `allowsAttunement(room) → false`, `coexistsAttunement → false`로 공명을 명시적으로 끈다(혜성 심층과 같은 방식). 정예방 4·7의 증원 1회, 에너지 6, 해금 1-10·탐험 Lv.2, 보스 HP 20500과 패턴, 보상·첫 보상은 그대로다. 종문 방에는 `objectiveProp = 'bellfall-bell'`을 붙여 보물 상자 소품이 종 중심과 겹치지 않게 했다. 보상 드랍은 유지된다.

### 정답 비노출

정답 순서는 AUTO 이동(`autoRoom`)과 불협 2회 뒤의 guide로만 밖에 나간다. 목표창은 소등 중에 방금 꺼진 종 이름만 보이고, 공명 단계에서는 guide 전까지 종 이름도 방 번호(roomId)도 보이지 않는다. 월드의 세 종은 guide 전까지 같은 색이다. 전술 문구의 종문 번호는 위치 안내 순서(1·2·3번)일 뿐이다. 소등 순서는 고정이라 반복 플레이에서는 기억할 필요가 줄어든다(다음 단계 후보).

## 화면 표시 (BellfallDeepBellView)

종마다 바닥 링(반경 = 판정 반경 3)과 공중 종 조형(높이 약 3.4, 코드 생성 LatheGeometry), 그리고 유지 진행 호 하나(유지 중인 종으로 옮겨 `setDrawRange`로 줄인다). 링과 종은 각각 InstancedMesh 3인스턴스라 draw call은 최대 3이다.

| 상태 | 색 |
|---|---|
| locked(적 대기) | 흐린 회청 0x5f6f80 |
| lit(점등) | 금색 0xffd060 |
| dark(소등) | 어두운 남색 0x1c2a5c |
| resonated(공명) | 청록 0x88dfc3 |
| 불협 직후 0.6초 | 보라 0xb06cff |
| guide | 링만 흰색 맥동(reduced면 고정 밝기) |

소등·공명 순간 종이 1.2초 흔들린다(reduced면 없음). 미발견 방의 종은 크기 0으로 숨기고, 목표가 닫히면 그룹을 숨긴다. geometry·material은 생성자에서만 만들고 update는 할당하지 않는다. 바닥 표식 renderOrder는 링 10.2, 호 10.5(BUNDLE-02 관례).

목표창(`battle-objective-view.js`의 `reverse-bells` 분기): 점등 `종문 점등 n/3`, 소등 `소등 순서 기억 k/3 · <방금 꺼진 종> 소등`, 공명 `종문 역순 공명 n/3 · 마지막에 꺼진 종부터 중심 2초`(guide면 `다음 <종> · 중심 2초`), 완료 뒤에는 기존 봉인 안내.

## 수치 근거

- 유지 2초·반경 3은 일반판 종문과 같은 학습 길이다. 복도 통과는 반경 3 원의 최대 현 6을 5.6~7.2 u/s로 0.83~1.07초라 2초에 닿지 않는다. 실제 `autoExplore` 단위 시험과 브라우저 AUTO 완주에서 불협 0이었다.
- 소등 간격 1.4초는 기존 예고 길이(유성·냉각 1.4초)와 같다.
- 불협 6%는 기존 저자 피해 비율(0.05~0.08) 안이며, 다른 경로 목표처럼 `hurt`에 최대 체력 × 비율을 넘기고 방어 경감(최대 60%)이 적용된다. QA의 레벨 50 기사 fixture에서는 실제 감소가 최대 체력의 약 2.7%였다.

## 측정 방법

도구는 `tools/bellfall-deep-qa.mjs`(판정 함수 `tools/bellfall-deep-checks.mjs`, 기준선 비교 `tools/bellfall-deep-compare.mjs`)다. 공유 `tools/expedition-qa-runtime.mjs`를 수정 없이 쓰며 빌드하지 않는다.

```
node tools/bellfall-deep-qa.mjs --expected-sha=<40hex> --out=/new/absolute/dir --profile=auto --seed=20261015 --hero=knight
node tools/bellfall-deep-qa.mjs --project=<기준선 워크트리> --expected-sha=<기준선 sha> --out=... --profile=auto
node tools/bellfall-deep-compare.mjs --candidate=<후보 report.json> --baseline=<기준선 report.json>
```

- 프로필: `auto`(AUTO 완주·불협 0·결과 줄·새로고침 보존), `discord`(AUTO로 공명 단계까지 간 뒤 AUTO를 끄고 Playwright 키보드로 오답 종에 2초 머문다. 1회째 불협 판정과 목표창 비노출, 2회째 뒤 종 원 밖으로 걸어 나와 guide 문구 확인, AUTO로 완주·불협 2회), `pause`(소등 중·유지 중 일시정지), `refresh`(공명 단계 새로고침: pending 취소·에너지 1회 환급), `screens`(점등·소등·유지·불협·결과를 640×360, 844×390, 390×844 PNG).
- 판정: 단계 전이 허용표(wake→toll→answer→done, 불협은 answer→toll), 소등 순서·간격(±1/60초), 공명 역순, 세 방은 done 전에 정화되지 않음, 봉인 해제는 done 뒤, 결과 객체·결과 줄. 불협 피해는 `max(1, round(maxHp × 0.06 × (1 − min(0.6, def/(def+250)))))`과 정확히 같아야 하고, 다른 경감(가드·성역·아이기스·물약 방어)이 켜져 있으면 합격하지 않는다.
- 기준선 비교: 완주 시간 비 ≤ 2, 종 방 2·3·5 첫 진입 draw call은 기준선 같은 방 첫 진입 대비 +12 이하, 첫 소등 프레임은 같은 후보 실행의 그 방 첫 진입 대비 +12 이하(짝 없는 표본은 실패). 50ms 초과 스텝은 전체와 종문 구간(소등·공명 단계)으로 나눠 센다.
- fixture(저장 주입·Lv.50 영웅·시드)·실제 UI·입력·제어 실행(고정 1/60초 `app.step`) 구분은 report.json의 `classification`에 남는다.

## 보스 합창 장막 — 마지막 울림 직후에만 반격 (BUNDLE-05)

개인 기본 원정 종락 심층의 보스(멈춘 합창의 주권자, `glass_hour_sovereign`)에만 붙는다. 일반 종락·공명목 수목원·유리 정원 심층·캠페인·파티·균열·전술 공략의 같은 보스는 바뀌지 않는다(종문 컨트롤러가 만들어지는 조건과 같다).

- 정의: `ROUTE_OBJECTIVES.bellfall_deep.counter = { signature: 'bell_toll', window: 3.5, veil: .5, open: 1.5 }`. 컨트롤러 `src/game/bellfall-deep-counter.js`(종문 컨트롤러가 만들고 `route.counter`로 내보냄), 뷰 `src/game/bellfall-deep-counter-view.js`.
- 장막(veiled): 보스가 등장 연출을 마치면 장막이 덮인다. 보스가 받는 피해는 0.5배다(Enemy.hurt의 방어·잠행 감쇄 뒤, 독 피해 포함).
- 조종 보호: 장막이 덮인 동안 삼중 조종은 그 조종으로 창이 열릴 때까지 기절·경직·브레이크로 끊기지 않는다(`guards`: Enemy.hurt, Enemy.update의 직접 기절 쓰기, postureHit). 실제 AUTO 기사가 조종을 모두 끊어 창이 한 번도 열리지 않던 진단 결과(smoke-counter-1: 조종 4회 모두 끊김)로 넣었다. boss-signatures 계약의 "기절이 대기 중 피해를 취소한다"는 이 보스의 장막 동안 삼중 조종에는 적용되지 않는다.
- 반격 창(open): BossSignatures가 세 번째 고리를 실제로 터뜨리며 `completedAttackSequence`를 쓴 다음 컨트롤러 갱신(Battle 순서상 1프레임 뒤)에 열린다. 3.5초 동안 1.5배 피해를 받고, 보스의 공격 대기를 창 남은 시간 이상으로 붙잡아 새 공격을 시작하지 않는다. 창 중에는 기절이 그대로 들어간다. 같은 조종으로 두 번 열지 않는다. 일시정지 중에는 창 시계가 멈춘다. 보스 처치·전투 종료·stop이면 ended로 장막을 푼다.
