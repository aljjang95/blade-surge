# 마법사 지팡이·머리 장식 교정 시도

기준 제품 소스는 `801ecff7ca21aec6a32b7ee6a57dd5dc91a5274d`다. 기존 `combat-mesh-qa.mjs`의 측정·117개 동작·3cm 판정을 수정하지 않는다.

## 보조 측정의 범위

`tools/mage-head-overlap-qa.mjs`는 머리·목에 지배적으로 묶인 스킨 정점과 긴 뒷머리가 묶인 상체 뒤쪽 정점으로 별도 볼록 껍질을 만든다. 후자는 원본 바인드 좌표 `y >= 0.72, z < -0.10`인 척추·어깨·골반 지배 정점이다. 팔·손·하체는 제외한다. 머리 정점의 75분위 절단과 Idle 깊이 차감을 하지 않는다. 지팡이 원본 정점·삼각형 중심·1cm 이하 간격의 변 표본을 검사한다. 가장 가까운 껍질 면까지의 안쪽 거리를 cm로 기록한다.

이는 **장식 외피에 대한 보수적인 깊이 상한**이다. 모자와 머리 사이의 빈 곳과 망토 일부도 포함하므로 실제 표면까지의 정확한 거리로 읽으면 안 된다. 이를 통과해도 모든 지팡이 삼각형 내부의 연속 교차가 없음을 수학적으로 증명하지는 않는다. 기존 피부 감사와 별도이며, 고정 대표 프레임·전체 프레임·세 시점 캡처를 함께 제출한다. 1.5cm 수용 기준은 완화하지 않는다.

원래 지적된 대표 프레임 일부가 이 순차 재생에서는 0cm다. 이를 양수로 꾸미거나 프레임을 바꾸지 않고, 지정 프레임의 값과 동작 전체 최악값을 따로 기록한다. 8개 동작 모두 동작 전체에서는 1.5cm 초과가 재현됐다.

## 시도 기록

1. 머리·목 지배 정점만 사용한 첫 측정은 회피의 긴 뒷머리를 누락했다. 실제 메시의 지배 뼈별 좌표 범위를 읽어, 척추·어깨에 묶인 뒷머리도 포함하는 보수적 상체 뒤쪽 외피로 보완했다. 이 **완성된 같은 측정법으로 전후를 비교**한다. 첫 측정의 숫자는 최종 기준선으로 사용하지 않는다.
2. 원본 자세 스냅샷에서 관절당 40도 안의 일정 보정부터 탐색했다. 머리 외피만 최적화한 후보는 환호 약0.82cm·회피 약0.50cm·사격 약0.40cm를 얻었으나, 실제 재생에서 환호 첫 프레임3.39cm와 긴 시전2.19cm가 남았다. 기존 마법사 메시 감사에도 결함6건(환호 팔→몸통1, 사격 계열 무기→팔·다리5)이 생겼다. **채택하지 않는다.**
3. 원본 액션의 실제 가중치·교차 페이드, 기존 피부 측정과 머리 외피를 함께 최적화한다. 초기 표본의 통과로 끝내지 않고 모든 원본 프레임에서 새 위반을 찾아 다음 탐색에 넣는다. 환호는 네 차례 탐색을 거쳐 원본 자세 계산상 외피 최대0.685cm·피부 결함0 표본을 얻었다. 이 계산은 최종 게임 재생 합격을 대신하지 않는다.

수정 전후 실행과 탐색 중에는 제품 `src`를 동시에 수정하지 않는다. 각 탐색·감사가 끝난 다음 보정 데이터를 적용하고 같은 검사를 다시 실행한다. 실제 결과와 미확인 항목은 `mage-overlap-result.md`에 기록한다.
