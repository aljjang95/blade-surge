# 여우 외형·던전 외벽 계약

이번 교정은 avatar_ranger_fox와 기존 셀 기반 던전 외벽에 한정한다. 궁수/도적 2·3단계 및 까마귀 외형의 기존 접지 차이는 후속 아트 작업이다. 전체 게임 출시 품질·실제 Android·발열 완료로 확대하지 않는다.

여우는 원본 normalized GLB/manifest를 보존하고 검증된 별도 공개 GLB를 source SHA가 맞을 때만 선택한다. Blender 5.2.2에서 하체 높이와 팔·손 외피를 기본 골격에 국소 피팅했다. 원본 얼굴·머리·가슴 POSITION, 본 rest/역바인드·무기 소켓·UV/텍스처/재질을 보존한다. 원본과 달리 좌우가 섞인 순수 다리의 1,182개 가중치만 국소 정규화했고 발/발가락 가중치는 유지한다. 명시한 POSITION/NORMAL/WEIGHTS 바깥 BIN은 같다. 편집 blend와 GLB explicit normal은 동일 shading이라고 가정하지 않으며 실제 게임 화면을 별도 검수한다.

큰 귀와 뒷머리·발은 기본 체형의 공유 회피·사망 자세와 맞지 않았다. 기본 궁수 v4는 그대로 두고 여우에게만 Blender 저작 Hips 수직 track 두 개를 연결한다. 회피는 원래 도약 곡선과 6mm 출발·착지 곡선, 사망은 고정 artist 접촉 키를 사용한다. 게임 매 프레임 스킨 최소값으로 보정하지 않는다. 다른 9개 클립·수평 이동·전투 시간/판정/회피/Actor.pos·경제·저장·소켓은 유지한다. 몸체 교체는 이후 클립 조회만 갱신하고 현재 액션·추가 별칭을 건드리지 않으며 해제하면 기본 참조로 돌아간다.

`test/fox-body-contact.test.ts`는 실제 로더의 11동작을 301 균등 표본·모든 키·기존 실패 시점에서 잰다. 외피 최소 -1cm, Idle/사격 지지발 절대 2cm, 사망 마지막 접촉 절대 2cm를 강제한다. `test/hero-body-motion.test.ts`는 생성/교체/원복·인스턴스 분리·원본 트랙/SHA·잘못된 메타데이터를 검증한다. 수치 통과는 미술·미디어·실기기 승인을 대신하지 않는다.

외벽은 4m 표시 격자 대신 실제 1m 셀의 현재/봉인 해제 후 이동 영역 합집합 경계 바깥에 놓는다. GLB 실제 치수·bottom center를 사용하고 높이/두께/공유 geometry를 유지한다. 좁은 1m 홈에서는 두꺼운 변형 대신 원본 일반벽을 선택하고 남는 폭으로 양쪽 여유를 제한한다. 원래 PRNG 소비를 유지해 장식과 게임 난수를 바꾸지 않는다. gameplay mask/inner/resolve/unseal 결과·시선 셰이더·concept/field 전용 경로는 유지한다. 회귀는 네 방향·실제 garden19/crypt182·봉인 해제·원본 치수·자원 소유권을 포함한다. 실제 96맵/33,015인스턴스의 부피 감사는 고정 기준3030b0c world와 초기/해제 후 상태를 대조했다.
