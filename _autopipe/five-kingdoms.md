# Blade Surge — 다섯 왕의 마지막 약속

2026-09-07 현재 로컬 구현 및 검증 기록.

## 적용 기준

- 대표님 요청: 로비 카메라 조작, 5개 지역 × 10개 관문(1-1~5-10), 수문장·중간 보스·최종 보스와 연결된 시나리오.
- 아트 출처: 대표님이 선택한 `TLL 3D MODEL Blender MCP` 작업 `01a077e6-82ca-7421-8d7e-6428c40abec5`.
- 선택된 원화 5장과 무한의 성 키아트 1장을 출처 파일과 SHA256을 대조한 뒤 복사했다. 영수증: `campaign-original-portraits-receipt.json`, `campaign-loading-receipt.json`.
- 이 작업에서 먼저 생성한 10개 콘셉트는 기각되었다. 저장소 public 자산과 런타임에서 제외했으며, 상위 작업 폴더의 rejected-concept-20260907에 기록용으로 보존한다.
- 원화 기반 3D GLB·리깅·애니메이션은 별도 작업에서 제작 중이다. 이 브랜치의 전투 모델은 기존 자산이며, 2D 원화 연결을 3D 완성으로 해석하지 않는다.

## 구현

- 로비: 드래그 회전, 휠 확대·축소, 방향키, +/- 키, 기본·정면·측면·후면 프리셋, 높이·거리 슬라이더, 초기화. 설정 저장과 전투 카메라 분리.
- 캠페인: 모든 50개 관문에 고유 이름·출격 장면·진실·클리어 대사·목표·보상. 3/7 수문장, 5 중간 보스, 10 지역 최종 보스. 미리보기는 허용하되 출격은 이전 관문 클리어로 제한한다.
- 정원·용광로·서리 도서관·심해·왕관: 서로 다른 방 그래프, 공간 비례, 지역 건축과 바닥 문양, 고정 시드 변형. 모든 관문의 봉인 전 일반 방 접근과 봉인 해제 후 보스 접근을 검사한다.
- 전장 기믹: 동심원 파동 / 교차 화염 띠 / 위치 기록 후 지연 폭발·감속 / 순차 조류·밀침 / 중앙 안전지대가 있는 십자 심판.
- 보스: 지역별 4등급, 20개 전투 정의. 기존 6개 공격 동사를 지역·등급·페이즈 순서로 조합한다. 예고 방향 유지, 돌진 준비 시간, 큰 맵에서 투사체 유지, 소환 상한과 종료 처리를 보강했다.
- 결과와 저장: 클리어 장면만 모험 기록 공개, 5-10 엔딩과 다음 관문 종료, 중복 보상 방지. 기존 3-10 클리어 저장은 4-1로 이어진다.
- 이야기: 자정마다 어제가 사라지는 세계에서 다섯 맹세를 회복한다. 마지막에는 네브 한 사람의 희생 대신 모두가 기억을 나누어 순환을 끝낸다. 상세 설명은 `docs/campaign.md`와 `src/data/campaign-story.js`.

## 검증

- 타입 검사, 172개 테스트 / 7,207개 assertion, Vite 빌드 통과. 환경의 Bun 1.3.13은 저장소 bun.lock v2를 읽지 못하여 의존성은 npm ci --ignore-scripts로 설치했고 잠금 파일을 변경하지 않았다. 테스트는 Bun으로 실행했다.
- 실제 IAB 입력: 로비 프리셋·드래그·키보드 조작 후 저장값 일치, 새로고침 후 복원, 전투 카메라 설정 독립.
- 실제 게임 루프: 일반 1-1 클리어. 다섯 지역은 공격력·HP를 명시적으로 조정한 QA fixture와 고정 dt로 탐험→봉인 해제→보스→승리→결과를 검증했다. 자연 성장 50연속 관문 밸런스 검증은 아니다.
- 다섯 대표 관문 1-10, 2-5, 3-10, 4-5, 5-10 승리와 지역 위험 구역 발동을 확인했다. 5-10은 엔딩 공개, 다음 관문 버튼 없음, 결과 재표시로 추가 보상 없음.
- 화면 크기 1280×720, 740×360에서 지역 선택·잠금 미리보기·스크롤 출격 버튼을 확인했다. 이는 실제 모바일 기기 성능 검증이 아니다.
- 실행 증거는 상위 `../evidence` 폴더에 보존한다. 지역별 JSON, 실제 화면, 테스트 출력과 최종 QA 요약을 포함한다. 개인 로컬 저장 백업은 Git에 넣지 않는다.
