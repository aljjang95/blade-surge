# 전투 설계 · 기예 패치

현재 Three.js / React Three Fiber / WebGL2 / Bun 1.4 게임과 KayKit 캐릭터 정체성을 유지한다. Unity Editor 프로젝트로 전환하지 않았으며, Unity 웹 최적화 및 delta-time 피드백 스킬의 적용 가능한 원칙을 독립 구현했다. 기존 Blender 실바, 착용 방어구, 던전 맵, Flow BGM/SFX/영상은 유지한다.

## 플레이 변화

- 보스·정예가 실제 강공격을 마친 회복 구간에 직접 마무리를 맞히면 균형 피해 +15. 동일 공격 시퀀스에는 한 번만 인정한다. 취소된 공격·경고 중·이미 붕괴 중에는 인정하지 않는다.
- 출격 시 고정하는 무료 기예 3종. 붕괴 중 첫 직접 마무리에서 한 번 발동한다. 파열은 반경 5의 다른 적 최대 2명에게 공격력 60% 피해와 밀치기 4, 수호는 최대 체력 12% 보호막 5초, 순환은 남은 시간이 가장 긴 일반 스킬 하나의 대기시간 -2초다. 궁극기·각성은 제외하며 AI 결투장은 공통 규칙을 유지한다.
- 로비의 전투 설계에서 영웅별 3개 구성을 저장한다. 실제 장비 4부위 UID, 전직, 전투 방식, 서약, 기예를 함께 복원한다. 다른 영웅의 장비를 가져오면 미리 표시하고 기존 소유자에게서 해제한다. 장비 복제·대체 지급이 없고 현재 강화 상태를 따른다. 사라진 장비나 잠긴 직업은 전체 적용을 거절한다.
- 기존 설정에 배경음악·효과음·목소리 음량을 분리 저장한다. 저장 실패 시 이전 상태로 되돌린다. 효과음 샘플 16개·짧은 음성 4개·나레이션 1개 제한, 중요한 UI/강타 우선순위, 종료 노드 정리, 중복 음성 로드 합치기, 최신 음성 의도 우선, 겹친 음악 감쇠와 장면 크로스페이드 수명 관리를 추가했다. 기존 합성 오실레이터까지 이 샘플 제한에 포함된다고 주장하지 않는다.
- 비배속 delta-time으로 음악 강도를 완만하게 변화시킨다. 일시정지 중 음량은 낮아지고 재개 시 복구되며 피치는 바꾸지 않는다. 전직한 영웅이 전투에서 레벨업해도 직업 능력치 정의를 유지한다.

## 공식 설계 참고

IAB에서 공식 원문을 확인했다. 아래는 설계 원칙의 참고이며 이름·에셋·고유 밸런스를 복사하지 않았다. 모든 게임의 장점이나 상업적 성과를 검증했다는 뜻은 아니다.

- [Supergiant, Hades Blood Price Update](https://www.supergiantgames.com/blog/hades-dive-into-the-blood-price-update/): 무기 양상과 각인 조합이 전투 선택을 바꾸고 이야기·음향·성능을 함께 개선하는 방식. 기존 각인/조합 위에 선택한 기예의 실제 행동 차이와 저장 구성을 더했다.
- [Blizzard, Burn Through the Darkening Decades](https://news.blizzard.com/en-gb/article/24295393/burn-through-the-darkening-decades): 기본 공격과 스킬 행동을 변형하는 Legendary Affixes, 균열 규칙과 보스 조합. 단순 능력치 상승을 넘어 명중 조건별 행동이 달라지는 무료 기예를 독립 설계했다.
- 이전 원정·성장 참고와 구현은 `RPG_MASTERWORKS_PATCH.md`, `MOBILE_RPG_JOURNEY_PATCH.md`에 기록했다.

## 검증 범위

순수 규칙 및 실제 Battle 호출 경로, 저장 원자성/장비 소유권, 설정 유효성, native dialog를 모사한 이벤트 테스트와 별도 IAB 실제 UI/전투를 구분한다. 실제 스마트폰 발열·배터리·장시간 안정성, Unity Editor 빌드, 온라인 PvP 동기화는 이번 증거에 포함되지 않는다. 상세 검사 로그와 브라우저 캡처는 작업의 `outputs/apex-combat-craft`에 보관한다.
