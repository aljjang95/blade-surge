# 심층 원정 이후의 전술 공략

각 지역의 심층 원정을 한 번 클리어하면 첫 전술 공략이 열립니다. 첫 공략의 정복 표식을 획득하면 같은 지역의 두 번째 공략이 열립니다. 던전 화면의 **전술 공략** 탭에서 조건·해금 이유·최초 보상을 확인하고 출격할 수 있습니다.

| 지역 | 공략 | 실제 판정 |
| --- | --- | --- |
| 유리정원 | 첫 종의 방향 | A → B 제단에서 각각 2초 공명 후 보스 처치 |
| 유리정원 | 마지막 종의 메아리 | B → A 제단에서 각각 2초 공명 후 보스 처치 |
| 잿불금고 | 끊어진 신호 | 두 화물칸의 표식 신호수를 각각 가장 먼저 처치 |
| 잿불금고 | 운반책의 행선지 | 두 화물칸의 호위 4명 이후 표식 운반책을 마지막에 처치 |
| 별빛서고 | 명령의 균열 | 보스 균형 붕괴 2회 이후 처치 |
| 별빛서고 | 돌아오는 이름 | 보스 균형 붕괴 중 플레이어의 직접 공격 3회 명중 이후 처치 |

A/B 제단은 미니맵에 표시됩니다. 첫 공명 제단에 따라 수호자의 공격 순서가 강타·회전 또는 소환·낙하로 바뀝니다. 화물칸에서 올바른 처치 순서를 지키면 그 방의 기존 증원 1회가 취소됩니다. 실패하면 유한한 기존 증원이 유지됩니다. 제단 순서를 놓쳐도 방·포탈·보스 처치는 계속 진행됩니다.

AUTO는 공략의 제단 순서를 따라가며, 처치 순서가 결정되기 전에는 가까이 접근해 기본 공격으로 표식/호위를 공략합니다. 수동 조작의 스킬·콤보·투사체 충돌·다른 적의 피해 판정은 그대로입니다. 광역 공격이나 동행의 처치 때문에 조건을 놓칠 수 있으며, 모든 플레이 결과를 성공으로 보정하지 않습니다. 일반 원정과 보스전의 자동 스킬 사용은 유지됩니다.

기존 심층 원정과 같은 에너지 6과 기본 보상을 사용합니다. 승리와 전술 달성은 별도로 판정합니다. 최초 달성에만 카탈로그의 골드·지역 재료와 정복 표식 하나를 저장하며, 재도전에서는 기본 보상만 지급합니다. 전투 실패는 보상을 지급하지 않고, 준비 실패·미완료 재로드의 에너지 복구는 기존 정책을 따릅니다. 소모 에너지·적의 HP/공격력·숙련 비용을 올리지 않았습니다.

전술 결과는 출격별 메모리 티켓과 실제 전투 이벤트를 연결한 불변 결과로 정산합니다. 복제한 UI 결과, 다른 출격의 결과, 중복 정산은 거절합니다. 저장 실패 시 표식·보상을 되돌리고 같은 출격 결과로 재시도합니다. 이는 단일 브라우저의 흐름 무결성으로, 서버 부정행위 방지 기능은 아닙니다.

검증은 `bun run check`, `tools/conquest-qa.mjs`로 수행합니다. 런타임은 이전에 실제 획득한 무료 법사 프로필의 해시와 상위 보고서를 확인한 뒤 격리 저장소에 복원합니다. 일반 UI 출격 버튼, 실제 AUTO, 기존 선택 창의 첫 선택, 1/60초 시뮬레이션을 사용하며 체력·피해·좌표·처치·표식·승리를 주입하지 않습니다. 정상 가격의 보유 무료 보석으로 에너지를 충전한 경우 기록합니다. 재로드의 표식/재료 불변, 3개 로컬 엔진의 세로/가로 화면, 버튼 접근성, 결과를 가리는 전리품 알림 제거도 확인합니다.

미디어 취소는 원본 네트워크 실패를 보존합니다. 정상 Range 응답, 실제 재생 시간, 같은 URL의 모든 이전 인스턴스 정지·연결 해제, 후속 다른 곡 재생이 확인된 경우만 종료된 미디어 요청으로 분류합니다. 재생 중 취소, 불명확한 인스턴스, HTTP 오류와 미디어 오류는 실패입니다. GC 원인 또는 스피커 출력으로 단정하지 않습니다.

6개 전술 공략은 후반부의 유한한 후속 목표입니다. 1년 콘텐츠·유지율, 수동 전투 밸런스, 모든 물리 기기의 성능·발열, 실제 모바일 OS 설치, 실네트워크 파티 클리어를 증명하지 않습니다. PWA/Neve 수정은 이전 릴리즈에서 이어집니다.
