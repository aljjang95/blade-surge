# 선택형 출격 로비와 던전 포털

2026-10-07 사용자 방향: 마을은 선택적 체험 공간이고 실제 플레이는 콘텐츠 선택 UI에서 시작한다. 기존 물리 입구 필수 동선은 이 계약으로 대체한다. 특정 타 게임의 화면을 복제하지 않고 빠른 선택·준비·출격 패턴을 Blade Surge의 기존 콘텐츠와 연결한다.

홈은 캠페인·12개 던전·결투장과 보급·성장·장비·공방을 제공한다. 던전 카드는 기존 CitadelHubUI 출격 준비를 열며 기본/심층, 해금·에너지, 영웅, 물약, 서약, 목표·기록을 유지한다. 보기·취소는 소비하지 않고 출격만 기존 startExpedition/ticket/저장/환급/정산 서비스를 호출한다. 미해금 던전도 조건을 읽을 수 있으며 출격은 기존 판정으로 막는다.

‘마을 둘러보기’에서만 이동·카메라 조작을 켠다. ‘출격 메뉴로’, 다른 탭, 전투 귀환·재실행은 선택 화면으로 복귀한다. 키·포인터를 정리하고 실제 클릭한 카드/버튼으로 초점을 돌려준다. 카메라 사용자 저장은 유지한다.

보급 상점은 기존 게임 골드로 물약을 1개씩 구매한다. 효과·사용 키·보유량·가격·구매 후 잔액을 표시한다. 별도 상품 상점 링크는 기존 보석 교환/상품 UI로 연결한다. 실제 결제 비활성과 기존 상품 판정, 구매 저장 실패·중복 정산 경계는 유지한다.

12개 던전 게이트는 공유 Three.js 셰이더를 사용하는 비고형 에너지 포털을 갖는다. 기존 테마 외곽·입장 좌표·물리 통로와 감속 모션을 보존한다. 참고 이미지 `docs/media/selection-20261007/dungeon-portal-reference.png`는 이 세션의 image_gen으로 자체 생성한 4×3 미술 기준이다. 원본 `/workspace/generated_images/exec-e6cae6a4-874b-481e-8f79-ba3dd88286c2.png`; 생성 프롬프트는 12개 테마(정원·금고·별빛·종·수문·천문·히드라·잿불·뼈·동록·사막·혜성), 에너지 내부와 공간 깊이, 고형 문이 없는 통과형 포털, 중립 3/4 제작 시점이다. 게임 스크린샷/구현 품질 증거가 아니며 배경 성·생물을 새 게임 에셋으로 채택하지 않는다.

Studio의 ‘UX 개선’은 관측 → 근거 → 다음 한 가지 수정 → 실제 입력 재검수 → 다음 프롬프트를 위한 개발 도구다. 4개 템플릿을 복사/TXT로 전달하고 작성 내용은 탭 메모리에 남는다. 외부 AI 호출·서버 쓰기·자동 PASS·자동 코드 수정·가격 변경·배포 기능은 없다.
