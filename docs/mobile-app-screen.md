# 모바일 앱 화면과 네브 대화

브라우저로 접속한 이용자가 시작 화면에서 바로 앱 설치 안내를 열거나, 지원되는 브라우저에서 한 번 눌러 전체 화면으로 전환할 수 있다. 로비의 `앱 설치`와 전투의 일시 정지 메뉴에서도 같은 화면 설정을 연다. 자동으로 전체 화면을 요청하거나 게임을 다시 불러오지 않는다.

설치된 앱은 `fullscreen`을 요청하고 `standalone`으로 대체할 수 있다. 앱 ID, 시작 주소와 scope는 `/`로 유지한다. 일반 탭의 주소창은 CSS로 없앨 수 없으므로 홈 화면의 BladeSurge 아이콘으로 실행해야 한다. iPhone 안내에는 Safari 공유 → 홈 화면에 추가 → 표시되는 경우 `웹 앱으로 열기` 켜기를 포함한다. 온라인 플레이 및 기존 서비스 워커 업데이트의 전투 보호는 유지한다.

네브 버튼은 로비 메뉴와 전투 일시 정지 메뉴 안에 배치한다. 활성 전투 위에 별도 버튼이나 대화 패널을 띄워 두지 않는다. 사용자가 연 대화는 모달이며, 닫기와 입력을 화면 안에 고정하고 가운데 내용만 스크롤한다. 최신 대화가 스크롤 영역에 들어오고 Tab/Shift+Tab은 대화 안에서 순환한다. 닫기 또는 Escape는 원래 버튼으로 포커스를 돌려준다. 전투 일시 정지에서 연 대화를 닫아도 `계속`을 누르기 전까지 전투는 멈춘 상태다.

기존 667×375 화면에서는 네브 입력 폼 하단이 화면 밖 382px까지 내려가 잘렸다. 개선 검사는 Chromium/Firefox/WebKit의 로비 320×568, 390×844, 667×375와 네브의 추가 390×400 축소 화면을 포함한다. 실제 버튼 탭, 전체 화면 API, 모달 포커스, 수호 전술 응답 스크롤과 전투 일시 정지 복귀를 검사한다. 로컬 엔진/축소 viewport는 실제 휴대폰 키보드, OS 설치와 성능 인증을 대신하지 않는다. `tools/app-screen-qa.mjs`로 결과 및 화면을 남긴다.

모바일 로비의 준비 중인 상점 홍보 카드는 접고, 시점 조작 버튼을 우측 위로 옮겨 영웅 이름과 메뉴를 가리지 않게 했다. 상품 안내는 상점에서 확인할 수 있다. 시점 패널도 열고 닫으며 화면 안에 들어오는지 검사한다.
