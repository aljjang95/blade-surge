# GCRB 신청 화면별 입력값 (에이전트 대행용)

전제: 대표님이 클라우드 데스크톱에서 GCRB 로그인·실명확인·휴대폰 인증을 끝낸 뒤 에이전트가 입력한다. **약관 동의·결제(입금)·최종 [신청완료]는 에이전트가 누르지 않는다**(대표님 확인 후). 화면 문구가 다르면 '뜻'으로 맞춘다. 상세 근거는 [../GCRB_APPLICATION.md](../GCRB_APPLICATION.md).

## 0. 사전: 중소기업 감면 확인 (메뉴 [중소기업환급신청])
| 항목 | 입력 |
|---|---|
| 업체 | 더럭셔리로드 / 사업자등록번호 849-09-03410 |
| 서류 | 상시고용인수 확인서류 1부, 매출액 확인서류 1부 — **대표님이 파일 제공** |

## 1. 신청서
| 칸 | 입력 |
|---|---|
| 담당자 이름·실명확인·휴대폰·이메일 | **대표님 본인 인증**(에이전트 입력 금지, 이메일은 대표님 지정) |
| 원작정보 | 없음(비워 둠) |
| 게임명 | 블레이드 서지 |
| 배급자 | 더럭셔리로드 |
| 개발연도 | 2026 |
| 플랫폼 | PC(온라인) — 웹 선택지가 따로 있으면 그것, 없으면 PC/온라인 |
| 장르 | 롤플레잉(RPG) |
| 희망등급 | 15세이용가 |

## 5. 수수료정산
플랫폼 PC/온라인, 이용형태(네트워크 — 대전 없음 선택지가 있으면 비대전), 장르 1군, 한글 → 화면 금액을 대표님께 보고(예상 72만 또는 108만 원, 감면 후). **입금은 대표님.** 입금자명 입력·입금증 업로드는 대표님 확인 후.

## 6. 신청완료
