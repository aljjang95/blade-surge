## 1. 결론 한 줄

**15세이용가로 신청한다(내용정보: 폭력성).** 12세가 나올 여지는 있으나(혈흔은 장비 세트 발동 때만 나오는 0.5초 붉은 핏방울 입자), 판타지 무기 전투가 주 내용이고 붉은 '피의 폭발' 연출이 있어 15세가 국내 동종작의 기본값이다. 15세로 신청하면 반려·재심의 위험이 가장 낮고, 웹(게임위)과 Play(IARC) 결과를 같은 답으로 맞추기 쉽다.

- 왜 청소년이용불가가 아닌가: 사람형 대상 잔혹 묘사·신체 훼손·사실적 출혈이 없다. 이용자 간 현금 거래·환전·경품이 없다(사행성 청불 사유 없음).
- 왜 전체·12세를 노리지 않는가: 12세를 노리려면 `blood_burst` 연출을 빼고 재심의 위험을 감수해야 하는데, 얻는 이득(13~14세 이용자)보다 일정 위험이 크다. 대안은 4장.

> **2026-10-30 실측 차이:** Play IARC 설문(같은 사실·보수적 답)의 한국 결과는 **12세**(ESRB E10+, PEGI 12)다. IARC는 문항 답으로 등급이 정해지므로 15세를 고를 수 없다. 웹(게임위) 신청은 15세를 유지하고, 앱 표기는 높은 쪽(15세) 원칙에 따른다. 상세는 [STORE_RATINGS.md](STORE_RATINGS.md).

## 6. 지금 운영 중인 웹의 위험과 조치

- 법 제32조는 등급분류를 받지 않은 게임물의 **유통·이용 제공**을 금지한다. 제21조 면제는 '영리 목적이 아닌 게임물', '개발 과정 시험용(확인증 필요)' 등이다.
- 현재 웹은 **결제가 꺼져 있다**(`IAP_ENABLED=false`, `WEB_BILLING_ENABLED` 꺼짐, BM_HANDOFF #7·#12). 유료 판매가 없으므로 위험은 낮지만, 광고·가격 노출·확률 소환 유료화가 붙는 순간 영리 제공이 명확해진다.
- **조치(게이트로 고정):** 등급분류 결정서(등급분류번호)를 받기 전에는 웹 결제·Play 프로덕션 결제·가격 공개를 열지 않는다(RELEASE_CHECKLIST G1). 공개 마케팅도 결정서 뒤.
- 결정서를 받으면 `src/data/game-rating.js`의 `status:'rated'`, `age`, `number`, `date`, `descriptors`를 결정서 그대로 고치고 `index.html #boot-rating` 문구를 같게 맞춘다(테스트가 둘을 대조).

### 8-1. 웹 수수료 (GCRB 공식 조견표 [GCRB 심의수수료](https://www.gcrb.or.kr/Institution/EtcForm01.aspx), 표시금액에 부가세 10% 포함, 산식 기초가액×이용형태×장르×한글화)

### 8-2. 원스토어 자체등급으로 직접 운영 웹까지 커버되는가
| 사실 | 수준 | 출처 |
|---|---|---|
| 지정 자체등급분류사업자(구글·원스토어 등)는 청소년이용불가·아케이드를 뺀 게임물을 자체 분류할 수 있다(법 21조의2 3항: 중개계약을 맺고 서비스하는 게임물 / 자기 제작 게임물) | 조문 요약 | [법 제21조의2](https://www.law.go.kr/LSW//lsSideInfoP.do?lsiSeq=265811&joNo=0021&joBrNo=00&docCls=jo&urlMode=lsScJoRltInfoR) |
| 자체등급분류 결과는 게임위 등급분류를 받은 것으로 본다(21조의4) → 법 21조 1항의 '유통 전 등급분류' 의무는 충족 | 2차 | [CaseNote 제21조의4](https://casenote.kr/%EB%B2%95%EB%A0%B9/%EA%B2%8C%EC%9E%84%EC%82%B0%EC%97%85%EC%A7%84%ED%9D%A5%EC%97%90_%EA%B4%80%ED%95%9C_%EB%B2%95%EB%A5%A0/%EC%A0%9C21%EC%A1%B0%EC%9D%984) |
| 한 사업자가 분류한 게임물을 **다른 자체등급분류사업자**가 유통하려면 새로 분류. **사업자가 아닌 자**가 유통하는 경우 게임위에 **통보**, 중개계약 사업자도 그 사실을 통보. 서로 다른 사업자 결과가 갈리면 청소년 기준 연령과 차이가 적은 쪽 표시 | 2차(검색 요약) | 같은 조문, [앱인토스 안내](https://toss.im/apps-in-toss/blog/game_rating_classification) |
| 게임위 관계자: 자체등급 받은 게임을 다른 플랫폼에서 유통하려면 게임위에 통보해야 하고 토스 유통 게임도 모니터링 대상 | 언론 | [비즈워치 2026-10](https://news.bizwatch.co.kr/article/mobile/2026/10/06/0036) |
| 내용 수정이 등급 변경이 필요 없는 정도면 효력 유지. 중개계약 종료 뒤 사업자 아닌 자로 유통하면서 내용을 수정하면 신고, 게임위가 새 게임물로 보고 재분류 | 2차 | 위와 같음 |

**판단.** 법 문구 구조상 원스토어 자체등급은 '게임위 등급분류로 간주'되므로, 같은 게임을 직접 운영 웹에서 서비스할 때 **새 등급분류 신청까지는 요구되지 않을 가능성이 높고 게임위(및 중개 사업자)에 대한 '유통 통보'가 필요할 가능성이 높다.** 단 확정 못 하는 점이 셋이다: ① 직접 서비스하는 사업자(우리)가 '중개계약' 없이 유통하는 경우를 21조의2 3항 문언이 그대로 덮는지(이것이 2016년 8월 이전 해석과 달리 열려 있는 쟁점) ② 통보 주체·방식·기한(시행령/시행규칙 원문 미열람) ③ 원스토어 등급 취득에는 **앱 입점 심사가 선행**해야 한다는 점(원스토어 등급은 앱 단위라 웹은 그 앱과 같은 게임물·같은 내용이어야 함). 

**위험도 판단: 중(中).** 근거 — 앞의 ① 때문에 게임위·GCRB가 '웹 직접 서비스는 별도 분류 대상'으로 볼 여지가 남고, 지금 이 경로는 사례 증거(직접 운영 웹이 자체등급만으로 서비스된 공개 사례)를 못 찾았다. 반대로 틀렸을 때 법 32조(미등급 유통 금지) 위반이므로 **결제·가격 공개 전에는 반드시 담당 기관 답을 받아 두는 것이 안전하다.** 추천 순서: ① 원스토어 입점·자체등급 취득 ② 게임위/GCRB 질의(서면 답변): "원스토어 자체등급분류를 받은 동일 게임물을 사업자가 직접 운영하는 웹에서 서비스할 때 별도 신청 없이 통보만으로 가능한가, 통보 방법은?" ③ 답이 '신청 필요'면 8-1의 감면 후 16만~108만 원으로 GCRB 신청(이 패키지 그대로 사용). 어느 쪽이든 웹 결제 게이트(G1)는 등급 근거(자체등급 간주 또는 GCRB 결정서)가 확정된 뒤에만 연다.

## 9. 대표님 결정 (2026-10-31): 원스토어 IARC 결과로 웹 등급 표기 — 카롬 마스터 선례

> "카롬 마스터처럼 원스토어에서 등급 받은 뒤 그걸 웹에서 써서 진행." GCRB 직접 신청·서면 질의는 **보류**한다(8장 ②③은 이 경로가 막힐 때의 후퇴선).

- **선례:** `aljjang95/carom-master`의 `public/legal/game-info.html`은 "원스토어 IARC 대한민국 결과 · 전체이용가 · IARC 인증 ID 7b6a5e95-… · 발급일 2026-09-08"을 적고, "GRAC 직접 심사 번호는 별도로 기재하지 않으며 IARC 인증 ID는 GRAC 직접 심사 번호가 아니다"를 명시한다. 이 저장소도 같은 구조로 간다.
- **구현:** `src/data/game-rating.js`의 `WEB_ONESTORE_IARC`(age·certId·date·descriptors) 한 곳만 채우면 웹 등급이 `rated`가 되고 `ratingReady`=true(웹 결제 게이트 `webRatingReady` 통과), 첫 화면 우측 상단 문구(`원스토어 IARC 인증 ID …`), 설정 화면, `public/game-info.html`(`node tools/gen-game-info-page.mjs`로 재생성)이 같이 바뀐다. 비어 있으면 지금처럼 '신청 준비 중'이고 게이트는 닫혀 있다. 표기는 항상 'IARC 인증 ID'이고 '등급분류번호'(GRAC)라고 부르지 않는다.
- **위험도: 중(中).** 8-2의 ①(중개계약 없이 직접 운영하는 웹을 21조의2 3항이 덮는지)이 법 문언상 확정되지 않았고 직접 운영 웹이 자체등급만으로 서비스된 공개 사례를 못 찾았다. 반대 근거는 카롬 마스터가 같은 방식으로 정식 유통 정보를 공개 중이라는 점(담당 기관의 이의 제기 여부는 확인 못 함). 틀렸을 때의 최악은 법 32조(미등급 유통) 지적이므로 **웹 결제 플래그(`WEB_BILLING_ENABLED`·포트원 채널 키)는 이 변경에서 건드리지 않고**, IARC 인증 ID가 들어간 뒤 열기 전에 대표님이 최종 판단한다. 원스토어 입점 심사가 앱 단위라 웹과 같은 게임물·같은 내용이어야 한다는 8-2 ③은 그대로다.
- **값이 오면 할 일(한 줄 수정):** 원스토어 ONEconsole에서 IARC 설문 결과(한국 연령·인증 ID·발급일·내용정보)를 받아 `WEB_ONESTORE_IARC`에 적고, `index.html #boot-rating`의 정적 문구는 비어 있는 상태 그대로(JS가 부팅 때 덮어씀), `node tools/gen-game-info-page.mjs` 실행 → `bun run check`. 앱 등급 표기는 4장 원칙대로 높은 쪽(15세)을 쓰되 웹 표시는 IARC 결과 그대로다.
