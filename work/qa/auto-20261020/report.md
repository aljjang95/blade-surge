# 레인 A AUTO 런타임 검증·수정 결과

AUTO 런타임 27개는 전부 무사망으로 클리어했고 경로·전술 목표와 정산도 성공했다. 타입 검사와 빌드도 통과했다. 전체 테스트는 인계 시점부터 있던 실패 8개가 남아 있으므로 요청의 전체 테스트 통과 조건은 미충족이다.

검증 제품 소스: `5bcbd459d6f673c19fc6447f3b94157ee1927582`. 브랜치: `codex/20261019-lane-combat`. 작업은 지정된 레인 워크트리에서만 수행했다. 이후 커밋은 QA 도구·영수증이며 제품 코드 차이가 없음을 확인했다. 푸시·머지·배포는 실행하지 않았다.

## 변경 파일과 원인

- `src/game/player.js`: AUTO 이동 목표와 실제 공격 조준을 맞추고, 보스·정예를 지원하는 치유사를 방패병 밀집 무리보다 먼저 처리한다. 군중 밀침으로 가까운 치유사가 바뀌어도 유효한 표적을 마무리한다. 준비된 궁극기를 회복 무리에도 사용하며, 실제 평타 취소 창에서 치유사 대응 스킬을 사용할 수 있게 했다. 기존 MP·쿨다운·미습득 스킬 제한과 순서형 공략의 정밀 공격 제한을 유지했다.
- `test/auto-healer-aim.test.ts`: 실제 Player·Enemy 기반 회귀 테스트 6개. 조준 전환, 치유사 자체가 무리 중심인 경우, 방패병 밀집 무리, 궁극기 판단, 표적 유지, 실제 평타 취소 창을 검사한다. 각 결함의 수정 전 실패를 확인한 뒤 수정 후 통과했다.
- `tools/auto-clear-qa.mjs`: 기존 하네스를 재사용하고 각 시나리오를 새 저장으로 격리했다. 시드·초기 저장·빌드 SHA·산출물과 하네스 해시·사망·원정 영수증·실제 결과 화면을 기록한다. 30초 서명 정체는 의심으로 기록하고 같은 최대 프레임까지 실행한다. React 원정 결과 화면을 일반 결과 화면으로 잘못 검사하던 오탐을 고쳤다.
- `tools/auto-clear-diagnostic.mjs`: 단기 계측 전용. 실제 메서드를 감싸 스킬 시전과 대상별 피해를 관찰했다. 27개 비교에는 사용하지 않았다.
- `tools/auto-clear-summary.mjs`: 27개 완결, 시드·초기 저장·하네스·시간 상한 일치를 확인한 뒤 성공 평균과 공통 성공 평균을 분리 집계한다.
- `work/qa/auto-20261020/`: 원본 JSON, 실패별 원인·수정·같은 시나리오 재실행, 비교표와 검사 결과를 보존했다.

조준 보정만으로는 충분하지 않았다. `71ce528`의 393.9초 단기 계측에서 보스 누적 피해는 732,937이었지만 회복으로 체력은 550,000이었다. 마지막 표본은 MP·궁극기 모두 100, 모든 쿨다운 0이었고 궁극기 시전은 전체에서 1회였다. 평타 연계 중 AUTO의 스킬 선택이 열리지 않는 원인을 확인했고, 스킬 취소 창 수정 뒤 두 보스전이 모두 무사망으로 통과했다. 실패했던 중간 수정은 덮어쓰지 않고 `defects.json`의 `runtimeAttempts`와 각 원본 보고서에 보존했다.

## 확인한 사실과 남은 위험

확인한 사실: Windows의 Chromium·SwiftShader, 844×390 터치 뷰포트에서 실제 컴파일 게임의 `app.step(1/60, false)`를 가속 실행했다. 각 시나리오는 새 저장·기사 Lv45·장비 미착용·동일 파생 시드로 시작했고 입장 제한만 해제했다. 위치·피해·적 체력·처치·승리·보상은 주입하지 않았다. 기준 실행의 부활은 실제 `revivePlayer` 경로로 기록했으며 최종 27개에는 부활 호출이 없었다. 장비가 없어 자동 부활 세트 효과도 없다. 대표 결과 캡처도 직접 열어 정산 저장 완료와 결과 표시를 확인했다.

기준 스냅샷은 `git archive`로 추출했다. 런타임 소스·공개 자산·빌드 입력 1622개를 원본 Git blob과 대조했고 326개 텍스트의 CRLF만 정규화해 일치를 확인했다. 상위 Git 루트를 읽는 빌드 버전 도구의 제약 때문에 스냅샷의 `version.json`은 이 검증된 기준 SHA와 검증 내역으로 보정했다. 이는 로컬 비교용 빌드이며 배포 영수증이 아니다.

이번 픽스처에서는 과거 ‘멈춤 3건’이 재현되지 않았다. 과거 저장·성장 상태까지 같은 재실행은 아니므로 그 3건 각각을 오탐이라고 확정하지 않는다. 다른 영웅·다른 시드·자연 성장·실시간 프레임 성능·물리 Android/GPU/발열·공개 서버는 검증하지 않았다.

남은 실패는 오디오 6개(배송 MP3 피크 1, 이전 강조음 기대 4, 레이어 피크 합 1)와 성장 계약 2개다. 성장 테스트 2개는 레벨만 오른 미습득 스킬의 장착 성공을 기대하지만 현행 브리프는 미습득 스킬 사용·장착 금지다. 오디오 소스·자산 및 해당 기존 테스트는 이번 쓰기 범위 밖이다. 전체 검사 통과와 출시 가능으로 판정하지 않는다. 통합 담당이 이 8개를 정리하고 전체 검사를 다시 실행해야 한다.

AUTO 검증에 사용한 브라우저·서버는 모두 종료했고 남은 AUTO QA 프로세스가 없음을 확인했다. 시작 시 실행 중이던 다른 UI 레인의 QA 프로세스는 중단하지 않았다.
