# 검성 전투 정체성 V1

목표: 같은 검성·같은 보스에서 장비 선택이 다른 타격 궤적과 전술을 만든다.
기존 `00aaf161e2f67e4c66b0a1673d18785777af9de9`의 진행 V2를 보존한다.

## 이번 플레이 범위

- 잔향 4세트: 전진 일섬 뒤 귀환 검기. 이동한 플레이어 방향으로 돌아오는 별도 관통타.
- 정박 4세트: 전방 고정 지점의 흡인과 지연 파열 3회. 이동한 적은 파열 범위를 벗어날 수 있다.
- 보루 4세트: 넓은 일섬을 좁고 빠른 관통타로 대체한다. 넓은 무리에는 불리하고 사거리·방어 연계를 활용한다.
- 2세트 및 해당 세트 없는 상태는 기존 일섬을 유지한다. 장비 수치와 드랍·제작 비용은 변경하지 않는다.
- 파티는 이번 솔로 후보에 포함하지 않는다. 기존 일섬과 프로토콜을 유지한다.
- 가디언의 다른 기본 기술에 일섬 변형이 적용된다고 표시하지 않는다.
- 프리셋은 장비 참조·Q/E underlying index·전직·기예·성장 경로·서약을 함께 복원한다.
- 변형의 정본은 출격 때 확정된 세트다. 로비 장비를 매번 조회하거나 전역 스킬 함수를 덮어쓰지 않는다.

## 취소와 회귀 경계

지연 공격은 원래 전투/플레이어/생명 주기에 귀속된다. 종료·교체·사망 후 부활 시 이전 공격을 다시 실행하지 않는다.
일시정지에서는 전투 시계와 피해가 진행되지 않는다. 프리셋 저장 실패는 Q/E와 장비를 함께 되돌린다.
기존 8개 스킬, Lv35/50 해금, MP100·4/초, 회피1.35초, 득템 최대2개, 보스 직행의 방 상태와 풀클리어 가산 보상은 보존한다.
새 화면 전체 흔들림·필름 진동·애니메이션 그레인은 추가하지 않는다.

## 검증 표면

`bun test` → `bun run typecheck` → `node node_modules/vite/bin/vite.js build --configLoader native`.
`node tools/knight-build-qa.mjs`는 실제 컴파일 빌드와 격리된 브라우저 저장만 사용한다.

동일 버전 비교는 `--baseline --root=<기준 체크아웃>`으로 같은 어댑터·보스·장비·레벨·Q/E·시드를 사용한다.
`--live`는 지정된 Blade Surge production origin만 검사하고 체크아웃 SHA와 version.json을 대조한다.
외부 쓰기 요청은 차단·기록하며 사용자의 기존 브라우저 프로필을 열지 않는다.

프로브는 합성 Lv50 장비를 준비하고 보스/잡몹을 잠시 고정해 한 번의 실제 입력→기술→피해를 관찰한다.
이후 고정을 풀고 실제 AUTO로 같은 보스 전투를 종료한다. 전체 던전의 자연 획득이나 수동 공략이라고 부르지 않는다.
첫 캡처는 보스 입장 배너가 남아 있어 증거에서 보존하되, 비교에는 자연스럽게 배너가 사라진 뒤의 캡처를 사용한다.
모바일은 880×400/640×360 Chromium 실렌더링이다. 휴대전화 FPS·발열·터치 만족도 또는 사람의 재미 판정이 아니다.

## 목표와 운영 경계

`APEX task-effort-routing-v1`과 APEX Universal Harness 안에서 현재 Blade Surge 목표만 관리한다.
현재 사용자 요청은 이 제품의 기획·빌드·검증·배포 RSI다. 결제·가격·새 provider·권한·타 프로젝트는 포함하지 않는다.
실행은 foreground이며 상시 daemon이나 다른 세션을 수집하는 감독자를 주장하지 않는다.
회전은 관측→재현→기준→작은 후보→실물 검증→독립 검토→유지/되돌리기로 닫는다.
자동 테스트와 독립 검토를 통과하지 않은 소스는 운영에 배포하지 않는다. GitHub Actions는 사용하지 않는다.
배포에는 기존 `tools/deploy.mjs --auth=wrangler`의 exact HEAD·lease·live ancestor·rollback 가드를 그대로 사용한다.

다섯 영웅 확장·새 보스 기믹·목표 파밍·MP 재설계는 이 후보의 완료 범위가 아니다.
검성 세 빌드의 인간 플레이테스트와 물리기기 검증을 다음 설계 입력으로 남긴다.
