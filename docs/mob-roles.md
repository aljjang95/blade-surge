# 일반 적 전투 역할

기존 일반 근접 적 16종이 같은 추적·단발 공격을 공유했다. 이 변경은 오크 전사·이계 침입자를 돌격병, 해골 자객·그림자 닌자를 측면 침투병, 뼈 오크·오크 덩어리를 중타병으로 만든다. 기존 모델, 체력, 경험치와 골드, 방 정원은 보존한다. 중타 공격만 긴 예고에 맞춰 공격력의 1.15배를 사용한다.

구현 전 수용조건:
- 돌격은 0.9초간 정지해 직선 범위를 경고한 뒤 실제 충돌 경로를 따라 이동한다. 경고한 범위와 실제로 지나간 구간 안에서만 한 번 피해를 준다. 벽 너머나 이동 전 경로 전체에 피해를 주지 않는다.
- 침투는 측면으로 최대 0.5초 이동한 뒤 방향과 공격 원을 고정한다. 그때부터 0.8초간 예고하고 공격한다. 이동하면서 플레이어를 계속 조준하는 공격은 없다.
- 중타는 전방 원을 1.2초 예고한 뒤 공격하고 1.05초간 반격 기회를 준다. 돌격은 0.9초, 침투는 0.75초간 회복한다.
- 동시에 준비·공격·회복하는 역할 적은 최대 3명이다. 기존 일반 공격으로 우회해 경고 없는 타격을 만들지 않는다. 기존 보스·폭탄·주술사·방패 행동과 스킬 VFX는 유지한다.
- 한 적당 경고 메시 하나를 재사용한다. 경고는 렌더·판정·파티 DTO가 같은 도형을 읽는다. 파티 호스트만 실제 피해를 계산하며, 동일 플레이어는 한 공격에 한 번만 맞는다.
- 정지는 경고와 이동을 동결한다. 경직·기절·사망·전투 종료는 이동과 경고를 취소하고, 취소된 공격이 일반 근접 공격으로 이어지지 않는다. 월드의 반경 충돌 처리를 유지한다.
- 단위 검증 외에 실제 앱의 각 역할 예고·회피·의도적 피격·벽·취소·회복을 검사한다. 별도 격리한 역할 검사와 실제 혼합 무리 AUTO 전투를 구분한다. 실물 모바일 성능이나 새 모델 제작으로 보고하지 않는다.

첫 AUTO 표본은 12개 방을 완주했으나 피격 비율 0.048로 기존 하한 0.05에 못 미쳤다. 역할 자체의 회복 시간 뒤에 기존 일반 공격의 긴 대기 시간까지 더해진 것이 불필요한 이중 대기였다. 예고와 반격 시간은 그대로 두고 추가 대기를 돌격 0.45초, 침투 0.3초, 중타 0.55초로 분리했다. 기존 지표 기준을 유지해 다시 검사한다.

분쇄는 경고 원의 실제 중심에 착탄 먼지와 낮은 충격음을 주며 밀침은 8이다. 몸 중심에서 엇나간 타격 표현과 가벼운 휘두름 소리를 교정한다. 공격 범위·피해 배율·예고와 회복 시간은 동일하다. 기존 합성 충격음을 사용하며 새 Flow SFX 제작으로 보고하지 않는다.

벽 시험의 첫 목표는 벽 밖이 아닌 연결 복도였다. 실패 표본을 보존하고, 목표가 실제 walkable 영역 밖인지 먼저 확인하는 북쪽 벽 시험으로 수정했다. 혼합 후기 관문 검사는 원래 레벨 1 영웅으로 난이도를 판정하지 않는다. HP 전용 장비 보너스를 넣고, 실제 스탯 재계산과 보상 선택을 유지한 채 세 역할의 동시 작동을 관찰한다. 별도 무보정 첫 관문 AUTO가 기존 성장·보상·피격 지표를 판정한다.
