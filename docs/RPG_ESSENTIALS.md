# RPG 필수 시스템 감사와 구현 순서

2026-10-29 `[gogo-chunk:blade-rpg#essentials]`. 대표님 요청 "RPG에 해당하는 가장 필수 장치들을 기획해서 넣어 달라"(목표: 하루 8시간·3개월 하이엔드 출시)에 대한 정본. 기준 소스 `origin/main` `c2603fc`, 판정은 코드 정적 확인(UI 입구까지 확인).

비교 대상: 던파 모바일·디아블로 이모탈(핵앤슬래시), 에픽세븐(수집형), 리니지M류(방치·복귀). 장르 상위작이 공통으로 가진 "돌아올 이유" 장치를 첫날 → 첫 주 → 첫 달 유지율 영향 순으로 본다.

## 2. 구현 순서(이 레인)

영향 큰 순서. 다른 레인 소관(레벨 곡선·재화 소모처·카드 보상·캐릭터 선택·로그인·결제)은 건드리지 않는다.

| 순서 | 덩어리 | 이유 | 유지 구간 |
|---|---|---|---|
| E1 | 알림 배지 확장(여정·탑 상자·도감) + 출석 리셋 05:00 KST | 이미 있는 보상을 놓치지 않게 — 비용 최소, 효과 즉시 | 첫날 |
| E2 | 오프라인 보상 + 복귀 보상(같은 lastSeen) | 다음 접속의 첫 화면 이유 | 첫날·첫 주 |
| E3 | 신규 7일 미션 이벤트 | 첫 주 매일 목표 | 첫 주 |
| E4 | 업적(평생 누적) | 장기 목표·수집 욕구 | 첫 달+ |
| E5 | 우편 모두 받기·만료·동적 저장 + 패스 XP를 의뢰에서 | 보상 통로 정비 | 전 구간 |

보류: 길드(서버·소셜 큰 작업, 소셜 레인과 별도 설계 필요), 요일 던전(던전 클리어 루프 레인과 겹침), 상시 랭킹(소셜 레인).

## 3. 규칙

- 새 일일 리셋은 `periodAt`(05:00 KST)을 쓴다. 기기 시계에 강해야 하는 보상(오프라인·복귀)은 `endgameNow`(서버 시각 우선).
- 새 보상은 `bun run sim:90d` 밴드 안이어야 한다. 시뮬레이터가 모델링하지 않는 보상원(출석·패스 등)은 하루 기대량을 이 문서 4절에 적는다.
- UI는 메뉴 안 모달과 메뉴 점만. 전투 화면 위 팝업 없음.
- 결제 연동·유료 트랙·가격 없음.
