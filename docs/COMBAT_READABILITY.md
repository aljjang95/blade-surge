# 전투 가독성 계약 (2026-10-29)

대표님 요청: "적과 싸우다 보면 식별이 잘 안 된다 — 내가 적을 쏘는 건지 허공에 쏘는 건지 구분이 안 간다. 타격할 때 적과 내가 식별될 수 있는 장치."

## 기준 녹화에서 본 식별 실패 (844×390 가로, 고정 시드, 1/60초 고정 프레임, SwiftShader)

도구: `node tools/combat-readability-qa.mjs --tag before --dist <빌드>` (5영웅 × 1-1·3-2·3-5, 12초 AUTO), `node tools/skill-vfx-gallery.mjs --tag before` (영웅별 스킬 4종 × 시전 후 0.12/0.3/0.55/0.9초).
산출물은 `work/combat-readability/<tag>/`, `work/skill-vfx-gallery/<tag>/`(커밋하지 않음).

1. **3장(서리 도서관) 흰 해골 무리 속 흰·청 영웅**: 바닥·적·영웅이 모두 밝은 청백색이라 무리 한가운데 영웅이 묻힌다(검성 3-2 약 8.4초). 적 일반 개체엔 발밑 표식이 없어 '저게 적인지 장식인지'가 갈리지 않는다.
2. **원거리 대상이 화면 아래 가장자리**: 바람추적자 1-1에서 자동 조준 대상(묘비 방패병)이 HUD 아래 가장자리에 있어, 화살이 화면 밖을 향해 '허공에 쏘는' 것처럼 보인다(약 4~5초).
3. **빗나감 표시 없음**: 화살·마탄이 사거리 끝에서 조용히 사라지고, 헛스윙도 소리뿐이다. 맞음/빗나감의 차이가 숫자 유무뿐이다.
4. **조준 대상 월드 표식 없음**: 대상 이름·체력(DOM 태그) 하나뿐이라 무리 속에서 누구를 노리는지 바닥에서 보이지 않는다.
5. **큰 피해 비율이 아닌 타격은 적이 번쩍이지 않음**: 무게 섬광(`flashFor`)이 weight ≤ .05면 생략돼, 체력 많은 적에게 작은 피해는 '맞았는지'가 안 보였다.
6. **스킬 섬광·지면 원화가 적 몸을 덮음**: 광전사·검성 스킬이 영웅 주변 원형 문양 위주라 동작이 단조롭고, 섬광이 커지면 대상이 묻힌다(스킬 VFX 레인에서 개선).

## 공용 식별 장치 (src/game/combat-readability.js + src/engine/readability-view.js)

| 장치 | 맞음 | 빗나감 | 비고 |
|---|---|---|---|
| 적 몸 | 영웅색 접점 불꽃(기존) + **최소 흰 섬광 0.08초**(치명 금색) + 반동·히트스톱(기존) | 없음 | 섬광이 더 긴 무게 섬광은 덮지 않음 |
| 숫자 | 피해 숫자(기존: 치명 금 `!`, 스킬 청, 보스 분홍, 마무리 크림) | **없음** | |
| 사거리 끝 | — | **회색 먼지 고리**(0.32초, 영웅색 아님) | 화살·마탄 수명 만료, 평타 헛스윙 |
| 조준 대상 | 바닥 꺾쇠 고리 **명중 펄스**(크기 +22%, 흰빛) | 펄스 없음 | 영웅색 회전 꺾쇠 + 머리 위 역삼각 표식 |
| 원거리 조준선 | 영웅→대상 바닥 점선(사격 직후 0.9초 진하게) | 같음 | 바람추적자·대마도사·검은 고양이 |
| 피아 | 적 일반 개체: **붉은 발밑 고리**(+눈금), 맞은 적: **머리 위 체력 막대**(흰 지연 막대, 정예 금색) | | 영웅: 기존 청록 비컨 + 위치 마름모. 정예·보스: 기존 금·적 고리, 보스는 상단 보스바 |
| 영웅 피격 | 화면 가장자리 붉은 비네트(기존 `ui.hurtVignette`) | | 플레이 영역 중앙을 가리지 않음 |

영웅별 조준색(`READ_COLOR`): 검성 금 `#ffd45a`, 광전사 호박 `#ffb028`(고유 붉은색은 적 표식과 겹쳐 비켜 둠), 대마도사 하늘 `#58c8ff`, 암살자 보라 `#c690ff`, 바람추적자 비취 `#7ff0c4`.

규칙
- 판정·피해·난수에 손대지 않는 표시 층이다. `Math.random`을 쓰지 않는다(시드 전투 결정성, 테스트로 고정).
- 화면 전체 흔들림 금지(`renderer.shake` no-op 유지). 무게감은 정지·섬광·반동으로.
- 표시가 플레이 영역을 덮지 않는다: 바닥 표식은 얇은 고리, 체력 막대는 맞은 적·대상만 3.2초.

## 성능 예산 (모바일 390px 높이 기준 60fps 목표)

| 표시 | 드로우콜 | 상한 | 수명 | 프레임당 비용 |
|---|---|---|---|---|
| 적 발밑 고리 | 1 (인스턴스) | 64 | 상시 | 적 수만큼 vec4 갱신 |
| 체력 막대 | 1 (인스턴스, depthTest 끔) | 24 | 맞은 뒤 3.2초 | vec4 ×2 |
| 조준 꺾쇠 고리 + 표식 | 2 (+외곽 1) | 1 | 상시 | 행렬 1 |
| 조준선 | 1 | 1 | 사격 뒤 0.9초 진하게, 대상 있으면 옅게 | 행렬 1 |
| 빗나감 먼지 고리 | 1 (인스턴스) | 16 (링버퍼) | 0.32초 | vec4 ×2 — 평타 화살·마탄 만료와 평타 헛스윙 첫 타만 |

새 할당 없음(모든 행·배열 미리 할당). 기존 스킬 VFX 예산(`IMPACT_FRAME_BUDGET` 72, `FX_EXPOSURE`, `TEX_FLASH_MAX_DIAMETER`)은 그대로다.

## 검증 범위

헤드리스 Chromium + SwiftShader 고정 프레임 캡처는 "보이는지" 확인용이다. 실제 Android GPU 프레임·발열·터치 손맛 증거가 아니다.
