# 관문 선택(스테이지 선택) 화면 (2026-10-24)

대표님 피드백(운영 실제 플레이): "던전 첫 진입 시 어디 스테이지를 선택할 건지에 대한 패치를 진행 중이었는데 그 부분이 안 되어 있다." 이전 WIP·PR·장부에 남은 코드가 없어 새로 만들었다. 설계도 노드 `stage-select-screen`·`stage-select-model`·`stage-select-memory`·`stage-map-art`(work/blueprint, 시안 c1 측면 시트 경로), 수용 기준 A44~A47, 결정 D24~D26.

## 흐름

1. 로비 오른쪽 아래 '출격'(그리고 영웅·장비 화면의 출격 준비, `gear-panel.js` → `openPreparation`)을 누르면 전투로 바로 가지 않고 관문 선택 화면이 열린다(`CitadelCommand.openPreparation` → `app.stageSelect.open`).
2. 탭 [캠페인 | 던전].
   - 캠페인: 지역 이름 · 이전/다음 지역 · 정화 'N / 10', 지역 그림 지도 위 관문 X-1~X-10(X-5 해골 '중간 보스', X-10 해골+왕관 '지역 보스'), 클리어=초록+별, 추천=금색 링+점 3개+'추천', 잠김=회색+자물쇠.
   - 던전: 열린 던전 전부 + 다음에 열릴 잠긴 던전 1곳, 각 카드에 [기본|심층] 단계. 심층은 정의가 있는 던전만 보인다.
3. 아래 상세 줄: 이름 · 꼬리표 · 추천 레벨(던전은 탐험 레벨) / 내 전투력 vs 권장(초록 충분, 노랑 80% 이상, 빨강 부족) / 입장 에너지 · 주요 보상(첫 클리어 보석, X-10 은 '지역 N 해금').
4. 오른쪽 아래 주황 '입장' 하나.
   - 캠페인 → `app.startStage(stageDef(ch, st))`. 에너지 차감·부족 충전 안내·실패 환급은 startStage 한 곳.
   - 던전 → 기존 준비창(`hubUI.openDestination`, 관문 없는 컨셉 던전은 `expeditionUI` 목록의 그 카드). 영웅·물약·서약·목표 확인을 유지하고 에너지는 준비창 '원정 시작'(startExpedition)만 쓴다. 준비창 내부는 수정하지 않았다.
5. 잠긴 관문·단계도 고를 수 있다. 입장 버튼이 회색 '잠김'이 되고 해금 조건 한 줄(예: `1-2 클리어 시 해금`, `캠페인 2-10 클리어 필요`, `탐험 레벨 3 필요`)이 보인다. 잠긴 지역으로 넘기면 그 지역 첫 관문의 조건을 보여 준다.
6. 열기·닫기(X, 바깥 누르기)·ESC·탭 전환·고르기는 저장·에너지를 바꾸지 않는다. 닫으면 초점이 '출격' 버튼으로 돌아온다.

## 기본 선택과 기억

순서(`stageSelectModel`): ① 로비 카드로 직접 고른 던전 → ② 기억한 마지막 선택 → ③ 추천. 잠긴 곳은 기본 선택이 되지 않는다.

- 추천: 다음으로 깰 관문(`progress.unlocked`, `Economy.nextStage`와 같은 규칙). 캠페인을 완주한 저장은 던전 탭(로비 착지 모델의 추천 던전·단계)이 추천.
- 마지막 선택은 입장할 때만 저장한다. 그때 고른 것이 추천이었으면 `followed: true` 로 남겨 다음 출격 때 **새 추천**(예: 1-1 을 깼으면 1-2)으로 열고, 추천이 아닌 곳(예: 1-3 반복 사냥, 특정 던전)이면 **그 자리 그대로** 연다. 반복 플레이는 '출격 → 입장' 두 번 탭.

## 저장 키

`localStorage['blade-surge.stage-select.v1'] = { introSeen: boolean, last: null | { tab: 'campaign', ch, st, followed } | { tab: 'dungeon', id, depth: 'standard'|'deep', followed } }`

- `normalizeStageSelectMemory`: 모르는 필드·범위 밖 지역/관문·이상한 던전 id·문자열 불리언은 버리고 기본값. 멱등. 손상 JSON·저장 공간 차단(getter 예외)은 기본값으로 이번 창에서만 기억.
- 게임 저장(`eco.s`) 형식은 바꾸지 않았다.
- 첫 안내: 이 기기에서 본 적이 없고 캠페인 별 기록이 하나도 없는 저장(신규)만, 첫 열기에 한 번. 열 때 바로 `introSeen: true`.

## 고른 이유와 다른 선택지

| 결정 | 고른 것 | 다른 선택지 · 버린 이유 |
|---|---|---|
| 화면 형태 | 시안 c1 측면 시트 경로(지휘 점수 18) | c3 하단 카드 캐러셀(17): 기존 던전 카드 줄과 모양이 겹쳐 무엇을 고르는지 흐려지고 5·10 보스 위치가 안 보임. c2 전체 지도(16): 로비·영웅이 사라지고 짧은 가로에서 상세 카드가 지도를 가림 |
| 세로 | 아래쪽 시트(높이 약 70%) | 오른쪽 시트는 390 폭에서 지도가 너무 좁다 |
| 기억 위치 | 기기 localStorage | 게임 저장(eco.s)에 키 추가: 서버 계정·기기 간 동기화는 되지만 수익화 레인이 economy/save 를 고치는 중이라 충돌, 첫 안내·마지막 위치는 기기 편의 정보(기존 tutorial·town-content 안내 키와 같은 관행) |
| 기존 저장의 첫 안내 | 관문을 하나라도 깬 저장은 띄우지 않음 | 모두에게 한 번 띄우기: 이미 진행 중인 사람에게 "1-1부터"는 틀린 안내 |
| 던전 입장 | 기존 준비창을 연다 | 선택 화면에서 바로 startExpedition: 영웅·물약·서약·목표 확인과 심층 판정 UI를 잃는다 |

| 첫 안내 그림 | 시안 c1 의 여우 동행 초상을 잘라 씀(`public/img/stage-select/guide-fox.webp`, 128px, 자체 생성 시안) | 동행 네브 초상: 시안과 다름. 전용 초상 생성은 남은 것 |
| 던전 목록 | 열린 던전 + 다음 잠긴 1곳, 나머지는 개수만 | 20곳 전부: 신규 저장은 16곳이 잠김이라 목록이 소음 |

## 다른 레인과의 경계

- 던전 목록은 `stageSelectDungeonSource(expedition)` 한 함수에서만 읽는다(지금은 `dungeonJourney` 의 `dungeonAccess` 기본 단계 판정). 마을 해금 레인(claude/blade-town-unlock)이 '보이는/열린 던전' 판정을 내보내면 이 함수만 바꾼다.
- 던전 카드 줄 필터·3D 관문·지역 마을 연출·상점 가격·준비창 내부·출격 중 각인(제거됨)은 건드리지 않았다.

## 연결 지점

- `src/ui/citadel-command.js` `openPreparation`: `app.stageSelect` 가 있으면 선택 화면을 연다(카드로 고른 던전 → `prefer`, 착지 모델 추천 → `dungeonRecommended`). 없을 때의 이전 경로는 그대로 남겼다.
- `src/main.js`: `this.stageSelect = new StageSelectUI(this)`.
- `src/ui/stage-select.js` / `stage-select.css`: 화면. `src/game/stage-select-model.js`: 순수 모델. `src/data/stage-select-maps.js`: 지역 지도·노드 좌표·배치 계산.
- 지도 배경: `public/img/stage-select/map-r1~6.webp`(1200x900, PC Codex 생성 원본 `art/stage-select-concepts` 브랜치 `out/map_r*.png` → webp q78).

## 검증

- 단위: `bun test test/stage-select-model.test.ts` — 정규화·멱등·저장 예외, 신규 1-1 추천·잠금 사유, 1-3 클리어 → 1-4, 기억(지난 자리·followed·잠긴 기억 무시·카드 우선), 던전 탭(열린 + 다음 1곳, 심층 사유, 소스 교체), 완주 저장 던전 추천·에너지 부족, 지역 지도 좌표 간격·띠, 지도 배치 여백.
- 실제 입력: `node tools/stage-select-qa.mjs <origin> <out> [--profiles=land-844x390,port-390x844,desktop-1280] [--battle=land-844x390] [--regions]` — 새 브라우저 프로필(신규 저장 Lv.1)에서 출격 → 선택 화면(첫 안내·1-1) → 잠긴 1-3 사유 → 던전 탭·잠긴 심층 사유 → ESC/닫기 비용 없음·초점 복귀 → 두 번째 열기 안내 없음 → 던전 입장=준비창(비용 없음) → 다시 출격 시 던전 기억 → 캠페인 1-1 입장=전투·에너지 1회 차감 → 시드 저장(1-3 클리어) 추천 1-4 → (--regions) 6지역 지도. 로컬 vite 의 `/api/*` 404 는 Worker 부재로 제외한다.

## 남은 것

- 실기기(Android) 터치·안전 영역 확인, 운영 배포 뒤 대표님 체험.
- 지역 1·4·6 지도는 그림 길이 노드 띠 밖으로 휘어 노드 일부가 길 옆 빈터에 놓인다(점선 길로 순서 표시). 노드 배치에 맞춘 지도 재생성 또는 좌표 미세 조정.
- 짧은 가로(844x390)에서는 노드 묶음 높이가 지도보다 커서 세로 간격을 줄인다(그림 길과 조금 어긋남).
- 첫 안내 여우 초상은 시안에서 잘라 낸 128px 이미지다. 전용 초상(동행 캐릭터 정체성 확인 포함)은 아트 레인.
- 마을 해금 레인 판정으로 `stageSelectDungeonSource` 교체.
- 난이도(숙련·악몽·지옥) 고르기는 이 화면에 없다. 저장된 난이도로 입장하고, 바꾸려면 메뉴의 캠페인 탭.
