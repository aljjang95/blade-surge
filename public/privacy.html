게임 진행

영웅·장비·던전 진행·설정은 현재 기기의 브라우저 또는 앱 저장소에 보관하며, 첫 스테이지를 클리어하거나 계정을 연동하면 같은 진행을 서버 계정에도 저장합니다(다른 기기 복원·데이터 보호 목적). 기기 저장 기록은 결제 증명으로 사용하지 않습니다. 게임 설정의 초기화 또는 기기 저장 삭제로 기기 기록을 제거할 수 있습니다.

계정·로그인

게스트로 시작하면 기기에서 만든 임의의 기기 키로 서버 계정을 만들며 서버에는 기기 키의 해시만 저장합니다. Google 계정으로 계속(연동)하면 Google이 확인한 계정 고유 식별자를 받아 해시만 저장하고 이메일·이름·사진은 저장하지 않습니다. 이 해시는 다른 기기에서 같은 진행을 복원하고 중복 계정을 막는 데만 사용합니다. 로그인 방식은 선택 사항이며 게스트로도 이용할 수 있습니다. 새 계정 생성·로그인 시도의 속도 제한에는 IP 주소의 해시만 쓰고 원문 IP는 저장하지 않으며, 제한 기록은 만료 후 삭제합니다. 다른 로그인 제공자를 추가하면 이 항목에 제공자와 처리 내용을 먼저 공개합니다.

스토어 인증·구매 복원

스토어 기능을 활성화한 버전은 사용자가 구매·복원을 요청할 때 Google 계정의 서명된 인증 토큰 또는 토스의 일회용 인증 코드를 플랫폼과 확인합니다. 서버에는 채널별 계정 식별자의 해시, 세션 토큰의 해시, 주문 상태·상품·지급 및 환불 기록을 보관합니다. 토스 주문 번호는 상태 재조회에 사용합니다. Google 구매 토큰과 카드 번호·결제수단 원문을 게임 저장이나 운영 로그에 기록하지 않습니다. 이 처리는 구매 인증, 복원, 환불 반영과 중복·부정 지급 방지에 사용합니다.

커뮤니티

게임 안 커뮤니티(채팅·친구·파티 모집·명예의 전당·소식·제보 게시판)를 쓰면 닉네임, 게임 내 기기 키의 해시, 공개 프로필(이름#태그·가입 순번·칭호), 채팅 메시지, 친구·차단·신고 기록, 게시글·댓글·공감 기록, 명예 기록(던전 클리어 시간·순위)을 서버에 보관합니다. 기기 키 원문은 서버에 저장하지 않고 해시만 저장합니다. 구글 계정을 연결한 경우 구글이 발급한 계정 고유 식별자의 해시만 저장하며 이메일·이름·사진은 저장하지 않습니다(게임 계정 연동은 위 ‘계정·로그인’). 채팅 기록은 광장별 최근 메시지만 유지하고, 게시글과 명예 기록은 운영 목적 범위에서 보관합니다. 기기 키를 잃으면 같은 계정으로 돌아갈 수 없고, 구글 연결 후에는 다른 기기에서 기록을 되찾을 수 있습니다. 삭제 요청은 아래 이메일로 보내 주세요. 디스코드 웹훅 등 외부 전송은 게시글 제목·내용과 명예 기록만 보내며 비밀번호나 기기 키는 보내지 않습니다.

광고

광고 기능이 활성화된 버전에서 사용자가 광고를 요청하면 토스 또는 Google AdMob SDK가 기기 식별자, 앱 상호작용, 진단·오류 정보와 IP 기반 일반 지역 정보를 처리할 수 있습니다. 플랫폼이 요구하는 동의를 확인한 뒤 광고를 요청합니다. Android 메뉴의 ‘광고 개인정보 설정’은 해당 동의 변경이 필요한 경우 제공됩니다.

선택 연결 기능·제공자

파티 기능을 선택하면 파티 코드와 플레이 상태를 서버와 교환합니다. 생성형 동행 대화는 기본 비활성입니다. Cloudflare는 서버·보안·서비스 제공에, 각 스토어와 Google은 사용자가 요청한 인증·주문 검증·광고에 이용됩니다. 제공자의 글로벌 인프라에서 처리될 수 있으며 제공자의 공개 방침을 확인할 수 있습니다. 운영 로그는 서비스 보호와 오류 확인에 사용하고 비밀번호·구매 토큰은 남기지 않습니다.

보관·삭제

기기 게임 진행은 이용자가 초기화할 때까지 기기에 보관합니다. 서버 계정 정보와 진행 기록은 회원 탈퇴 시까지 보관합니다. 게임 설정 → 계정 · 데이터 → 계정 · 로그인 연동에서 회원 탈퇴를 신청하면 로그인 세션·연동 정보·기기 키 정보와 커뮤니티의 친구·차단·기기 연결은 즉시 삭제하고 커뮤니티 이름은 익명화하며, 진행 기록은 복구 요청에 대비해 30일 보관하며, 이 기간이 지난 기록은 파기 대상으로 분리해 정기 점검 때 파기합니다. 연동 없는 기기 계정에서 연동된 다른 계정으로 전환하면 이전 기기 계정의 진행 기록은 90일 보관하며, 이후 같은 방식으로 파기합니다. 연동·결제 이력이 없는 저레벨 게스트 계정이 180일 이상 접속하지 않으면 진행 기록을 별도 보관함으로 옮기며(같은 기기로 돌아오면 그대로 복원) 보관 1년이 지나면 같은 방식으로 파기합니다. 만료된 인증·세션·악용 방지·미사용 주문 준비 기록은 30일이 경과한 기록부터 정기 삭제합니다. 구매 원장은 영구 비소모품 복원과 환불·재사용 방지를 위해 권한 유지 기간 보관합니다. 삭제 요청 시 본인 확인 후 불필요한 정보를 제거하고, 법령상 보관이 필요한 거래 기록은 목적을 제한해 보관한 뒤 파기합니다.
