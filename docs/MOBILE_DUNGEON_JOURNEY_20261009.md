# 모바일 시작과 던전 여정

사용자가 제공한 짧은 가로 화면에서 모험 패널 본문이 잘렸다. 844×300과 667×280의 기존 공개 산출물로 재현했으며, 상·하단 여백과 메뉴·헤더의 합이 패널 높이보다 커 본문이 34px로 줄고 패널 밖에 놓였다. 원본은 `work/mobile-journey-20261009/baseline/`에 보존한다.

모바일 첫 시작 버튼은 `전체화면 · 가로로 시작`이다. 실제 사용자 터치 스택 안에서 Fullscreen API를 호출하고, 승인된 뒤 `screen.orientation.lock('landscape')`를 시도한다. 최초 회전 안내는 로딩/시작 버튼을 덮지 않는다. 미지원·거절은 시작 실패로 바꾸지 않으며, 가로로 돌리기 안내와 세로 계속하기를 제공한다. Safari와 실제 Android 회전은 브라우저 뷰포트 검수만으로 승인하지 않는다. API 근거: [Fullscreen](https://developer.mozilla.org/en-US/docs/Web/API/Element/requestFullscreen), [Orientation lock](https://developer.mozilla.org/en-US/docs/Web/API/ScreenOrientation/lock).

짧은 가로 모험 화면은 정보·메뉴를 작게 배치하되 44px 터치 영역을 보존한다. React 패널은 `auto / minmax(0, 1fr) / auto` 그리드로 본문 스크롤을 소유하며, 알림이 없는 저장 푸터는 공간을 차지하지 않는다. 기존 정산 결과의 전체 화면 소유권은 유지한다.

홈에 다음 던전 그림이 보이는 여정 입구를 추가하고 기본 던전은 12개 지역 그림·연결 경로·해금 레벨·정복 표식·현재 영웅으로 표시한다. 지역 선택/잠금 확인/취소는 자원을 소비하지 않는다. 출격은 기존 준비창과 `startExpedition`의 ticket·에너지·저장·환급·정산만 사용한다. 지역별 목표·보상·심층·전술 공략은 기존 상세 화면에 보존한다. 배경과 초상화는 기존 승인된 이미지이며 새 외부/유료 자산은 사용하지 않는다.

기존 Lv.1 유리 정원 승리 EXP100만으로 원정 Lv.2(필요 EXP150)에 도달하지 않는다. 별도 메뉴의 클리어 퀘스트 EXP60을 받을 수 있을 때 결과에 `보상 받고 다음 던전`을 표시한다. 레벨·경험치·해금 수치를 바꾸지 않고, 필요한 수령 가능 퀘스트만 미리보기한 뒤 명시적 터치에서 기존 `claimQuest`를 호출한다. 저장 실패/오래된 결과/입장 준비 중/미해금은 진입을 막는다. 다음 준비창까지는 에너지를 쓰지 않으며 실제 출격에서만 한 번 차감한다. 패배·심층·균열·전술 공략의 정산과 다시 도전은 유지한다.

검증 경로는 기존 `tools/mobile-qa.mjs --journey --angle=d3d11`과 `tools/mobile-journey-checks.mjs`다. 모바일 Chromium 두 프로필에서 최초 화면 요청, 6개 크기의 모험 메뉴, 잠금 확인/취소, 자연 승리, 클리어 보상 수령, 다음 지역 준비·재로딩·실제 입장·소유한 전투 정리를 관측한다. 주입한 승리·세이브·시계는 사용하지 않는다. desktop GPU의 모바일 viewport/touch 검증이며 실기기 Android GPU·발열·Safari·청감 인증과 구분한다. 정확한 소스/빌드·결과·스크린샷·미디어 오류 경계는 실행별 영수증을 따른다.
