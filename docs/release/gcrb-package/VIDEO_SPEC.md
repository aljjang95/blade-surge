## 3. 제작 방식 (신고서에 그대로 밝힘)
- 운영 주소 https://blade.tllhouse.com 의 실제 코드를 실제 키 입력으로 플레이해 촬영.
- 클라우드 환경에는 GPU가 없어 게임을 1/30초 단위로 진행하며 프레임을 찍어 30 fps로 엮었다. 게임 내부 속도는 정상.
- 흡혈 4세트 장착과 1-5 개방은 심사 장면 확보를 위해 게스트 저장 상태를 직접 설정했다(영상·REVIEWER_ACCESS.md 3절에 명시).
- 무음 영상. 게임 BGM·효과음은 포함되지 않는다.

## 4. 확인하지 못한 GCRB 제한
- 영상 파일 형식·코덱·해상도·길이·용량의 상한은 공식 문서에서 확인하지 못했다. 이번 파일(H.264 MP4, 1280×720, 158초, 약 28 MiB)은 일반적 업로드 규격 범위라고 판단했지만, 실제 접수 화면의 제한은 제출 전에 확인해야 한다.
- 접수 화면에서 요구하는 영상 설명 형식이나 최소 길이는 미확인.
- 사업자·수수료 등 접수 조건은 이 파일의 범위 밖이다(GCRB_APPLICATION.md 참고).
