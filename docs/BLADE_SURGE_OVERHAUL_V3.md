# Blade Surge — 서약 원정대 V3

기준: `1fcd4d8` · 제작: Blender **5.2.1 LTS**, build `9e2066aef7ef` · 2026-09-16.

## 플레이 목표

혼전에서도 내 영웅과 공격 방향을 즉시 찾고, 이동·회피·공격·카메라를 서로 방해 없이 조작한다. 다섯 영웅은 얼굴과 기존 전투 정체성을 유지하면서 실루엣과 재질로 구별한다. 전체 화면 흔들림·번쩍임으로 타격감을 대체하지 않는다.

## 대안과 결정

1. 기존 자산의 색/효과 보정: 추가 비용 없음, 가장 빠르지만 평평한 복장과 식별 문제를 충분히 해결하지 못한다.
2. 기존 엔진/리그를 보존하고 Blender 복장·구도·접촉 피드백 개편: 기존 로컬 도구와 배포 권한 사용, 추가 유료 서비스 없음. 성장/전투 회귀를 기존 검사로 비교할 수 있다. **선택**.
3. 엔진과 캐릭터를 전면 교체: 별도 플랫폼과 애니메이션/입력/저장 이식이 필요하며 검증 범위가 급증한다. 이번 개선에는 부적합.

## 아트 계약

- 아르카: 상아 흉갑, 남청색 분할 코트, 황동 검 문장, 층진 어깨판. 큰 밝은 상체와 긴 수직선.
- 드라칸: 적갈색 망토, 흑철 비대칭 어깨판, 짧고 넓은 실루엣과 무거운 도끼. 피부와 갑옷을 구별.
- 리아: 남보라 로브, 은빛 초승달 어깨, 별 보석. 하체가 넓어지는 종 모양.
- 카인: 어두운 청록 후드, 사선 가죽 하네스, 분리된 코트 꼬리. 좁고 날렵한 실루엣.
- 실바: 숲색 의상, 겹잎 어깨와 상아 장식. 기존 활·화살통·얼굴·독자 Bow_Shoot를 보존.
- 원본 GLB와 리그/클립은 보존한다. 별도 V3 GLB·편집 가능한 blend·제작 코드·SHA 기록을 남긴다. 복장의 관절별 부착은 기존 뼈 이름으로 검증한다.
- 게임에서 쓰이는 원본 얼굴과 함께 실제 렌더로 비교한다. Blender 제품 렌더를 인게임 성공 증거로 부르지 않는다.

## 전투·카메라 계약

- 자동 카메라는 실제 가까운 보스와 근처 적만 고려한다. 먼 곳의 보스 등장만으로 영웅을 축소하지 않는다.
- 이동 선행 시점과 락온 편향은 제한하고, 기본 전투 구도에서 영웅의 상체·무기·발밑 방향이 읽혀야 한다.
- 밝은 발밑 외곽과 어두운 받침, 가림 실루엣을 유지한다. 고정된 머리 위 플레이어 표식으로 혼전 시 위치를 재확인한다.
- 명중 확정 때만 접촉 표현, 짧은 정지, 기존 타격 오디오가 발생한다. 지속/간접 피해는 직접 타격과 중복시키지 않는다.
- 여러 입력원을 동시에 사용해도 하나의 release가 다른 입력의 공격/이동을 취소하지 않는다. pause/modal/blur는 모든 해당 입력 소유권을 해제한다.
- reduced motion, low quality와 원래 피해량/스킬/보상 규칙을 보존한다.

## 검증과 승격

retained: 기본 검성, 가로 1280×720/880×400, 첫 층의 일반 전투·혼전·보스. holdout: 다른 영웅, 640×360, 카메라 회전 후 이동, low/reduced motion, pause·복귀·재출격.

필수: typecheck·전체 회귀·production build, 다섯 자산의 바운드/뼈/재질과 애니메이션 검사, 같은 환경 전후 화면, 실제 입력과 전투 종료/재출격, 브라우저 오류 및 GPU 자원 회수, 독립 리뷰. 기기 FPS·멀티터치·오디오 체감·대표님 FELT는 실제 증거 없으면 미검증으로 남긴다.

RSI는 이 제품과 이 브랜치의 개선 루프다. 전체 세션 수집·Supervisor 활성화·모델 가중치 변경을 뜻하지 않는다. 불확실하거나 악화한 후보는 승격하지 않는다. GitHub Actions를 사용하지 않고 로컬 CI/Proof와 기존 배포 잠금·live SHA·rollback 검증을 유지한다.
