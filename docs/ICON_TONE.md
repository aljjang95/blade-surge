# 아이템 아이콘 톤 정리안 (2026-10-28, icon-tone)

대표님 지적: "에셋 아이템 디자인·느낌이 별로." 방어구는 몸에 보이지 않고(`docs/AVATAR_FULLSET.md`), 무기는 강화 단계별로 빛나며(`docs/WEAPON_GLOW.md`), 외형은 아바타 풀셋이 맡는다. 그래서 아이콘 한 장이 장비의 얼굴이다. 이 문서는 조사, 문제, 규칙, 제작 경로, 성공 기준을 한곳에 둔다.

## 1. 아이콘이 어디서 오는가

렌더 경로는 `src/ui/item-presentation.js` `itemVisual()` 하나다. 인벤 칸(`maple-inventory.js`), 장비 칸(`maple-equipment.js`), 상세 시트(`meta.showItem`), 전리품(`ui.js`), 비교(`gear-panel.js`)가 모두 이 함수를 읽는다. 아이템 194종.

## 3. 문제 (심각도 순)

1. **등급 구분이 그림에서 안 된다.** N·S·E 무기는 은회색 직검 실루엣이 거의 같고(`sheet-weapon-armor.png` 위 3줄) 등급은 테두리색에만 있다. L 무기도 N~E와 같은 두께의 검이라 "전설"로 안 읽힌다. 아바타 카드(일러스트 풀컬러)와 같은 화면에 놓이면 더 약해 보인다.
2. **같은 부위 안 스타일 혼재.** 방어구 U 줄이 두 갈래다. 테마 8종은 마스코트 같은 둥근 상자 + 뿔·날개 장식, 뒤따르는 유틸 6종은 얇은 평면 티셔츠 모양 + 파스텔(`sheet-weapon-armor.png` U 줄 오른쪽 `R`). 반지·신발도 같은 U 줄에서 도넛/통통 장화와 가는 금빛 링/직육면체로 갈라진다(`sheet-ring-boots.png`). 한 인벤에 섞이면 다른 게임 에셋처럼 보인다.
3. **실루엣이 작아 안 읽힌다.** 무기는 45° 기울인 가는 검이라 37px 칸에서 선처럼 보이고(`before-bag.png`), 방어구는 정면 상자라 N~E 대부분이 "회색 덩어리"다. 신발 N~S는 납작한 파스텔 한 쌍으로 부위 구분이 약하다.
4. **등급 테두리·글로우 강도 역전.** N 테두리가 `#e6e6e6` 흰색이라 칸에서 가장 밝고, S·E보다 튄다(`before-bag.png`). 광도가 등급 순서와 반대였다. 전역 `.rar-*`(style.css)와 칸 글로우(maple-window.css)가 따로 정의돼 N~U 글로우 세기도 규칙 없이 45% 고정이었다.
5. **강화·아바타 톤과 충돌.** 무기는 강화 단계에서 광륜이 붙는데 아이콘 쪽에는 같은 단계의 빛 언어가 없다(+12 무기도 칸에서는 배지 `+12`만). 아바타 카드는 따뜻한 일러스트 배경이고 장비 아이콘은 차가운 파스텔 블록 렌더라 같은 UI에 놓이면 질감이 다르다(`before-shop-avatar.png`). 조명 방향도 아이콘마다 다르다(왼쪽 위·정면 혼재).
6. (참고) 레거시 `it_*` 116장은 불투명 배경·192²로 규격이 달라 렌더 폴백이 열릴 때 튄다. 현재는 `item-renders`가 우선이라 영향 없음.

## 4. 목표 톤과 규칙

**목표 톤 한 문장:** "따뜻한 한 방향 조명의 통통한 로우폴리 소품이 어두운 남색 칸 위에서 등급색 빛으로 구분되고, 칸에 들어가도 실루엣만으로 부위와 등급 티어가 읽히는 아이콘."

| 항목 | 규칙 |
|---|---|
| 구도 | 정중앙, 칸 안 여백 8%(그림이 칸의 88%), 투명 배경 PNG/WebP 256² 한 장. 무기는 대각 45° 한 방향(손잡이 왼쪽 아래), 방어구·신발·반지는 정면에서 살짝 내려다본 3/4(현행 `itemViewDirection`) |
| 카메라 | 기존 gear-icon-studio와 같은 시점 고정. 아이콘마다 시점 바꾸지 않는다 |
| 조명 | 키라이트 왼쪽 위, 림은 오른쪽 아래에서 등급색 약하게. 그림자는 이미지 안에 굽지 않는다 |
| 채도 | N·S는 낮게(원색 금지), E 이상은 포인트 부위만 등급색. 전체를 파스텔로 칠하지 않는다 |
| 외곽선 | 1~2px 어두운 외곽선(`#0b1424`, 투명도 70%)으로 칸 배경과 분리. 현재는 없다 |
| 틀 | 칸 틀은 CSS가 담당(그림에 틀을 굽지 않는다). 배경은 등급색을 위왼쪽에서 비추는 방사형, 테두리 1px |
| 강화 표시 | 그림은 +0 기준 하나. 강화는 배지(`+N`)와, 무기만 칸 글로우를 `WEAPON_GLOW` 단계색에 맞춰 올린다(그림을 단계별로 새로 굽지 않는다) |
| 등급 구분 | 등급은 ① 테두리·바탕색 ② 글로우 세기 ③ 실루엣 요소 수(N 단순, S 장식 1, E 장식 2, U 테마 오라 요소, L 왕관·날개·후광 같은 큰 요소)로 3중 표시 |

### 등급 테두리·배경 색표 (현행 `RARITY_COLOR` 유지, 칸 규칙 확정)

| 등급 | 테두리 | 바탕 중심(위왼쪽 30%) | 칸 안쪽 글로우 | 바깥 글로우 |
|---|---|---|---|---|
| N | `#9aa3b2`(회색, 기존 흰색에서 낮춤) | 거의 중립 | 없음 | 없음 |
| S | `#5ce07a` | 초록 30% 혼합 | 6px · 30% | 없음 |
| E | `#4cc3ff` | 파랑 30% | 8px · 42% | 없음 |
| U | `#c07cff` | 보라 30% | 10px · 55% | 없음 |
| L | `#ff9a2e` | 주황 30% | 12px · 70% | 6px · 45% |

(이름 글자색 `RARITY_COLOR.N`은 `#e6e6e6` 그대로 둔다. 글자는 밝은 쪽이 읽힘이 좋다.)

### 종류별 실루엣 규칙

- **무기:** 대각 한 방향, 검날 폭은 칸 폭의 18% 이상(지금은 약 8~10%). 날 윤곽이 등급 티어를 말한다: N 직선, S 홈·곡선 1, E 장식 2, U 테마 형태(불꽃·얼음 결정·번개), L 큰 날밑·날개·후광. 영웅 무기 형태(활·지팡이·쌍단검)는 `forms/`로 같은 규칙.
- **방어구:** 정면 흉갑 하나, 어깨 폭이 몸통 폭의 120%가 되게 어깨 장식을 넣어 "갑옷"으로 읽히게 한다. 상자형(현행 N~E 흉갑 덩어리)은 목 구멍·허리 띠로 의복 방향을 분명히. 한 부위 안에서 U 테마(마스코트형)와 유틸(평면 티셔츠형)을 같은 문법으로 통일한다.
- **반지:** 링 + 보석 한 점이 항상 위, 보석이 등급 색의 주인공. 링은 두께를 일정하게(U 유틸의 가는 링을 굵게).
- **신발:** 한 쌍이 옆으로 나란히, 발목이 칸 높이의 절반 이상. 납작한 슬리퍼 형태(N~S)를 부츠 목 높이로 키운다.

## 5. 코드로 바로 고친 것 (이번 변경, `src/ui/maple-window.css`만)

런타임 렌더 아이콘은 없고 틀이 CSS이므로 틀 쪽 3가지를 고쳤다.
1. N 테두리를 흰색 → 회색(`#9aa3b2`), 글로우 제거. 글로우를 N<S<E<U<L 순으로 단계화(위 표).
2. 칸 바탕에 등급색을 위왼쪽에서 비추는 방사형 그라데이션을 깔아 등급과 조명 방향을 통일(기존은 위에서 아래 단색 그라데이션).
3. 장비 그림 크기를 칸의 80% → 88%로(좁은 칸에서 무기 읽힘 개선).
전후: `before-bag.png` ↔ `after-bag.png`(844×390). 상점·밀도 CSS(BM·UI 레인)는 건드리지 않았다.

코드로 더 할 수 있는 후보(이번에 하지 않음): 전역 `.rar-*`(style.css)와 칸 규칙 통합, 무기 칸 글로우를 강화 단계색과 연동(WEAPON_GLOW 토큰 필요), 레거시 `it_*` 정리.

## 6. 우선순위 (많이 보이는 것부터)

1. 무기 N~E 24종 + 방어구 N~E 24종(인벤·전리품에서 가장 자주 보임)
2. L 전 부위 25종(얼굴 장비, 등급 차이가 가장 커야 함)
3. U 방어구·반지·신발의 스타일 혼재 해소(테마 8종과 유틸 6종 한 문법으로)
4. 반지·신발 N~E
5. 레거시 `it_*`·`armory-v1/arm_*` 정리·재규격

## 7. 제작 경로

- 게임 아트는 Codex CLI 이미지 생성이 원칙(대표님 규칙). 현재 OpenCodex 풀 한도로 막혀 있다. **한도 회복 후 생성** 단계: 부위당 N·E·L 3장 시안 → 대표님 시트 확인 → 선택 규칙으로 나머지 일괄. 모델(3D 렌더)을 새로 만드는 경우는 기존 gear-icon-studio 카메라·조명을 위 규칙으로 갱신해 다시 굽는다(이쪽은 코드 작업이라 지금 가능, 모델 형태 수정이 필요한 것만 한도 회복 후).
- 지금 가능(코드·렌더 스튜디오 설정): 조명 방향·림 색·외곽선·여백을 gear-icon-studio에 반영해 전 아이콘 재렌더, CSS 틀 통일, 사이즈 규격 정리.
- 한도 회복 후: 무기·방어구 실루엣 요소 추가(조각 형태 변경), L 전설 장식(후광·날개), 아바타 카드와 같은 질감의 풀컬러 일러스트화 여부 결정.

## 8. 성공 기준 (시트로 판정)

같은 방식으로 `sheet-weapon-armor.png`·`sheet-ring-boots.png`를 다시 만들어 비교한다.
1. 30% 크기로 줄여도 N·E·L 행이 색 없이 실루엣만으로 구분된다(눈 가늠 3인 중 2인 이상 일치).
2. 한 부위 한 줄 안에서 스타일이 하나(조명 방향·외곽선·채도 같음). U 줄의 두 갈래가 없어진다.
3. 844×390 인벤 칸(37~40px)에서 무기 날 폭이 3px 이상이고 부위 4종이 흑백으로도 구분된다.
4. 광도가 N<S<E<U<L 순(바탕·테두리·글로우 합).
5. 상점 아바타 탭과 같은 화면에 놓았을 때 질감 차이가 대표님이 "튄다"고 하지 않는다(대표님 확인).
6. `bun run check` 통과, 다른 레인 파일 변경 없음.
