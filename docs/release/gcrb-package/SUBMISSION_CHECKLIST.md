# 대표님이 낼 것 (순서)

1. **GCRB 회원가입·로그인**(gcrb.or.kr, 업체 회원) — 약관 동의, 담당자 **주민번호 실명확인·휴대폰 인증**은 대표님이 직접. 클라우드 데스크톱(`cloud-desktop link`)에서 하면 이후 입력은 에이전트가 대행.
2. **중소기업 감면 확인**: 상단 [중소기업환급신청]에 상시고용인수 확인 서류 1부 + 매출액 확인 서류 1부(감면 후 수수료 1/2, 확인 1년 유효).
3. **사본 준비**: 사업자등록증 · 게임제작업 등록증 · 게임배급업 등록증(보유분, PDF/이미지).
4. **수수료 납부**: 5단계 계산 화면 금액 확인 → 대표님이 입금(예상 72만~108만 원, 감면 후, 부가세 포함) → 입금증 업로드.
5. **최종 신청완료 버튼**(접수대기로 바뀜). 처리 15일 이내.
6. 결정서(등급분류번호) 수령 → 에이전트에 전달 → 표시 반영(`src/data/game-rating.js`)·배포·결제 게이트 해제.
