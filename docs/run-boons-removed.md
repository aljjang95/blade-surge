# 출격 중 각인 제거 (2026-10-24 대표님)

대표님 피드백: "중간에 각인 뜨는 게 게임의 흐름을 방해하는 느낌이라 매우 별로다", "각인은 요즘 겜의 슬롭 느낌이라 빼는 게 맞다. 대신 강화 시스템에 룬 박기, 또는 유료 다이아로 굴리는 1회용 각인(주사위·슬롯머신 연출)을 플레이 전에 골라서 들어가는 구조."

## 지금 동작

- 출격 시작·방 클리어·3·6번째 보상·마지막 접근 어디서도 각인 보상, 선택 창, 일시정지, '각인 +N' 대기 뱃지가 없다. 수동·AUTO 동일하다.
- 길 위의 만남(한 판 1번, 심층·파티·AI 결투 제외)은 전투를 멈추지 않는다. 저장된 선택이 있으면 재방문 회복(회복 선택 12% / 명성 선택 6%), 없으면 첫 선택지(명성)로 기록하고 화면 가장자리 알림(`ui.toast`, 상단 알림 띠)만 띄운다. 저장 실패는 빨간 알림만 남기고 그 판에서는 다시 묻지 않는다. 기록 탭에서 결과를 읽을 수 있다.
- HUD '각인' 버튼은 출격 전에 정한 각인이 있을 때만 보인다. 사용자가 직접 연 현황 창만 전투를 멈춘다.
- 마을 '성장 · 숙련'(이전 '성장 · 각인') 준비 탭에 '각인 · 준비 중' 안내를 둔다.
- 명성(처치 5회마다 +1)·발견·의뢰·숙련·서약·선택 기록 등 각인 외 영구 성장은 그대로다.

## 남겨 둔 엔진과 진입점

- 12각인·4가문·6조합·maxRank 3 데이터(`src/data/masterworks.js`), 효과 합산 `boonEffects`·`previewBoon`·`boonChoices`(`src/game/masterworks-core.js`), 전투 적용 `applyBuildStats`(`masterworks-combat.js`)는 그대로다.
- 진입점: `battle.setPreRunBoons(ids)` → 다음 개인 출격 `start()`에서 한 번 소비해 `run.picked`·`run.preRunBoons`에 넣고 `applyBuild()`로 랭크·조합을 계산한다. 정리는 순수 함수 `seedRunBoons(ids)`(알 수 없는 id 제거, 같은 각인 maxRank까지, 순서 보존). 파티·AI 결투는 받지 않고 버린다.
- 현재 호출자는 없다(빈 목록 = 각인 없음). 대체 레인(장비 강화의 룬, 출격 전 1회용 각인 뽑기)이 이 진입점을 쓴다. 뽑기는 유료 재화 결제 검증이 끝나기 전에는 성공 표시·지급을 만들지 않는다.

## 밸런스

각인이 주던 출격 중 보정(공격 최대 약 +20%대·체력·쿨감 등)이 빠졌다. `bun run sim:90d`는 원래 masterworks(숙련·각인)를 계산에 넣지 않으므로 90일 곡선 수치는 바뀌지 않는다. 실제 체감 난도 하락분은 룬 레인이 메울 예정이며 이 변경에서 적 수치는 조정하지 않았다.
