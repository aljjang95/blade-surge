## 남은 범위

- 기존 generic 공격의 원점이 외부 넉백으로 이동할 때 예고와 판정 위치가 어긋날 가능성은 남아 있다. 이번 정지는 잔여 추격 속도와 몰이의 첫 프레임을 수리하며 강제 넉백 자체를 없애지 않는다.
- 마무리 강화 창은 기존대로 발동 시 소비한다. 빗나감에는 소비하지 않는 설계로 바꾸려면 실제 유효 명중 토큰과 투사체 생명주기를 별도 변경해야 한다.
- 파티·실기기 멀티터치·발열·GPU FPS·청감, 5영웅 자연 수동 완주와 장기 재미는 이 자동 검증만으로 승인하지 않는다.
- 운영 `blade.tllhouse.com` 배포는 기존 `tools/deploy.mjs` 및 D1 소유 잠금을 유지한다. 현재 클라우드 런타임에는 승인된 Cloudflare 환경변수와 vault 실행 경로가 없다. GitHub 연결 자체를 배포 인증으로 취급하지 않는다.
