# 블레이드 서지 콘텐츠 확장 · 2026-09-09

## 제품 기준

대표님 요청에 따라 현재 서비스의 casual-v2 캐릭터 정체성과 전투 리그를 유지한다. GitHub main에서 2026-09-09 확인한 `068e1fc2344fa62d8b2fb899d06bce340221691d`(PR11, 다섯 지역 캠페인/로비 카메라)를 기준으로 분기했다. 실제 라이브 로비에서 둥근 왕관, 민트 의상, KayKit 얼굴과 전당을 확인했다. `/version.json` IAB 열람은 ERR_BLOCKED_BY_CLIENT로 실패했으므로 실제 배포 SHA와 GitHub HEAD의 동일성은 별도 미확인이다.

AI3D 제작 브랜치 `codex/blade-ai3d-20260909`의 `f71f39a54cb0780d5c9e8f05d7aeb01fe18e8456`와 원본 작업물은 다른 게임의 재사용 자산으로 보존한다. 이 확장 브랜치에는 해당 변경을 병합하지 않는다. 기존 canonical checkout의 미커밋 변경도 보존한다. 이미 서비스에 포함된 `public/models/tll/*-casual-v2.glb`는 현행 정체성의 일부이므로 제거하지 않는다.

## 연결된 콘텐츠

- 기존 5지역/50스테이지 캠페인을 유지하며 세 개의 목적형 재료 던전을 추가한다.
- 획득한 재료와 전리품으로 장비 세트와 전투 소모품을 제작한다. 새 재료3종은 강화석·상급 강화석·전설 강화석으로 정련해 실제 장비 강화에도 사용한다.
- 원정 레벨/경험치와 순차 퀘스트로 수호 기사·바람 추적자 전직을 해금한다.
- 결투장은 로컬 AI 대전이다. 실시간 다른 플레이어 매칭이나 서버 랭킹으로 표시하지 않는다.
- 전투·퀘스트·제작 보상은 기존 세이브 안에 저장하고 중복 지급을 방지한다.

## 실행과 제작

기술: Three.js r170/WebGL2, React19, React Three Fiber9, Vite6. packageManager는 bun@1.4.2이며 실제 Bun1.4.2 실행으로 테스트·타입검사를 통과했다. 최초1.3.13 관찰과 이후1.4.2 실제 경로는 docs/runtime-bun.md에 구분했다.

현행 CC0 KayKit/Quaternius/Kenney 원본과 출처를 보존한다. GUI 생성 이미지와 Flow 생성 미디어는 오픈소스 자산과 분리해 출처·해시·실제 파일 검증을 기록한다. 새 결제·운영 배포는 별도 승인 경계다.

## 검증 완료 조건

실제 IAB에서 로비→원정→던전/결투→결과→제작/퀘스트 흐름을 실행하고, 입력·휴대폰 폭 레이아웃·오류·세이브 복구·보상 중복·모드 재진입을 확인한다. 코드 검사·이미지 캡처와 실기기 오디오/발열/체감은 구분한다.

## 게임 안에서 관리하는 구조

별도 전체 화면 원정 페이지를 제거했다. 기존 게임 하단의 모험 메뉴에서 5지역 캠페인과 새 던전·결투장·공방·전직·퀘스트를 관리하며 재화 바와 게임 탐색 메뉴를 유지한다. 영웅 메뉴의 3D 착용 모습은 실제 장비와 동일한 외형 함수를 사용한다. 기존 맵5종은 이전 작업본과 동일한 파일로 확인해 그대로 재사용한다. 캐주얼 캐릭터 얼굴과 몸은 유지하며 방어구16종/원정3세트의 관절 부착 의상을 추가했다.

유리 정원 Flow 영상은 첫 입장 때 세션당 한 번 무음으로 재생하며, 건너뛰기·다시 보기를 지원한다. 모션 감소 설정에서는 자동 재생을 생략하고 재생 실패가 전투를 막지 않는다.
