## 규칙 (`src/game/dungeon-route.js`)
1. **보스 공개**: 일반 캠페인 던전은 입장 즉시 미니맵·전체 지도에 보스 방 위치·크기·♜가 보인다(`world.bossRevealed`, 방의 `discovered`는 그대로). 현재 방에서 보스 방까지 최단 경로가 노란 점선으로 보인다(지도 창의 '경로 표시' 버튼으로 끄고 켬, 기기 저장).
2. **보스 문 개방**: 시작 방에서 *정화한 방만 밟고* 보스 방 문 앞까지 닿으면 봉인이 풀린다(`bossApproachOpen`). 최소는 최단 경로 위 방(관문마다 2~5곳). 경로는 '새로 정화해야 하는 방 수'가 가장 적은 길(0-1 BFS)이라 이미 돈 방을 우선한다.
3. **남은 방은 선택**: 길로 연 봉인은 포탈을 열지 않는다(보스 문이 바로 옆). 대신 가장자리 토스트로 "남은 구역 n곳은 선택 — 전부 정화하면 보너스"를 띄우고, 전투력이 권장 미만이면 위험 안내를 한 번 더 띄운다. 나중에 마지막 방을 정화하면 예전처럼 보스방 포탈이 한 번 열린다.
4. **동선 선택(AUTO)**: 지도 창에서 '전부 사냥'(기본) / '보스 직행'. 전부 사냥 AUTO는 봉인이 먼저 풀려도 남은 구역을 다 돈 뒤 보스로 간다(기존 AUTO와 같은 순서·결과). 보스 직행 AUTO는 경로 위 첫 미정화 방 → 보스. 선택은 기기 `localStorage`(`bs.dungeonRoute.v1`)에 남는다.
5. **적용 범위**: 캠페인 던전만. 무한의 성·원정·파티·필드·전술 원정(conquest)·장치 목표 관문(route-objectives: 밸브·별자리·종 등, `canUnseal`이 전부 정화를 요구)은 기존 계약(전부 정화)을 그대로 둔다.

## 보상 차이 (서버 정산 변경 없음)
전부 정화하면 기존 그대로: 전체 정화 보너스(경험치 +50%·골드 +40%·조각·정예 장비 1, `completeStage` fullClear — 서버 `serverRating`이 정화 방 수로 같은 판정), 별 3(탐색 80% 초과 → 소탕 자격), 방마다 필드 드랍·보물방 상자. 직행은 이것들이 줄어드는 대신 시간이 짧다. 첫 클리어·스토리·처치 원장(`docs/SERVER_AUTHORITY_GATES.md`)·업적·의뢰의 조건은 바꾸지 않았다.
