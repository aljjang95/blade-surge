# 장비 외형·아바타 (2026-10-23, gogo-chunk blade-gear#g1)

대표님 요청: "장비에 따라 외형 바뀌는 것과 아바타 개념도 추가되면 좋겠어." 기존 자산과 코드로 할 수 있는 부분을 먼저 끝내고, 새 아트가 필요한 부분은 아트 레인 요청 목록으로 남긴다.

## 1. 감사 (변경 전, 915x412 폰 가로, `tools/gear-look-audit.mjs`)

영웅 화면 3D 미리보기(`src/expansion/wardrobe.jsx`)에서 기사 기준으로 장비를 하나씩 바꿔 찍었다.

| 바꾼 것 | 보이는 변화 |
|---|---|
| 방어구 N·S | 없음. 맨몸과 같은 1단계 몸체(`hero_knight_t1`) |
| 방어구 E·U | 2단계 몸체(`_t2`)로 교체됨. 분명히 보임 |
| 방어구 L | 3단계 몸체(`_t3`)로 교체됨. 분명히 보임 |
| 무기 N→E→L | 대장간 형태(검→대검)와 등급색이 바뀜. 보임 |
| 반지·신발 | 어떤 등급이든 변화 없음 |
| 아바타 | 상점에서 보석 구매 후 착용하면 몸 전체가 바뀜. 사기 전에는 볼 방법 없음 |
| 미리보기 조작 | 버튼 3개(↶ 정면 ↷)뿐. 드래그·확대 없음. 캐릭터가 패널 높이의 약 40%로 작음 |

원인: 절차형 갑옷(`armor-appearance.js`)과 병기고 장식(`armory-assets.js`)은 옛 KayKit 몸체(`casual-v2`)나 병기고 아이템에만 붙는다. 지금 영웅은 모두 Tripo 라이브러리 몸체라서 방어구 단계 교체와 무기 외에는 아무것도 안 보였다.

## 2. 설계 (모바일 핵앤슬래시 상위작 기준)

- 장착 즉시 외형 반영: 무기 = 형태와 등급 발광, 방어구 = 몸체 단계(1·2·3) + 등급 윤곽광, 신발 = 다리·발 윤곽광, 반지 = 왼팔뚝·왼손 윤곽광. 강화 수치에 따라 윤곽광이 더 밝아지고, 기존 +10/+15/+20 오라는 그대로 둔다.
- 등급 읽기: N 없음 → S 초록 → E 파랑 → U 보라 → L 주황. 미리보기 발밑 링은 장착 장비 중 최고 등급색이다.
- 아바타: 외형 덮어쓰기 전용이며 성능 영향은 없다(기존 계약). 흐름은 미리보기(시착, 저장 변경 없음) → 보석 구매(기존 확인창) → 착용·해제 → **장비 외형 표시 토글**(아바타를 입은 채로 장비 외형을 보여 줌, 영웅별 저장).
- 3D 미리보기: 드래그로 회전, 핀치·휠로 1.0~2.6배 확대, 상반신·전신 버튼. 같은 영웅이면 장비를 바꿔도 각도와 배율을 유지한다.
- 결제: 아바타는 기존처럼 게임 안 보석으로만 산다. 실제 결제 흐름(`docs/BM_DESIGN.md`)은 바꾸지 않았다.

## 3. 구현

| 파일 | 내용 |
|---|---|
| `src/game/gear-accents.js` | 라이브러리 몸체 재질에 등급 윤곽광(프레넬) 훅을 재질마다 한 번만 건다. 부위는 스킨 가중치(Leg/Foot/ToeBase, LeftForeArm/LeftHand)로 나눈다. 장비가 바뀌면 유니폼 값만 바꾼다. 재컴파일·드로우콜·정점 추가와 프레임 할당이 없다 |
| `src/game/look.js` | 아바타가 아닐 때 방어구·반지·신발 윤곽광을 적용한다 |
| `src/game/economy.js`, `save-base.js` | `displayAvatar(heroId)`, `setShowGear(heroId, on)`, 저장 `avatars.showGear` 정규화 |
| 표시 경로 | 로비 쇼케이스(`main.js`), 전투(`battle-base.js`), 파티 표시(`party/session.js`), 초상화(`hero-portraits.js`)는 `displayAvatar`를 쓴다 |
| `src/expansion/wardrobe.jsx` | 드래그·핀치·휠·상반신 조작, `show(id, { previewAvatarId, previewLabel })` 시착 API, 발밑 등급 링, 캡션 |
| `src/ui/gear-panel.js`, `src/style.css` | 아바타 줄: 미리보기·구매 / 미리보기·착용 / 장비 외형 켬·끔·해제 |

처음에는 몸 표면에 띠 조각(허리띠·발목 띠·팔찌)을 덧붙이는 방식을 시험했다. Tripo 갑옷의 망토·스커트에 가려 허리띠가 보이지 않았고, 발목 띠는 덩어리처럼 보여서 버렸다. 윤곽광 방식은 원본 실루엣을 그대로 둔다.

## 4. 검증

- `bun run check` 통과.
- 단위 테스트: `test/gear-accents.test.ts`, `test/avatars.test.ts`(showGear), `test/wardrobe-controls.test.ts`.
- 브라우저 확인(Playwright, 915x412, SwiftShader): 이 브라우저는 GPU가 없는 소프트웨어 렌더라서 색과 구도가 보이는지만 확인했다. 확인한 장면은 기사의 N~L 방어구, 무기, 전체 L, 상반신 확대, 미보유 아바타 시착(보유 목록 변화 없음 확인), 장비 외형 켬/끔, 전투 화면에서 전체 L의 윤곽광이다. 콘솔 오류는 기존 404 2건만 있다.
- 남은 게이트: 실기기(S26·Tab S7+)에서 터치 드래그·핀치 조작감과 블룸 아래 윤곽광 밝기.

## 5. 아트 레인 요청 (Tripo 재제작 담당 [gogo-chunk:blade-art#t1]에게 전달)

코드로는 등급색을 다르게 보이게 할 수 있지만 실루엣을 바꿀 수는 없다. 상위작 수준의 단계별 실루엣 차이를 내려면 아래 아트가 필요하다. 모두 기존 `hero_<id>_t1` Mixamo 골격에 메시만 다시 묶는다(t2·t3와 같은 방식).

1. 5영웅 × S등급 몸체 `hero_<id>_t1s`: 지금은 N과 S가 같은 몸체를 쓴다. 천·가죽 위에 철판 몇 장을 덧댄 수준.
2. 5영웅 × U등급 몸체 `hero_<id>_t2u`: 지금은 E와 U가 같은 몸체를 쓴다. 테마 세트(폭풍·피·중력·불사조·서리·역병)의 색과 장식.
3. 신발 등급 부츠 파츠: 5영웅 공용, 발 본 스킨, N/E/L 3단계. 발밑 실루엣 차이를 내기 위한 것.
4. 아바타 2차분: 영웅당 1종씩 + 상점 카드용 아바타 초상(지금은 영웅 초상을 재사용 중).

`asset-library/manifest.json`에 `armorTier`를 1.5처럼 소수로 넣으면 단계 선택(`heroTierCandidates`)도 고쳐야 한다. 아트가 들어올 때 이 레인이나 후속 레인에서 맞춘다.
