# 출격 준비 — 모험 수첩

2026-10-08 승인 시안 `work/design/departure-journal-20261008/departure-journal-concept-v1.png`를 기존 출격 준비창에 적용한다. 모바일 시안의 아이보리 종이·비취색 선택/출격 버튼·정원 그림·보상 아이콘·영웅/물약·접힌 목표/서약 순서를 유지한다. 가로 화면은 보상과 준비를 두 열로 배치하고 작은 화면은 본문만 스크롤하며 출격/복귀 버튼은 고정한다.

시안의 임시 은발 영웅 대신 승인된 실제 영웅 portrait를 사용한다. 모든 지역과 기본/심층 조건, 에너지, 기본/첫 클리어 보상, 프론티어, 개인 목표, U/I/O 물약 재고와 효과는 `citadelPreparation`에서 읽는다. 목표·지역 행동·전술·프론티어·개인 목표는 목표/규칙 펼쳐보기에, 서약 변경과 합산/미리보기/저장 범위는 서약 펼쳐보기에 유지한다. 접근 오류와 저장 알림은 접히지 않는 하단에 표시한다.

입장은 기존 `startExpedition('dungeon', id, { depth })`, 서약 저장은 기존 MasterworksService만 실행한다. 미리보기와 취소는 에너지/물약/보상을 변경하지 않는다. 키보드 포커스 순환은 네이티브 summary도 포함한다. 실제 영웅·아이콘·기존 지역 그림을 보존하며 유리 정원의 기본 준비 그림에만 새 원화를 사용한다.

새 배경 2개는 built-in imagegen 자체 생성물이며 원본은 로컬 design 폴더에 보존한다. 배포용 WebP의 크기·해시·생성 설명은 `public/img/departure-journal/provenance.json`에 기록한다. 기존 하네스 `tools/garden-ui-qa.mjs`에 보상·본문 펼침·서약 저장/원복·심층 잠금·하단 가시성 검증을 추가했다. 실제 브라우저 결과는 해당 후보의 별도 영수증을 따른다. 물리 Android·유료 동행·결제 검증을 뜻하지 않는다.
