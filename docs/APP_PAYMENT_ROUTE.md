# 앱 안 결제 경로 조사와 추천 (Google Play 한국 대체결제 · 원스토어 외부결제)

확인 날짜: 2026-10-30. 근거는 공식 문서만 쓴다. 확인하지 못한 사실은 **미확인**으로 표시한다. 이 문서는 조사·추천이며 콘솔 신청·코드·플래그 변경은 하지 않았다.

## 1. 결론 (추천안 한 줄)

**앱 안 결제는 채널별 스토어 인앱 결제(Play는 Google Play Billing, 원스토어는 원스토어 IAP)를 유지한다.** KG이니시스(포트원) 웹 결제는 앱 밖(웹)에서만 두고, 앱 안에서 쓰는 대체결제·외부결제는 웹 상품이 열리고 매출이 생긴 뒤에 재검토한다.

## 2. 지금 상태 (저장소 기준)

- 상품 정본 `src/shared/iap-catalog.js`: Play에서 켜진 상품은 광고 제거·스타터·월정액·시즌 패스. 웹 채널 상품은 `monthly_pass_v1`(`gate:'web-billing'`)이 닫혀 있어 **지금 웹으로 팔 수 있는 상품이 없다**. 영웅 직접 판매는 `gacha-only`로 닫힘.
- 채널은 빌드 시 고정(`src/platform/store-channel.js`: web / googleplay / onestore / apps-in-toss, 상품 ID 맵 포함).
- 웹 결제는 KG이니시스 업종 사전 질의·MID 신청 전이다(`docs/KG_APPLICATION.md`, `docs/PAYMENT_COMPLIANCE.md` 2.4·4장).
- Play는 내부 트랙, 게임물 등급은 Play·원스토어 자체등급분류.

## 3. Google Play 한국 대체결제

출처: [한국 결제 요건 변경](https://support.google.com/googleplay/android-developer/answer/11222040?hl=en) · [사용자 선택 결제 이해](https://support.google.com/googleplay/android-developer/answer/13821247?hl=en) · [서비스 수수료](https://support.google.com/googleplay/android-developer/answer/112622?hl=en) · [대체결제 API 요건](https://developer.android.com/google/play/billing/alternative)

| 항목 | 확인된 내용 |
|---|---|
| 게임 적용 | 가능. 한국은 모바일·태블릿의 게임과 비게임 앱 모두 대상. |
| 프로그램 | 한국은 독자 프로그램(사용자 선택 결제 = Play 결제와 대체결제 병행). 한 지역에서는 한 프로그램만 등록. 한국에 "alternative billing only(Play 결제 없이)" 프로그램이 있는지는 **미확인**(공식 목록상 해당 변형은 EEA에 한정되어 보임). |
| 수수료 | 대체결제로 결제된 거래는 Play 서비스 수수료에서 **4%p 감면**. 기준 수수료는 연 매출 첫 US$1M까지 15%, 초과분 30%, 자동갱신 구독 15%. 예: 15%는 11%. 감면 후에도 Google에 내는 몫이 남는다. 2026-06-30 이후 개정 수수료 체계가 한국에 어떻게 적용되는지는 **미확인**. |
| 등록 절차 | Play Console → 계정 관리 → 앱 설정 → 수익 창출 설정 → 대체 결제에서 약관 동의·결제 프로필 등 온보딩 → Google 확인 메일 후 앱별 등록(앱 단위 옵트인). PCI DSS 준수 인증과 부정 거래 신고 수단 제공이 요건. 결제 수단 로고 이미지(192×20dp PNG, 최대 카드 5개)를 콘솔에 올린다. |
| 기술 요건 | 대체결제 API 필수(2023-08-02부터). 사용자 선택은 Play Billing Library 5.2 이상. 앱이 외부 거래 토큰을 받아 Google에 전달하고, 서버가 외부 거래 ID로 Play Developer API에 보고. 신규·업데이트는 2026-08-31까지 Billing Library 8 이상(연장 2026-11-01까지). |
| 보고 의무 | 한국 사용자의 승인된 모든 거래를 **24시간 이내** API로 보고. 수동 월 보고는 2023-08-02에 종료. |
| 사용자 안내 화면 | 클라이언트 API를 쓰면 선택 화면은 Google Play가 그린다(별도 UX 지침 준수 불필요). 앱 안 대체결제 홍보와 임베디드 웹뷰 아웃링크 결제도 허용(같은 연동 요건). 가격은 Play 결제와 달라도 된다. |
| 환불·취소 | 대체결제 거래의 환불·정산은 우리 책임(Play 환불 API로 처리 안 됨). 구체 의무 문구는 **미확인**. |

## 4. 원스토어 외부결제(제3자 결제)

출처: [원스토어 개발자 문서 — 서비스 이용료(대한민국)](https://onestore-dev.gitbook.io/dev/docs/payment/service_fee/korea) · 참고(비공식, 연동 절차 사례): [부트페이 원스토어 외부결제](https://docs.bootpay.co.kr/v1/online/onestore)

- 허용: 공식 문서가 "원스토어 In-app 결제수단이 아닌 외부결제"의 이용료율을 규정하므로 허용 구조로 보인다.
- 수수료: 외부결제 **5%**(VAT 포함). 기본 인앱은 20%, 구독(SDK V21+ 정기결제)은 10%. 외부결제는 중소 개발자 감면(월 US$5,000 이하 50%)의 대상·기준 거래액 산정에서 **제외**.
- 의무: 원스토어가 지정한 방식으로 외부결제 판매 내역 전송, 서비스 이용료를 판매월 익월 25일까지 지정 가상계좌로 송금.
- 절차: 개발자센터에서 앱별 외부결제 키 발급(경로는 비공식 자료 기준, 공식 화면 **미확인**). 게임 앱 제한·앱 안 외부결제 안내 화면 요건·사전 승인 필요 여부는 **미확인**.
- 참고: 원스토어는 중소 개발자에게 기본 20%의 절반(10%)이 적용되는 구간이 있어, 소규모 매출에서는 원스토어 인앱(10%)이 외부결제 5% + PG 수수료(약 3~4%)와 비슷해질 수 있다(PG 수수료율은 KG 협의 전이라 **미확인**).

## 5. 비교

| 선택지 | 실효 수수료(대략) | 코드·운영 부담 | 지금 가능? |
|---|---|---|---|
| A. 스토어 인앱 유지 (추천) | Play 15%(구독 15%), 원스토어 10~20% | 없음(이미 구현·내부 트랙) | 예 |
| B. Play 사용자 선택 결제 + KG | 11% + PG 약 3~4% = 약 14~15% | 크다(Billing Library 업그레이드, 외부 거래 토큰, 24h 보고, 환불 직접, KG 계약) | KG 미계약이라 아니오 |
| C. 원스토어 외부결제 + KG | 5% + PG 약 3~4% | 중간(판매 내역 전송, 익월 송금, 환불 직접) | KG 미계약이라 아니오 |
| D. 웹 결제만(앱 밖) | PG 약 3~4% | 웹 상품 개방 필요 | 상품이 닫혀 있어 아니오 |

B는 감면이 4%p인데 PG 수수료와 환불·보고 운영을 우리가 지므로 순이익이 거의 없다. C가 가장 싸지만 원스토어는 소규모 구간에서 인앱 감면이 있고, 둘 다 KG 승인이 선행이다.

## 6. 추천과 이유

**A를 고른다.** 이유: (1) 앱 안에서 팔 상품은 Play 인앱으로 이미 서버 검증·환불 역분개까지 구현됐고 내부 트랙에서 E2E를 앞두고 있다. (2) KG 업종 사전 질의·MID 신청이 끝나기 전에는 대체결제를 켜도 쓸 PG가 없다. (3) 한국 대체결제는 4%p 감면뿐이고 PG 수수료·환불·24시간 보고 부담이 더 크다. (4) 웹 상품이 지금 하나도 열려 있지 않아 앱 안에서 웹으로 유도할 대상이 없다. (5) 정책 위반 위험을 피한다: 가입 없이 앱 안에서 외부 결제로 유도하지 않는다(`PAYMENT_COMPLIANCE.md` 2.4).

다른 선택지는 5장 B·C·D. 재검토 조건: 월 매출이 커져 4%p(또는 원스토어 15%p) 절감이 PG·운영 비용을 넘을 때, 또는 KG 승인 후 웹 B형 상품이 열릴 때. 그때는 C(원스토어 외부결제)를 먼저, 그다음 B를 본다.

### 필요한 코드 변경 범위(대략)

- 추천안 A: **없음**. 앱 안에서 웹 결제 링크·안내 문구를 넣지 않는다는 원칙만 유지.
- 나중에 B를 하면: Play Billing Library 업그레이드(사용자 선택은 5.2+, 신규·업데이트는 8+ 요구 일정 확인), 외부 거래 토큰 수신, 서버의 Play Developer API 외부 거래 보고(24시간), 포트원 결제 취소 API 연동, 상점 채널 분기(`store-channel.js`) — 중간~큼.
- 나중에 C를 하면: 원스토어 외부결제 키, 판매 내역 전송 잡, 월 정산 송금 절차, 환불 처리 — 중간.

### 남은 대표님 할 일

- 지금(A) 필요한 새 일은 없다. KG이니시스 업종 사전 질의 발송과 가맹 신청은 기존 계획대로(`docs/KG_APPLICATION.md`).
- 미확인 항목 확정이 필요해지면(재검토 시점): Play Console의 대체 결제 설정 화면 확인, 원스토어 개발자센터에서 외부결제 키 발급 화면·게임 앱 조건 확인(둘 다 로그인 필요, 집행 전 대표님 확인).

## 7. 미확인 요약 (2026-10-30)

- 한국에 "대체결제 단독(Play 결제 없음)" 프로그램이 있는지.
- 2026-06-30 이후 개정 수수료 체계의 한국 적용.
- 대체결제 거래의 환불·분쟁 의무 문구.
- 원스토어 외부결제 키 발급 화면, 게임 앱 제한, 앱 안 안내 화면 요건.
- KG이니시스(포트원) 실제 PG 수수료율과 게임 업종 승인.
