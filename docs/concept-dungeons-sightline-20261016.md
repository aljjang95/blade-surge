# 전투 벽 시선 확보 · 컨셉 신규 던전 2곳 (2026-10-16)

## 벽 시선 확보 (`src/engine/battle-occlusion.js`)

이전 cutaway는 카메라 수평 방향에 수직인 무한 평면 하나로 층 전체의 카메라 쪽 벽을 높이 0.35m에서 잘랐다. 측면 경계가 없어서 영웅이 움직이면 단면이 옆벽을 따라 미끄러졌다. 벽은 단면 재질이라 속 빈 껍데기 단면이 보였고, 카메라 쪽 벽은 납작한 띠가 되었다. 그림자 깊이 재질도 같은 clippingPlanes를 상속해 그림자가 함께 깜빡였다. 벽 메시와 인스턴스 스케일(4×4×1, 균등)은 정상이었다.

지금은 `BattleOcclusion`(같은 API)이 시선 원뿔 디더를 쓴다.

- 카메라에서 영웅 몸통(높이 1m)으로 향하는 원뿔 안에 있고, 수평으로 영웅보다 카메라 쪽에 있는 조각만 화면 고정 4×4 Bayer 디더로 비운다. 원뿔은 모바일 가로 화면에 맞춰 옆으로 1.45배 넓다.
- 영웅 몸을 실제로 덮는 조각은 짧은 앞뒤 램프(1m)로 바로 비운다. 영웅 곁 옆벽은 긴 램프(3.2m)로 천천히 비워, 벽을 따라 걸을 때 비움 경계가 튀지 않는다.
- 바닥 0.45m 아래 경계는 남기고 1.35m까지 점진적으로 비운다. 원뿔 밖 벽은 원래 높이와 실루엣을 유지한다.
- 카메라 앞 1.4~4.4m의 면은 비운다. 줌 140·피치 -18에서 카메라 높이가 벽보다 낮아질 때 근접 단면을 숨기기 위해서다.
- `onBeforeCompile` 체인과 캐시 키(`|battle-sightline-v2`)를 쓴다. 기존 석재 디테일 훅을 보존하고, 다른 시선 객체가 다시 묶어도 셰이더 삽입은 한 번만 일어난다. 재질은 불투명 상태로 두고 clippingPlanes는 쓰지 않는다. 그림자는 원본 깊이 재질을 쓴다.
- 광장 수관(`CanopySightline`)은 기존 평면 구현 `PlaneCutaway`를 그대로 쓴다.

- 보행면은 모두 y=0 평지이고 난간은 1m 충돌 마스크 경계 바로 바깥에 선다. 큰 높낮이는 보행 영역 밖 배경 볼륨으로만 표현하며 가짜 계단은 없다. 보행 영역 남쪽(카메라 쪽) 볼륨 높이는 북쪽 보행 경계까지 거리의 절반 정도로 제한한다.
- `world.js`의 원형 방(`layout.shapes[i]==='disk'`)은 마스크·`roomAt`·`randomIn`에 원을 쓴다. 컨셉 레이아웃의 봉인 해제는 결계 띠 대신 방·회랑 형상으로 마스크를 다시 채운다. 기존 레이아웃은 동작과 난수 소비가 바뀌지 않는다.
- 진입: 기존 '다른 던전' 목록(ALL_DUNGEONS) 끝, Lv.1, 에너지 4. 성채 광장 6관문 계약은 그대로다. 광장 관문이 없는 던전(확장 6곳 포함)은 여정 지도 버튼이 '던전 입장 · 에너지 N'으로 기존 직접 출격을 부른다.
