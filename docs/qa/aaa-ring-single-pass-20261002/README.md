# 평면 충격파 양면 패스 감소

기존 Mesh/재질·색·확대·페이드·수명과 전투 경고를 유지하면서 평면 DoubleSide 링의 불필요한 앞/뒷면 별도 패스를 줄인다. `_keep` 준비 키에도 `forceSinglePass`를 넣어 실제로 사용하는 양면 프로그램을 미리 준비한다.

880×400 실제 Chromium의 기사/mid, 마법사/low, 궁수/mid/reduced motion에서 실제 `1`키 스킬 입력, MP/CD 변화, 링 32개, 경고 불변, 소멸, 전투 중지·재시작을 검증했다. 같은 선형 장면 타깃의 추가 draw가 64→32이며, 링 draw 이후 GPU 프로그램 수는 준비된 127/118/127에서 증가하지 않았다. 콘솔 오류 0. `report.json`은 소스 freeze 전 dirty 빌드와 정확한 FX 소스 SHA256을 명시한다.

타입 검사·빌드 통과, 전체 테스트 1244 pass / 2 skip / 0 fail. 기존 skip은 탐색 진단과 Linux에서 실행할 수 없는 Windows DPAPI 검사다.

기사 링 장면은 전체 RGB 픽셀이 일치했고, 마법사/low의 최대 채널 오차는 2/255다. 궁수의 전체 이미지에는 안내 배너·버튼 표시 차이가 있어 전체 픽셀 동일성을 주장하지 않는다. 링·영웅·바닥 형상을 직접 비교했다. 과도한 발광에 가려지는 영웅 실루엣을 이 수정으로 해결했다는 주장은 하지 않는다.

이전 InstancedMesh 후보 `33f2188192f56d17103076533ca406d14c0c6dc9`은 복구 후 새로 사전 등록한 5쌍을 끝까지 측정했으나 pair 1·3의 평균 스텝 시간 회귀로 거절됐다. 원본 manifest/10개 보고서/최종 판정은 `rejected-instanced-series.json`에 보존했다. 대표 중앙값만으로 실패를 지우거나 같은 소스를 재측정해 통과 표본을 선택하지 않았다. 그 소스 브랜치도 유지했다.

이 파일은 freeze 전 검증 기록이다. 새 후보의 깨끗한 정확한 SHA를 사전 등록하고 빌드한 뒤 전체 5쌍과 형식 검사를 통과해야 머지·배포할 수 있다. 기존 baseline draw427의 출처와 원본 해시도 유지한다. Head 기준과 상대 회귀 기준을 낮추지 않는다. 최종 승인/배포 상태는 PR의 정확한 SHA·측정·릴리스 receipt로 확인한다.

실기기 GPU/FPS·발열·배터리·멀티터치·청취·장기 플레이 유지율과 AAA 완성 판정은 이 증거의 범위 밖이다. GPU draw 감소와 헤드리스 JS 스텝 시간을 실기기 성능으로 바꾸어 표현하지 않는다.
