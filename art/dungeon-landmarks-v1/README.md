# TLL Dungeon Landmarks V1

This pack is authored with Blender 5.2.1 LTS for Blade Surge. It adds six distinct 3D landmark silhouettes while keeping the existing dungeon kit, collision mask, heroes, and enemy rigs intact.

- `dungeon-landmarks-v1.blend` is the editable source.
- `dungeon-landmarks-v1-beauty.png` is a Blender render of the authored pack.
- `../public/models/tll/dungeons/dungeon-landmarks-v1.glb` is the runtime export.
- `../public/models/tll/dungeons/manifest.json` records Blender version, file size, and SHA-256.

The six runtime node names are `TLL_Dungeon_memorial_Landmark`, `TLL_Dungeon_kiln_Landmark`, `TLL_Dungeon_archive_Landmark`, `TLL_Dungeon_beacon_Landmark`, `TLL_Dungeon_tribunal_Landmark`, and `TLL_Dungeon_confluence_Landmark`.
