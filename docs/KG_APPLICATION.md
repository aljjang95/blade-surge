## 5. 제출 직전 단계

모두 **누르지 않았다**.

| 경로 | 화면 | 제출에 해당하는 버튼 | 비고 |
|---|---|---|---|
| A. KG 공개 신청서 | www.inicis.com/service-application | "신청하기" (개인정보 수집·이용 동의 체크 후) | 상담 신청 성격. 접수되면 담당자가 연락. 신청 전 4번 질의를 먼저 보내는 편이 안전(PAYMENT_COMPLIANCE 4.2-E 순서). |
| B. 전자계약 | 담당 영업의 안내에 따라 진행 | 본인인증 → 서류 업로드 → 등록비 결제 | 결제 단계는 대표님 확인. |
| C. 포트원 경유 | admin.portone.io/onboarding ("전자결제 신청") | 화면 못 봄 | 로그인 필요. 대표님 재로그인 후 재정찰 필요. |
| D. 기존 가맹점이면 | iniweb.inicis.com 가맹점관리자의 서비스 추가 신청 | 화면 못 봄 | 지불수단 추가·MID 추가 가능(공개 안내 기준). |

대표님이 직접 할 일:
1. 사업자 정보 확정과 서류 준비(사업자등록증, 통신판매업 신고증, 대표자 명의 휴대전화/인증서).
2. 월 예상 거래액 결정(2번 표 {{대표님 입력}}).
3. 4번 질의문 발송 승인(메일 발송은 에이전트가 하지 않음).
4. 약관·개인정보 수집 동의 체크, 본인인증, 서류 업로드, 최종 제출, 등록비 결제.
5. 포트원·이니시스 로그인 세션 갱신(PC에서 `admin.ps1 -SessionVaultCapture portone` / `kginicis` 한 번, 비밀번호·OTP는 대표님이 직접).

## 6. 확인 못 한 것

- 포트원: 채널 목록, KG이니시스(inicis_v2) 채널 유무, 테스트/실연동 구분, 상점 수, "전자결제 신청" 화면의 입력 항목·첨부 서류·안내 문구(모두 로그인 필요, 세션 무효). 참고: `console.portone.io`는 이 환경의 네트워크에서 차단(`ERR_TUNNEL_CONNECTION_FAILED`)이다.
- KG이니시스 가맹점관리자: 기존 가맹 여부, 가맹 상태, 계약 서비스, 추가 서비스 신청 항목·서류(로그인 세션 무효).
- 우편계약 필요 서류 목록, 등록비 금액, 보증보험·담보 요건, 정산 주기, 월 한도.
- 입점 제한 업종 "게임아이템판매"가 우리 자사 직판 패키지에 적용되는지(공개 문구만으로 판단 불가) 및 카드사별 등록불가 항목의 정확한 카드사 대응.
- 게임물 등급분류 증빙이 KG 공식 요구인지.
- `blade.tllhouse.com` 푸터의 통신판매업 신고번호 표시 여부(이번 범위 밖).
- 금고 상태 `apex vault status`는 portone·kginicis를 "저장됨"으로 표시하지만 실제로는 두 사이트 모두 로그인되지 않았다 → 금고 세션 갱신 필요.
