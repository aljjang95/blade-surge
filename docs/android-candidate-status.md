# Android 준비 코드 — 보존용 초안

## 현재 우선순위
- 2026-09-11 지시: 웹/PWA 운영을 먼저 유지하고 Android 빌드·스토어 작업은 당장 진행하지 않는다.
- 웹 운영 정본은 PR21 병합 SHA `ca0b2337aa70fdae4e12f4d09c668c9c12bb892f`다.
- 이 브랜치는 기존 Android 준비 코드를 보존하는 초안이며 운영 배포나 스토어 제출 승인본이 아니다.

## 포함된 작업
- 기존 Three.js 웹 엔진을 유지한 Capacitor Android 프로젝트와 기존 앱 식별자.
- 백그라운드 전환·뒤로가기·복귀 처리 및 수동 일시정지 소유권 보존.
- 초기 상태 응답 경쟁 방지, 중복 저장 방지, 네이티브 PWA 등록 차단.
- 빌드 스크립트는 릴리스 서명 환경변수가 없을 때 중단하며 디버그 키로 대체하지 않는다.

## 검증과 남은 경계
- 2026-09-11 로컬 `bun run check`: 414개 테스트, 18,499개 단언, 타입 검사와 웹 빌드 통과.
- 보조 Chrome 검증은 실제 IAB 또는 Android 기기 검증이 아니다.
- 기존 보조 전투 검증의 피격 비율 0.041은 PRD 하한 0.05 미달이다. 원인 및 동등 조건 기준본 비교는 미확정이다.
- 새로운 Android 바이너리, 실기기 중단·복귀, 독립 검토, 스토어 등록 결과는 검증되지 않았다.
- 이전 APK/AAB는 이번 수정 이전 산출물이며 이 커밋의 릴리스 파일로 사용하지 않는다.
- 광고·결제는 실제 SDK 및 영수증 검증 전까지 비활성 상태를 유지한다.
- 서명 키·암호·DPAPI 파일·빌드 산출물·로컬 로그는 이 브랜치에 포함하지 않는다.

검증을 끝내기 전에는 이 초안을 병합·배포하거나 앱 출시 완료로 표시하지 않는다.
