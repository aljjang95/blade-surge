# 컨셉 던전 전용 보스와 표준 → 심층 → 재도전 루프 (2026-10-17)

빙하 조수 분지(`glacier_tide_basin`)와 석양 황동 채석장(`sunbrass_quarry`)은 2026-10-16에 지형·기믹이 새로 생겼지만 보스전은 일식 수문(`obsidian_hydra`)과 재벼림 제련소(`ash_colossus`)를 그대로 반복했고, 심층이 없어 기본 원정 반복만 가능했다. 이 묶음은 두 맵에 지형 기믹을 이어받는 전용 보스를 주고, 기존 심층·정산 서비스 위에 심층 2곳과 결과 화면의 '다음 도전'을 더한다. 새 로비·입구·화폐·저장 필드·유료 자산은 없다.

## 전용 보스

| | 빙하 수문의 거신 `tidegate_titan` | 도르래 거수 `pulley_colossus` |
|---|---|---|
| 외형 | 기존 라이브러리 `frost_golem`(Glaciertitan 얼음 결정 골렘), 로스터 키 `Big_TidegateTitan`, 청록 색조 | 기존 라이브러리 `shadow_soldier`(가시 갑옷 병사), 로스터 키 `Big_PulleyColossus`, 황동 색조 |
| 전투 수치 | `obsidian_hydra`와 같음(hp·atk·spd·range·atkTime·exp·gold·armor·scale·kit) | `ash_colossus`와 같음 |
| 기술 | 수문 범람 `tidegate_flood`, 물결 고리 틈 `tidegate_ring_gap` | 도르래 낙석 `pulley_ore_fall`, 사슬 당김 `pulley_chain_line` |
| 페이즈(60%·30%) | 범람·강타·고리 틈·부채 → 고리 틈·범람·회전·강타 → 범람·고리 틈·돌진 | 낙석·강타·사슬·회전 → 사슬·낙석·부채·강타 → 낙석·사슬·돌진 |

두 자산은 다른 19개 던전 기본 보스, 12개 기존 심층 보스, 캠페인 최종 보스(`*_finalboss`, `dungeon_*_finalboss`)가 쓰지 않는다. 다만 `frost_golem`은 캠페인 4장 1관문 대장(`tide_captain`)과 3장 중간 보스(`frost_midboss`)도 쓴다. KayKit 장식 조립 경로는 이미 철회돼 있어(`public/models/tll/encounters/README.md`) 새 GLB·초상은 만들지 않았다. 전용 초상이 없으므로 보스 바 초상은 숨겨진다. 표시 키는 약 4.3m(거신)·5.1m(거수)이며 판정 반경은 교체 전 보스와 같다.

기본 컨셉 던전 정의에서는 `bossEnemy`·`bossName`(빙하만 '빙하 수문의 거신'으로)·`tactic`의 보스 문장·`bossPattern` 메타데이터와 목표 문장의 보스 이름만 바뀌었다. 에너지 4, 보상, 보스 체력(11,800/12,600), 레이아웃, 명단, 맵 기믹은 그대로다.

## 기술 4종의 판정

모두 기존 `BossSignatures` 풀(보스당 평면 6장)·`hazardContains` 판정·파티 경고 스냅샷을 그대로 쓴다. 기본 예고 1.35초(최소 1.2초), 마지막 타격 뒤 회복 1.05초, 시전 순간 위치로 고정된 도형, 일시정지·기절·사망·정지 시 취소 규칙도 같다.

- **수문 범람**: 보스 마당을 거신이 선 줄(방 중심에서 반폭의 45% 안으로 제한)의 마른 수로(폭 4.4m, 광폭화 3.6m)로 나눈다. 플레이어가 없는 먼 쪽이 1.4초에, 플레이어 쪽이 2.5초에 잠긴다. 먼저 잠긴 쪽은 다음 물결 때 안전하다. 광폭화에서는 3.6초에 먼 쪽이 한 번 더 잠긴다. 차례마다 수로 방향이 90도 돈다.
- **물결 고리 틈**: 방 중심 기준 바깥 물결 고리와 가운데 소용돌이가 1.4초에 함께 치고, 그 사이 빈 고리가 안전하다. 2.7초에는 가운데 물결 고리가 빈 고리를 덮는다(2페이즈부터 바깥 고리도 함께). 광폭화에서는 3.9초에 소용돌이가 다시 친다.
- **도르래 낙석**: 마당 중심 둘레(반지름 최대 7.5m)를 따라 광석 상자 3개(2페이즈부터 4개)가 0.45초 간격으로 떨어지고, 마지막 상자는 시전 순간 플레이어 자리에 떨어진다.
- **사슬 당김**: 북쪽(화면 위쪽) 두 도르래 고정점에서 시전 순간 플레이어 자리를 지나 방 끝까지 사슬 선이 1.45초·2.6초에 당겨진다. 2페이즈부터 보스에서 플레이어 자리로 가는 선이 더해지고, 광폭화에서는 두 사슬이 동시에 당겨진다.

심층 레이아웃은 기본 컨셉 레이아웃 객체를 펼쳐 같은 셀·간선·원형 방·이름표·컨셉 키를 쓰고 방 종류만 바꾼다. 같은 지형 생성기와 같은 맵 기믹(조수 범람·도르래 낙석)이 그대로 돈다. 보스 체력은 기준 심층과 같다(22,000/22,400). 음악 계획에는 두 심층 칸을 추가했고 대체 곡은 기본 원정이 쓰는 지역 곡과 같아서 실제 재생은 바뀌지 않는다.

저장은 기존 `expedition.stats[id]`·`expedition.depthWins[id]`만 쓴다. `normalizeExpedition`이 `EXPEDITION_DEPTHS`로 키를 만들기 때문에 구 저장은 새 두 키가 0으로 정규화되고 기존 기록은 그대로다. 첫 정복 보상은 `settle`이 `depthWins === 0`일 때 한 번만 더한다. 패배는 첫 정복을 소비하지 않는다. 출격 중 새로고침은 에너지 6을 한 번 돌려준다.

## 다음 도전과 표시

`src/ui/concept-challenge.js`는 저장을 읽기만 하는 모델이다. 해금·에너지·보상 판정은 기존 `ExpeditionEconomy.dungeonAccess`·`begin`·`settle`이 맡는다.

- 결과 화면(`src/expansion/hub.jsx`): 컨셉 던전 승리에서 첫 버튼이 '다음 도전'이다.
  - 기본 승리이고 심층이 열려 있으면 '다음 도전 · 심층 원정 준비'. 로비로 돌아가 던전 화면의 심층 탭을 열고 그 심층 카드로 스크롤·초점을 옮긴다. 에너지는 쓰지 않는다. 기존 '다시 도전'은 보조 버튼으로 남는다.
  - 기본 승리이고 심층이 잠겨 있으면 '다음 도전 · 다시 도전 · 에너지 4'와 실제 잠김 사유(예: '심층 잠김 · 캠페인 4-10 클리어 필요'). 같은 재도전 버튼을 중복해서 두지 않는다.
  - 심층 승리이면 '다음 도전 · 심층 재도전 · 에너지 6'과 첫 정복 보상 상태.
  - 누르는 순간 같은 판정을 다시 계산하고, 보이던 행동과 다르면 다시 그리기만 한다. 패배·저장 실패·균열·전술 공략·다른 던전 결과는 기존 버튼 그대로다. 컨셉 던전에서 '다음 도전'이 보일 때는 '다음 던전' 제안을 숨긴다.
- 던전 화면 카드(기본·심층 탭)와 여정 지도의 선택 지역 패널: 컨셉 던전에 보스 이름, 두 기술의 이름·cue 한 줄, '기본 클리어 N회 · 심층 상태'(잠김 사유 / 첫 정복 보상 대기 / N회 정복 · 첫 정복 보상 받음)를 붙인다. 새 입구나 목적지는 없다. 광장 관문과 `citadelPreparation`은 기존 12곳 그대로다.

QA가 읽을 수 있는 자연 상태: 결과 버튼 `[data-next-challenge]`(`retry`/`deep-prep`)·`[data-next-depth]`·`[data-next-challenge-detail]`, 카드 `[data-concept-boss]`·`[data-concept-status]`, 심층 카드 `.exp-dungeon[data-depth="deep"][data-dungeon="<id>"]`, 전투 중 보스의 `signatures.plan.key`. 새 디버그 훅은 추가하지 않았다.
