# 심사용 접속 계정 안내서 — 블레이드 서지

(게임산업법 시행규칙 제9조: 온라인·웹 게임물은 접속 계정을 기재한 서류 제출)

## 1. 접속 방법
| 항목 | 내용 |
|---|---|
| 접속 주소 | https://blade.tllhouse.com (PC·모바일 브라우저, 설치 불필요) |
| 필요한 계정 | **없음.** [터치하여 시작] → [게스트로 시작]을 누르면 게스트 계정이 발급되어 가입·로그인·인증 없이 즉시 시작 |
| 계정 종류 | 게스트(자동), Google 연동(선택·심사에 불필요) |
| 심사용 별도 계정 | 제공하지 않음. 운영 서버를 그대로 보며 심사용 우회·특권 경로는 없다 |
| 과금 | 등급분류 결정 전에는 결제가 꺼져 있어 결제 화면은 열리지 않는다 |

## 2. 심사 항목별로 보는 법 (모두 게스트 계정으로 가능)
| 심사 항목 | 어디서 | 소요 |
|---|---|---|
| 폭력성(몬스터 전투) | 접속 → 게스트 시작 → 시작 영웅 선택 [이 영웅으로 시작] → 로비 [출격] → 1-1 [입장](첫 장면은 [건너뛰기]) | 즉시 |
| 보스전 | 1-1부터 순서대로 진행해 1-5 중간 보스(스테이지 선택 화면의 '중간 보스' 표시). 1-10은 지역 보스 | 약 10분 |
| 확률형 아이템 | 하단 [메뉴] → 상점·소환 묶음 → [소환] → [i 확률 정보](같은 내용이 https://blade.tllhouse.com/odds 에도 있음) | 즉시. 무료 지급 소환권 5장과 무료 보석 1,500개로 소환 가능(1회 보석 300, 10회 보석 2,700) |
| 장비·세트 효과 | 하단 [영웅·장비] → 가방·세트·제작 공방(제작 공방은 [메뉴] → 성장·정비에서도 열림). 장비는 던전 드랍·제작으로 획득 | 플레이 진행 필요 |
| 선혈 연출(흡혈 세트 4개 장착 시 피격) | 흡혈 세트 장비 4개 장착 상태에서 피격될 때 약 0.5초 | 장비 획득 필요(플레이 시간 소요) |
| 이용자 채팅 | [메뉴] → 시스템 → [커뮤니티] → 채팅 탭(광장 채널). 처음에는 닉네임(2~12자) 입력 화면이 뜬다 | 즉시(심사 중 글 전송은 불필요) |
| 이용약관·확률·환불·개인정보 | 부팅 화면 하단 링크 | 즉시 |

## 3. 시간이 걸리는 장면 안내
흡혈 세트 4개와 1-5 보스는 처음부터 하려면 플레이 시간이 필요해, **제출 영상(`04_플레이영상.mp4`)에 해당 장면을 담았다.** 영상은 운영 주소의 실제 코드를 실제 키 입력으로 플레이한 것이며, 심사 장면 확보를 위해 흡혈 4세트 장착·1-5 개방 상태는 게스트 저장 데이터를 직접 설정했다(숨기지 않음). 심사 중 직접 확인이 필요하면 담당자 연락처로 알려 주시면 해당 장면 시작 상태를 준비해 안내한다.
