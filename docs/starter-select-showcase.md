## 구현 (src/ui/starter-select.js · starter-select.css)
- 무대: 직업색 방사 조명·두 겹 안개(16/22초 왕복)·바닥 광·불씨 캔버스(46개, 화면이 떠 있는 동안만, 동작 줄이기면 정지)·비네트.
- 왼쪽 세로 탭 5개(원형 초상 + 직업색 이름판). 세로 화면은 맨 아래 가로 줄.
- 가운데 전신 일러스트 `public/img/tll/stage/<hero>-stage-v1.webp`(원본 `*-original-v1.webp`를 rembg isnet-general-use로 배경 제거, 높이 1000px, 합계 약 650KB, 화면을 열 때 미리 받음).
- 고르는 순간: 이전 영웅 왼쪽으로 빠짐 → 새 영웅 밝게 떠오름(0.55초) + 발밑 룬 서클 확장 + 빛기둥(0.75초) + 불씨 가속 + 카드 소리 + 0.16초 머문 영웅만 선택 음성(`hero_<id>_select`).
- 정보 카드: 이름·칭호·역할·한 줄 특징·대표 스킬 3개(기본 2 + 궁극기)·난이도 별·공격/생존/난이도 막대.
- 확정: 직업색 섬광 + 큰 빛기둥 + 영웅 발광(0.9초), `gacha_reveal_sr` + `ui_confirm`. 두 번 눌러도 한 번만 고른다.
- 곡: `STARTER_SELECT_CUE`(src/data/music.js). 전용 FlowMusic 곡 배송 전에는 `regions/crown`.
