# 2026-10-08 전투 흐름과 로비 패치

실제 플레이에서 보고된 반복 피격의 조작 중단, 몰이 전에 발생하는 타격, 첫 출격 안내의 강제 정지, 로비 카메라 무응답, 동일한 던전 입구를 함께 수리한다. 현재 수동 콤보의 새 누르기 입력 계약은 유지한다.

## 동작 변경

- 일반 피격(`kb < 6`)의 체력 피해·피격 판정·사망은 유지하며 이동 속도와 행동 상태를 초기화하지 않는다. 작은 시각·소리 피드백은 짧은 간격으로 제한한다. 강한 넉백과 해당 공격의 기존 경직은 유지한다.
- 철벽 강타·대지 강타의 준비 구간과 회전·눈보라 채널에서 기존 충격형 `pull`과 분리한 목표점 몰이를 사용한다. 실제 위치는 기존 Actor와 Floor 충돌 경로로 움직인다. 보스·엘리트 저항, 고정 공격 예고·돌진 경로의 소유권과 공격 시계는 보존한다.
- 첫 출격의 조작 안내는 기본 접힘이며 다시 열 수 있다. 안내 단계가 바뀌어도 전투·AUTO·입력을 정지하거나 초기화하지 않는다. 안내 버튼의 초점만 현재 활성 전투 캔버스로 복귀시킨다. 다른 모달과 일시정지 소유권은 유지한다.
- 로비의 화면 드래그와 별도 모바일 시점 패드, 확대·기본 복귀 조작을 실제 걷기 카메라에 연결한다. 조이스틱과 시점 패드의 포인터를 분리하고 전투·모달·탭·화면 종료 시 캡처를 해제한다.
- 던전 12개와 캠페인·투기장 2개의 입구를 별도의 Three.js 구조로 만든다. 온실·금고·서고·종탑·수문·천문대·히드라·모루·첨탑·잎·초승달·혜성 구조를 구분하며 기존 입장 조건·트리거·좌표·충돌 통로는 유지한다. 입구마다 재질별 버퍼를 병합하고 네 재질을 공유한다.

원본 소스를 읽기 전용으로 추출하고 동일한 시드 2,000개를 원본과 후보에 각각 적용했다. 3영웅×30·60·120fps에서 실제 Player/Enemy/Actor/ImpactClock/Floor/contact 코드를 진행한다. 후보 2,000회는 모두 생존·유한 수치·충돌·첫 접촉의 몰이 기대 검사를 통과했고 일반 피격의 새 hurt 전환은 0건이었다. 기사 초기 무리의 범위 밖→첫 접촉 안 이동은 평균 6.94→12명, 시뮬 종료 시 생존 적의 최초 중심 기준 최대 거리 평균은 5.66→2.20m였다. 이 종료 값은 대개 남은 강적 한 명의 거리이며 채널 중 군집 유지의 직접 증거로 쓰지 않는다. 이 시뮬은 Lv1 단일 방의 전투 성분이며 GLB·DOM·오디오·전체 층 보상·성장·가챠는 측정하지 않는다.

회오리의 첫 접촉은 즉시에서 약 0.167초로 늦춰 실제 몰이 준비 시간을 준다. 원래 0.22초 반복 간격과 1회 피해는 유지한다. 한 생존 표적의 실제 Player 종료까지 원본은 30/60/120fps에서 7/7/8회, 후보는 7/7/7회다. 120fps 조건의 총 단일 표적 피해는 8→7타로 줄어들며, 이를 전체 피해 보존으로 표기하지 않는다. 8초 시드 무리 전투에서 초당 기록 피해 평균은 기사 1,227.77→1,372.70, 광전사 1,545.93→1,548.82, 마법사 1,750.95→1,751.46이다. 최대 피해 검사는 실제 접촉 수와 기존 치명타 상한으로 계산하며, 층 전체 DPS나 성장 밸런스 통과로 확대하지 않는다.

접힌 안내 버튼이 짧은 가로 화면의 보스 이름·체력바와 겹치는 것을 새 PNG에서 발견해 위치를 수정했다. 수정 후 전체 검사를 다시 통과했고 880×400의 보스·밀집 전투·종료 화면 세 장을 직접 확인했다. 보스 HP 배치를 수정한 CSS-v2의 단독 지표는 오류 0, 로드 6,436ms, 평균 게임 JS 1.05ms, p95 2.3ms, 388 draw calls, 188.9초/197처치/42드랍/12구역 완주다. 기준선 대비 평균 JS +7.14%, draw calls -3.24%로 기본 상대 한도를 통과했다. 실제 기기 FPS와 다른 게임 JS 계측이며, 앞선 CSS 후보 0.91ms와 구분한다.

실제 입력의 새 저장 첫 출격에서 안내 열기·다음·접기 뒤 전투는 계속 진행됐고 캔버스로 초점이 복귀해 새 W로 1.24m 이동, Space로 공격 상태 진입을 관측했다. 별도 로비 입력에서는 카메라 패드·휠·회전 시점의 W 이동·초기화·저장, 조이스틱과 카메라의 독립 터치 포인터·부분 해제·핀치 확대를 관측했다. 원본 하네스의 전체 결과는 보조 행동 대기·중복 CDP 터치 해제·소프트웨어 렌더의 벽시계 제한으로 실패했으며 이를 전체 native 통과로 바꾸지 않는다. 실제 첫 방에서 적이 따라오는 모습과 경타의 상태 시계 연속·강타 경직 보존도 관측했다. 새 CSS 후보의 실제 첫 방에서는 통로로 무리를 유인한 뒤 철벽 강타 버튼을 눌렀다. 자연 RAF의 t=.05/.10초·cast=false 동안 살아 있는 적의 플레이어와의 거리가 ID2는 2.855→1.661m, ID7은 4.176→3.108m, ID11은 4.057→2.963m로 줄었고 각 HP는 같았다. 이후 cast=true와 적 HP 감소·처치를 관측했다. 자연 경타로 HP가 2,778/2,800이 된 뒤 실제 W 이동과 새 Space 세 번의 입력을 받아 마지막 attack/comboIdx2를 확인했다. `candidate-native-v7`의 원시 관측과 영상은 보존하며 접촉 시점 PNG를 접촉 전 이미지로 사용하지 않는다. 같은 실행의 첫 출격에서 안내 버튼이 보스 직행을 가리는 배치를 발견해 실제 상단 버튼 표시 상태에 맞춰 여백을 예약했다.
