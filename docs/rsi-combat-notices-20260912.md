# 전투 알림 QA — 2026-09-12

보스 봉인 해제에서는 경고와 포탈 안내가 같은 tick에 발생한다. 기존 UI는 최대 4개 알림을 쌓고, 세로 전투 화면에서 경고가 있으면 일반 알림을 숨겼다. 숨겨진 알림도 2.2초 후 삭제되어 포탈 안내가 표시되지 않을 수 있었다.

전투 중에는 한 개의 알림만 표시한다. 위험 알림이 일반 안내를 즉시 선점하고, 중단된 안내는 이후 다시 표시된다. 동일 메시지·종류는 중복 제거하며, 표시를 시작할 때 각 2.2초 수명을 부여한다. 대기는 4개로 제한하고 오래된 일반 안내부터 정리한다. 전투 종료·재시작은 큐와 타이머를 정리하며 로비 알림은 기존 동작을 유지한다.

검증: 봉인 해제→포탈, 위험 선점→복귀, 중복, 경고 순서, 연속 이벤트 상한, 전투 전환·취소 타이머를 포함한 신규 6개 회귀 통과. 전체 420개 테스트/18,524 assertions, 타입 검사, 웹 빌드 통과. 독립 코드 리뷰에서 확인된 P1/P2 없음.

실제 화면 검증은 미완료다. IAB가 native pipe closed 이후 User unavailable을 반환했다. 짧은 가로 화면에서 단일 알림(top 18%)과 중앙 배너(top 26%)가 맞닿는지는 추가 확인이 필요하다. 이 후보는 초안 PR로 보존하며 해당 화면 QA 이후에 병합·배포한다. 기존 Chrome/SwiftShader 표본의 피격 비율 .041은 동일 조건 IAB 기준선 비교가 없으므로 이 패치의 회귀나 통과 근거로 사용하지 않는다.

현재 운영에는 별도로 PR22의 0b0d8c86이 배포되어 있다. Android 빌드·기기·스토어 검증은 현재 웹 QA의 선행조건이 아니다.
