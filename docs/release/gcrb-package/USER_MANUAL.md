# 사용설명서 — 블레이드 서지 (공개용)

> PDF 생성 시 장면 캡처 8~10장(가로 1280x720, 운영 주소 https://blade.tllhouse.com 실제 화면)을 각 절 아래에 넣는다. 파일명 `shots/NN-장면.png`.

## 1. 시작하기
- 인터넷 브라우저(PC 크롬·엣지, 모바일 크롬·사파리·삼성 인터넷)로 https://blade.tllhouse.com 에 접속한다. 설치·회원가입이 필요 없다.
- 첫 화면(부팅)에서 등급 표시 줄과 이용약관·개인정보처리방침 링크를 볼 수 있다. 화면을 누르면 시작한다.
- 별도 입력 없이 **게스트 계정이 자동 발급**되어 바로 플레이할 수 있다. 설정에서 Google 계정을 연동하면 다른 기기에서 이어서 할 수 있다(선택).
- 캡처: `01-부팅` `02-로비`

## 2. 조작
| 동작 | PC | 모바일 |
|---|---|---|
| 이동 | W A S D | 왼쪽 조이스틱 |
| 공격 | J / 스페이스 | 오른쪽 공격 버튼 |
| 회피 | K / Shift | 회피 버튼 |
| 스킬 | 1~6 | 스킬 버튼 |
| 자동 전투 | AUTO 버튼 | AUTO 버튼 |
- 캡처: `03-전투-조작`

## 3. 게임 진행
영웅을 고르고 [출격]으로 던전에 들어간다. 몬스터를 처치하며 구역을 정화하면 보스 봉인이 풀리고, 보스를 쓰러뜨리면 장비·재료를 얻는다. 캡처: `04-던전전투` `05-보스전`

## 4. 성장·장비
영웅 레벨, 스킬 트리, 장비(무기·방어구·반지·신발) 드랍·강화·제작·세트 효과. 캡처: `06-장비`

## 5. 소환(확률형 아이템)과 상점
보석으로 영웅·장비를 소환한다. 소환 화면의 [확률 정보]에서 등급별 확률·천장 규칙을 볼 수 있고 https://blade.tllhouse.com/odds.html 에도 같다. 이용자 간 거래·환전은 없다. 등급분류 결정 전에는 유료 판매를 하지 않는다. 캡처: `07-소환` `08-확률정보` `09-상점`

## 6. 소통
월드 채팅·친구 대화가 있다. 금칙어와 링크는 자동으로 가려지고 차단·신고·도배 제한이 있다. 캡처: `10-채팅`
