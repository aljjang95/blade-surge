# 이번 패치의 관찰 가능한 완료 기준

- REQ-IDENTITY: 몹몰이→진공기→드랍→장비/강화→다음 층과 네브 동행 대화를 보존한다. 원요청과 현재 PRD의 경계를 기록한다.
- REQ-INPUT: 정지/대화/포커스 상실/결과 화면에서 입력이 쌓이거나 복귀 후 이동·공격이 이어지지 않는다. 수동 정지와 대화 정지가 서로를 해제하지 않는다.
- REQ-REWARD: 한 전투 결과는 한 번 정산한다. 광고 목업 추가 보상의 표시와 지급이 일치하고 중복/다른 전투 보상이 발생하지 않는다.
- REQ-SAVE: 부분/구형/손상된 로컬 저장 데이터가 시작 화면을 영구적으로 막지 않는다. 유효한 영웅·장비·진행은 보존하고 정상 저장은 재로딩 후 유지된다.
- REQ-RUNTIME: 타입검사/회귀 테스트/빌드와 실제 브라우저 전투·대화·성장·완주를 확인한다. 가로 모바일/세로 안내/오류 로그와 실제 장치 미검증을 구분한다.
- REQ-BOUNDARY: 실결제/계정/서버 추가 없이 목업을 유지한다. 기존 동료/렌더링 변경 보존, production 배포 없음, 유료 API 없음.
