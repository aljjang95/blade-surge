## 3. 설계

### 3.1 전설 수련(Legend Rank) — 끝이 없는 성장 축
- 대상: 영웅 Lv.80 이후 EXP. 계정 공통(영웅을 바꿔도 유지 — 8시간 플레이어가 여러 영웅을 키우게 만든다).
- 단계 r → r+1 필요 EXP = `LEGEND.baseExp × (1 + r × LEGEND.growth)`(선형 증가). 상한 없음(저장은 정수 상한 `MAX_COUNTER`로만 막는다).
- 단계마다 점수 1. 점수는 네 갈래 판에 넣는다: **칼날**(공격·치명), **철벽**(체력·방어·회피 회복), **폭풍**(몰이 반경·진공 세기·재사용 대기), **약탈**(골드·드랍 확률, 상한 있음). 갈래마다 노드 6개, 노드는 1~20단계, 단계 효과는 체감 감소(`eff × r / (r + k)`). 5단계마다 갈래 키스톤 하나가 열린다(전투 동사를 바꾸는 것만 — 예: 폭풍 키스톤 "진공 끝에 작은 회오리가 1초 남는다"). 스탯만 늘리는 키스톤 금지.
- 점수는 언제든 무료로 재분배(골드 비용, 재련처럼 골드 싱크).
- 순수 규칙: `src/game/legend-rank.js` — `legendExpFor(rank)`, `grantLegendExp(state, amount)`, `legendStats(state)`, `allocate(state, nodeId)`, `respec(state)`. Economy 정산 트랜잭션 안에서만 상태를 바꾼다. 저장 키 `legend: { rank, exp, points, nodes: {} }`, 마이그레이션은 기본값.
- 서버 권위: `shared/` 정산과 같은 함수를 쓰게 둔다(지금 서버 명령이 없는 로컬 필드는 `endgame`처럼 `PARITY_KEYS`에 넣지 않는다 — CONTENT_90D 5.1 이유 그대로).

### 3.2 고통 단계(Torment) — 에너지 없이 끝없이 도는 난이도
- 지옥 다음 난이도. T1은 아무 지역 지옥 10관문 클리어 시 열리고, T(n+1)은 Tn에서 지역 최종 보스(X-10) 클리어로 열린다. 최대 T50(데이터 상한).
- 배율: 적 체력·공격 = 지옥 × `1.17^n`, 보상 = 지옥 × `(1 + 0.08n)`, EXP = 지옥 × `(1 + 0.1n)`. 단계가 오를수록 상급·전설 강화석·초월석·룬 가중(`loot-tables.js`가 자동 생성하는 구조 재사용).
- **에너지 0**. 대신 보상 감쇠: 하루 첫 N판(`TORMENT.fullRuns`)은 보상 100%, 그 뒤 판은 골드·재료 35%이고 EXP(→전설 수련)는 100%. 그래서 8시간 플레이어는 남는 시간을 전설 수련으로 바꾸고, 짧게 하는 플레이어는 손해가 없다.
- 순수 규칙: `src/game/difficulty.js`에 `torment` 항목과 `tormentScale(n)`; 기록은 `endgame.torment = { best, today: { day, runs } }`.

### 3.3 7~12장 — 시간 개방 신규 지역

- 6장 고정 상수 일괄 정리(정찰 결과): `loot-tables.js` `length:6`·`Math.min(6,…)`·`CHAPTER_START_LEVEL`, `worker/party-state.ts` `stageIdx > 60` 두 곳, `stages.js`·`music.js`·`campaign-towns.js`의 `ch===6`·`ch===5` 분기, 테스트 고정값. 파생값(`CHAPTERS.length * STAGES_PER_CHAPTER`)은 테스트로 고정.
- 지역별 신규 AI 동사(리스킨 금지):

| 장 | 지역(가칭) | 신규 몬스터 동사 | 최종 보스 핵심 패턴 |

### 3.4 시뮬레이터 확장(S1~S5 증명)
- `PERSONAS.marathon = { minutes: 480, sessions: 4, skill: .85, enhCap: 20, towerShare: .3 }`.
- 하루 시간 배분 순서: 일일·주간 임무 → 새 캠페인/난이도 관문(에너지) → 탑(주간 상한까지) → 고통 단계 최고 단계 도전 → 남은 시간 고통 단계 반복(감쇠 보상 + EXP→전설 수련). 이 순서에 넣을 것이 없는 분이 `idleMin`.
- 7~12장은 `CHAPTERS.length`·`CHAPTER_OPEN`을 읽어 자동 반영(지역 레인이 머지되면 숫자가 바뀌고 밴드는 그대로).
- 전설 수련·고통 단계 전투력은 진행 판정(`POWER_NEED`)에 넣되 CONTENT_90D 4.5의 '보너스층 제외' 원칙과 충돌하지 않게 S5 몫 밴드로 상·하한을 건다.

## 5. 결정과 다른 선택지
- 끝없는 축을 **전설 수련**(계정 공통 판)으로 고른 이유: 8시간 플레이어의 남는 시간을 확실한 진행으로 바꾸면서, 판 효과에 체감 감소를 걸어 장비·강화가 계속 주력이 된다. 다른 선택지: 영웅 레벨 상한 상향(80→200, 기존 밸런스 전부 재조정 필요라 기각), 무한 강화(+20 이상, 파괴 체감이 커서 기각).
- 고통 단계를 **에너지 0 + 하루 N판 뒤 감쇠**로 고른 이유: 에너지로 막으면 8시간이 불가능하고, 감쇠 없이 열면 재화 인플레이션(CONTENT_90D 4.4)이 깨진다.
- 지역을 **시간 개방**으로 고른 이유: 60관문을 한 번에 열면 8시간 플레이어는 1주 안에 소비한다. MMO_DESIGN 7.5 달력과 같은 주에 맞춘다.

## 7. 기준 변경 공개
밴드(2절 S1~S5, CONTENT_90D 4.5)는 약하게 바꾸지 않았다. 아래는 **3절 설계의 수치**를 시뮬레이터로 보정한 변경이다. 어느 것도 기준을 낮춘 것이 아니라 그 기준을 만족시키는 수치로 옮긴 것이며, 실기기 손맛로 다시 확인할 대상이다.

| 항목 | SPEC 초안(3절) | 확정 | 이유 |
|---|---|---|---|
| 고통 단계 적 체력·공격 배율 | 지옥 × 1.17^n | 지옥 × (1 + n/14)^2 (`TORMENT.curve`) | 요구 전투력이 지옥 대비 1.17^n 이면 T10 에서 5배를 넘는다. 마라톤의 전투력 천장(Lv.80·장비 +17~19·전설 +25%, 약 85k)은 `1-10` 기준 약 T12 에서 막혀 S5(D90 T18~T30)를 증명할 수 없다. 거듭제곱 곡선은 같은 천장에서 T24 로 멈추고, 올라갈수록 단계 사이가 완만해져(T1 +15% → T25 +5%) 전투력이 느리게 오르는 구간에서도 새 단계가 이어진다. T50 이 지옥의 약 21배라 T30 은 천장 밖이다(S5 'T30 p10 ≥ 75일' — 16시드 모두 미도달) |
| 고통 단계 EXP 계수 | 지옥 × (1 + 0.1n) | 지옥 × (1 + 5n) (`TORMENT.expStep`, 처치 EXP 포함) | 0.1 이면 마라톤이 Lv.80 에 D72 에야 닿는다(레벨 70→80 에 EXP 약 2.1억). 그러면 전설 수련이 D72 부터라 S2(90일 중 80일 이상 주요 진행)·S5(전설 몫)를 증명할 수 없고 D16~D72 는 전투력 정체다. 5 로 Lv.80 을 D16 으로 당긴다. 하드코어 이하는 고통 단계 시간이 하루 4분 남짓이라 영향이 없다 |
| 전설 수련 필요 EXP | `baseExp × (1 + r×growth)` 형식 | baseExp 12,000,000 · growth 0.001 (`LEGEND`) | 5단위 돌파가 하루 1회 안팎 나오게(S2 주요 진행일 87/90). growth 를 0.1 로 두면 D40 이후 돌파 간격이 2.2일로 벌어져 주요 진행일이 63일에 그친다(시드 0 실측). 마라톤 D90 단계 약 391 — 노드 480칸 중 약 390점을 채운 상태라 90일 안에 판이 끝나지 않는다 |
| 키스톤 | '5단계마다 갈래 키스톤 하나' | 단계 5·10·15·20 에 칼날→철벽→폭풍→약탈 순서, 단계 100 에서 20개 모두 개방. 자동 적용(선택 없음) | 모호한 문구의 해석. 모두 전투 동사를 바꾸는 효과 플래그이며 스탯 키스톤은 없다 |
| 약탈 갈래 | 골드·드랍 확률, 상한 | 골드 +30%·드랍 +20% 상한, 강화석·조각 몫 포함 | 상한은 `LEGEND.caps` |
| 점수 재분배 | '무료'와 '골드 비용'이 함께 적힘 | 골드 비용: 1,000,000 + 50,000×사용 점수 | 3.1 본문의 '골드 싱크' 쪽을 택했다 |
| S2 최장 연속 | 마라톤 ≤ 3일 | p90 ≤ 3 로 검사 | p50 보다 엄격하다(실측 p50 2 · p90 2) |

시뮬레이터 한계와 가정:
- 라이트·미드·하드코어는 고통 단계를 쓰지 않는 것으로 모델링한다(기준선 보존, S4). `bun tools/sim-90d.mjs --torment-all` 로 모두 켜면 하드코어 D90 T3, 미드 T0 — 에너지 콘텐츠 뒤 남는 시간이 거의 없어 전설 수련은 시작도 못 한다(미드 D90 Lv.61). 그래서 'S5 미드 D90 전설 몫 ≤ 15%'는 0%로 통과한다(실제 실측 의미는 '미드는 Lv.80 에 못 닿는다').
- 고통 단계 도전은 지옥으로 클리어한 가장 쉬운 X-10 에서 한다(해금 규칙 그대로 '아무 지역 X-10'). 반복은 단계 1~(최고+1) 중 보상+EXP 가치가 가장 큰 (관문, 단계)를 클리어 가능한 범위에서 고른다. 한 판 4.5분.
- 마라톤 에너지는 세션 간격 4시간 = 세션마다 80(=4h/180s)만 찬다. 세션 끝의 한 판 미만 자투리는 '할 일 없음'이 아니다.
- 장비 룬·숙련·세트·스킬 같은 보너스층은 진행 판정에서 뺀다(CONTENT_90D 4.5 규약). 실제 전투력은 더 높으므로 실제 T 는 T24 보다 높을 수 있다 — 실측 KPI 로 보정할 대상.
- 7~12장은 `StagesData.CHAPTER_OPEN`(없으면 모두 개방)을 읽는다. 값은 시즌 시작 기준 0부터 센 주차 또는 개방 시각(ms)이어야 하며, 지역 레인이 모양을 정하면 `tools/sim-90d.mjs` `chapterOpenIdx` 만 맞춘다. 장 수가 늘면 `TOTAL_STAGES`·`NEED_BASE`·`stageNeed`가 `CHAPTERS.length`로 자동 늘고, 밴드는 그대로다.
