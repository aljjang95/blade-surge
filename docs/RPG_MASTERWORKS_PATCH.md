## 실제 적용 계약

1. **출격 빌드**: 12각인, 4계열, 6조합. 시작과 구역 정화 후 3개 중 1개, 한 출격 최대 6회 선택. 같은 각인은 최대 3단계. 선택창을 닫고 이어가도 단계 제한이 유지된다. 귀환 시 출격 각인만 종료된다.
2. **행동 변화**: 마무리 추가 피해, 마무리 연쇄 최대 2대상, 회피 회복, 파괴력, 재사용 감소, 처치 회복과 능력치 조합. 피해가 없는 공격과 조용한 지속 피해는 균형을 올리지 않는다. 보스는 일반 적보다 붕괴시키기 어렵고 회복이 빠르다.
3. **숙련 보상**: 정확 회피 직후 3초 안의 첫 유효 직접 명중은 35% 추가 피해. 붕괴된 적은 30% 추가 피해를 받는다. 전투 피드백은 기존 Flow/Kenney 사운드와 VFX를 사용한다.
4. **영구 성장**: 명성으로 3계열×3단계 숙련을 배운다. 명성은 실제 처치·첫 발견·완료·의뢰·선택에서 얻는다. 신규 저장에 무료 숙련을 만들지 않는다. 명성과 선택은 실패 후에도 남는다.
5. **선택과 재방문**: 등불·대장장이·기록실 세 이야기의 첫 선택을 저장한다. 처음의 명성은 한 번만 지급한다. 재방문은 선택에 따른 후일담과 6% 또는 12% 회복을 그 출격에서 한 번 제공한다.
6. **탐험·목표**: 실제 정화한 구역과 첫 캠페인 완료를 기록한다. 동일 구역 중복 발견 보상은 없다. 길드 의뢰 3개는 실제 처치/정예/승리를 세며 한 번 수령한다. 기존 재료 던전과 지정 장비 제작이 이어진다.
7. **도전과 편의**: 균형·선봉·추적자 세 방식, 3개 선택 서약, 독립 준비 저장 3슬롯. 서약은 적 체력·공격과 완료 명성을 함께 바꾼다. AI 결투는 공통 기존 규칙을 사용하며 각인/서약 추가 지급을 적용하지 않는다.
8. **통합 유지**: 모든 화면은 앱 내부에 있다. 기존 캐릭터·맵·재화·장비·전직·원정·도감·동행을 보존한다. 저장 실패는 거래를 되돌리고, 이미 지급한 선택/의뢰/발견을 중복 지급하지 않는다. 각인 창의 정지는 기존 정지 이유를 해제하지 않는다. 시뮬레이션 시간은 기존 전투가 단독 소유한다.

## 검증·출시 기준

코드 통과만으로 완료라고 판단하지 않는다. 현재 빌드에서 출격 준비→각인→전투→구역 보상→만남→보스→결과→숙련 구매→새로고침→재도전을 검사한다. 원거리 실바 및 근접 영웅, 서로 다른 던전·서약, 중첩 정지와 작은 화면을 확인한다. 마이그레이션·중복 보상·저장 실패·레벨업 체력·각인 단계·사망 후 정산은 회귀 검사로 확인한다.

실제 휴대폰 성능·발열·터치와 주관적 청음·재미 평가는 별도 측정이 필요하다. 기술 검증을 이용자 선호도나 시장 성공으로 표현하지 않는다. 검증 로그와 실행 화면은 작업 결과의 `outputs/rpg-masterworks/`에 남긴다. 커밋/원격/운영 SHA를 실제 대조한 뒤 출시 기록을 추가한다.

- 실바 유리 정원 승리: 16처치, 최대 콤보29, 4계열 각인과 6조합, 균형 붕괴1, 명성36. 영웅 레벨2→4와 기존 재료·장비 전리품 지급을 확인했다.

- 실제 획득 명성으로 공세·생존·통찰 첫 숙련을 구매한 뒤 새로고침해 저장값 일치를 확인했다. 준비 슬롯은 균형/무서약, 추적자/철의 적, 선봉/철의 적·분노의 적으로 독립 보관했다. 누적30처치·3승·정예5처치 의뢰를 모두 한 번씩 수령했다.

- 런타임에서 찾은 레벨업 체력 중복, 대기 각인 단계 초과, 사후 처치·발견 지급, 선택 명성 집계, 짧은 던전의 누락된 만남, 소환수로 인한 지급 간격 변동, 결과에서 던전·공방으로 이동하지 못하는 문제를 수정하고 회귀 검사했다. 저장 실패 결과는 버리지 않고 재정산 안내를 유지한다.

- 연쇄와 반격은 실제 `Battle.damageEnemy` 경로 회귀에서 대상 HP 감소로 검증했다. 연쇄의 거리제곱42/최대2명/공격력55%/0.65초 간격과 quiet 재귀 차단, 반격의 첫 유효 직접 명중135→다음 명중100, 빗나감·quiet 미소비를 검사했다. 관찰용 래퍼·타이머는 검증 후 복원·제거했다.
- 최종 빌드의 무료 AI 결투에서 각인·서약 효과가 비활성이고 기본/최종 능력치가 같은 것을 확인했다. 결투 종료→숙련→원정 준비→재료 던전의 실제 이동, 길드 의뢰→공방 진입을 확인했다. 최종 로컬 브라우저 오류 로그는 0건이었다.
