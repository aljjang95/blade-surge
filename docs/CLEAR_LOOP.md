# 클리어 루프 — 카드 보상·즉석 정비소·무기 수리·인게임 가방·동료 네브 (2026-10-29)

대표님 실기기 신규 플레이 피드백(1-1 결과 화면: VICTORY·처치 190·Lv.1→5·'획득 보상 장비 43개 · 눌러서 비교'):

1. 결과 화면이 별로다. 장비 개수보다 **카드 3장 중 1장 고르기**로 "한 판 완수"를 느끼게.
2. 얻은 장비를 **클리어 직후 바로 판매·강화**하는 상점.
3. **수리**로 무기에 애착.
4. 재화를 금방 쓸 곳(**인플레이션 방지**). 큰 틀은 전투·성장 레인과 공동, 이 문서는 클리어 직후 소모처(수리·강화·정비소)를 맡는다.
5. 다른 영웅 장비를 얻으면 **인게임에서 가방을 열어** 확인하고 싶다.
6. 뒤에 따라다니는 동료가 **누군지, 어떻게 얻는지** 보이게.

## 지금 상태 (main c2603fc, 코드 확인)

- 결과 화면(`src/ui/ui.js` showResult): VICTORY 띠, 별, 성장 바, '획득 보상 · 장비 n개 · 눌러서 비교' 접힘 목록. 장비를 누르면 로비 영웅 화면으로 이동한다. 1-1 한 판에 필드 장비가 수십 개 들어와(대표님 화면 43개) 목록이 길고, 고르는 순간이 없다.

- 판매·분해·강화 함수는 이미 있다(`sellItem`·`salvage`·`enhance`, 확정 강화 포함). 결과 화면에서 바로 부를 길만 없었다.
- 내구도는 없었다.
- 따라다니는 존재는 **네브**(이야기 동료, `src/companion/director.ts` startBattle → `CompanionCombatant`, 모델 skeleton_mage에 청록 틴트)다. 매 전투 자동으로 붙고 이름·소개·획득 경로를 보여 주는 화면이 없다. 로비 왼쪽 '네브' 버튼은 대화창이다.
- 전투 중 가방은 없다(일시정지 메뉴에도 없음). 장비는 영웅 귀속(`docs/GEAR_OWNERSHIP_VAULT.md`)이라 다른 영웅 장비가 떨어져도 전투 중에는 알 수 없다.

## 설계와 수치

### A. 카드 보상 (`src/game/clear-loop.js`)

- 캠페인 승리(`completeStage`)마다 카드 3장. 소탕·무한의 성·원정은 만들지 않는다.
- **난수를 쓰지 않는다**: 관문·난이도·판 수(`quests.stages`)·영웅·장비 순번의 해시로 정한다. 클라이언트와 서버가 같은 카드를 만들고, 기존 필드 장비·강화 난수 순서를 바꾸지 않는다(서버 패리티 유지).
- 희귀도 가중치: 일반 56 · 희귀 30 · 영웅 11 · 전설 3. 첫 클리어·보스 관문은 가운데 카드가 희귀 이상.
- 종류(3장은 서로 다른 종류): 금화(관문 기본 골드 × 희귀도 배율 × 1.6) · 강화석(2/3/5/8개, 5장부터 중급) · 장비(S/E/E/U, 그 관문 장비 레벨) · 조각(5/10/18/35) · 정비 쿠폰(무기가 닳았을 때만: 무료 완전 수리 + 골드) · 주문서(영웅·전설 카드만: 축복/보호 1장).
- 희귀도 배율: 일반 0.5 · 희귀 0.8 · 영웅 1.2 · 전설 2.0.
- 저장: `s.clearCard = { id, heroId, cards, picked }`(서버 소유 키, 비면 필드 없음). 고르기는 `pickClearCard(i)` 한 번(서버 `/cmd pickClearCard`). 고르지 않고 다음 승리를 하면 첫 장을 자동 수령한다.
- 기존 보상(경험치·골드·필드 장비)은 그대로 지급하고 화면에서 한 줄 요약으로 줄인다. 카드가 결과 화면의 주인공이다.

### B. 즉석 정비소 (결과 화면)

- 이번 판 얻은 장비 목록: 판매 · 분해 · 강화(확정 강화 포함) · 상세(로비 장비 화면). 다른 영웅 장비는 '◆ <영웅> 장비' 표시, 출전 영웅 장비는 착용 비교 한 줄.
- 새 경제 함수는 없다(기존 `sellItem`·`salvage`·`enhance` 명령). 판매는 골드를 늘리므로 정비소 맨 위에 수리·강화를 먼저 둔다.

### C. 무기 내구도·수리

- 무기만. 캠페인 승리마다 −3(보스 관문 −5). 약 15판(하루 한두 세션)에 50 아래.
- **깨지지 않는다**. 50 이상 감소 없음 · 25~49 무기 공격력 −4% · 1~24 −8% · 0 −12%. 초보가 몰라도 막히지 않는 완만한 설계(장비 화면·결과 화면에 상태 표시).
- 수리 골드(완전 수리) = 등급 판매가 × 0.3 + 그 강화 단계 비용 × 0.6. 닳은 만큼만 낸다. 예: 스페셜 +0 약 420, 에픽 +10 약 3,270, 유니크 +15 약 11,280 골드. 강화가 높을수록 비싸져 후반 골드 잔액을 꾸준히 빨아들인다.
- 도입 근거: 대표님 요청(애착·소모처) + 던파의 수리 루프. 불이익은 최대 −12%라 진행을 막지 않는다. 서버 정산도 같은 `completeStage`로 닳는다.

### 인플레이션 확인 (`bun run sim:90d`)

- sim 모형: 판마다 카드 기댓값(관문 골드 × 0.55 + 강화석 1)을 더하고, 착용 무기 마모만큼 그 판에 수리 골드를 뺀다(`tools/sim-90d.mjs`, `CLEAR_CARD_SIM`).
- 결과는 아래 '검증'에 기록한다.

### D. 인게임 가방 (전투 중, 일시정지 없음)

- HUD 가장자리 '가방' 버튼 + 새 득템 배지(다른 영웅 장비는 ◆). 오른쪽 가장자리 시트: '이번 판' / '전체 가방' 탭, 비교 한 줄, 다른 영웅 꼬리표. 보기 전용(장착·판매·강화는 결과 화면 정비소에서). 플레이 영역 중앙을 가리지 않는다.

### E. 동료 네브

- 머리 위 작은 이름표. 첫 전투에서 한 번 왼쪽 위 가장자리 소개 띠: 초상·'네브 · 여섯 번째 증인'·역할·획득 경로('이야기 동료 · 처음부터 함께(무료) · 로비 네브 버튼으로 대화·전술 변경'). 일시정지 메뉴에서 다시 보기.
- 네브는 이야기 동료라 유료 판매하지 않는다. 앞으로 유료 동료를 만들면 상품 id만 정하고 BM 레인에 넘긴다(가격 공개 금지). 이번 범위에서는 만들지 않는다.
