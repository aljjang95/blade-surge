# 유리 정원 소품 키트 실제 화면 점검 (2026-10-21)

- 환경: 로컬 Vite 개발 서버 + Chromium(SwiftShader, 소프트웨어 렌더) 844×390 터치 에뮬레이션, 렌더 품질 높음(LOD0). 실제 Android GPU·터치·발열 증거가 아니다.
- 흐름: 부팅 → 모달 닫기 → 로비 던전 입구 → 출격 준비 → 유리 정원 기본 원정 시작. 영웅은 QA 스크립트(`tools/glass-garden-decor-qa.mjs`)가 방 가장자리 근처에 직접 놓았다.
- `props/`: 소품 종류마다 첫 배치 앞 3.4 m에서 게임 카메라로 찍은 화면. `rooms/`: 방 1·3(일반), 방 2(보물), 방 4(보스) 가장자리.
- `draw-calls.json`: 같은 프레임을 한 동기 호출 안에서 장식을 켠 채·끈 채 그려 잰 draw call·삼각형 차이(5개 방 × 5지점, 요약은 `summary`).
- 적과 영웅의 시야·이동 영역은 장식과 겹치지 않는다(여유 규칙 검증은 `test/glass-garden-decor.test.ts`).
- 스크린샷·`draw-calls.json`은 무리 대형 여유 규칙을 넣기 전 배치(58개)에서 찍었다. 이후 배치는 40개로 줄었고 같은 소품·같은 재질이라 draw call은 이 값 이하다(재측정은 하지 않았다).
