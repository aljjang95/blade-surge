## 1. 결론 한 줄

**15세이용가로 신청한다(내용정보: 폭력성).** 12세가 나올 여지는 있으나(혈흔은 장비 세트 발동 때만 나오는 0.5초 붉은 핏방울 입자), 판타지 무기 전투가 주 내용이고 붉은 '피의 폭발' 연출이 있어 15세가 국내 동종작의 기본값이다. 15세로 신청하면 반려·재심의 위험이 가장 낮고, 웹(게임위)과 Play(IARC) 결과를 같은 답으로 맞추기 쉽다.

- 왜 청소년이용불가가 아닌가: 사람형 대상 잔혹 묘사·신체 훼손·사실적 출혈이 없다. 이용자 간 현금 거래·환전·경품이 없다(사행성 청불 사유 없음).
- 왜 전체·12세를 노리지 않는가: 12세를 노리려면 `blood_burst` 연출을 빼고 재심의 위험을 감수해야 하는데, 얻는 이득(13~14세 이용자)보다 일정 위험이 크다. 대안은 4장.

## 6. 지금 운영 중인 웹의 위험과 조치

- 법 제32조는 등급분류를 받지 않은 게임물의 **유통·이용 제공**을 금지한다. 제21조 면제는 '영리 목적이 아닌 게임물', '개발 과정 시험용(확인증 필요)' 등이다.
- 현재 웹은 **결제가 꺼져 있다**(`IAP_ENABLED=false`, `WEB_BILLING_ENABLED` 꺼짐, BM_HANDOFF #7·#12). 유료 판매가 없으므로 위험은 낮지만, 광고·가격 노출·확률 소환 유료화가 붙는 순간 영리 제공이 명확해진다.
- **조치(게이트로 고정):** 등급분류 결정서(등급분류번호)를 받기 전에는 웹 결제·Play 프로덕션 결제·가격 공개를 열지 않는다(RELEASE_CHECKLIST G1). 공개 마케팅도 결정서 뒤.
- 결정서를 받으면 `src/data/game-rating.js`의 `status:'rated'`, `age`, `number`, `date`, `descriptors`를 결정서 그대로 고치고 `index.html #boot-rating` 문구를 같게 맞춘다(테스트가 둘을 대조).

## 7. 확인 못 한 것 (GCRB 확인·후속)

1. 웹 브라우저 게임의 플랫폼 분류(PC/온라인 vs 기타) — 수수료 기초가액이 달라진다. 신청 화면 선택지로 확정(담당 기관은 GCRB로 확정).
2. 2026-11-02 이후 수수료표 개정 여부 — 조견표(2013-02-07 적용 표기)로 추정했다(GCRB_APPLICATION 4장).
3. 플레이 영상 길이 요구 — 명문 없음. 내용정보 체크 항목이 모두 나오게 2~3분 본편 + 항목별 장면.
4. 별표 3 등급 표시 규격의 현행판(웹/모바일 크기).
