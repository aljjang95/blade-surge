# 장비 외형 아트 계획 (gear-appearance-avatar.md 5절 요청분)

요청: `docs/gear-appearance-avatar.md` 5절. 코드 레인(#239)이 등급 윤곽광·아바타 시착·외형 토글을 끝냈다. 실루엣 차이는 아트가 필요하다.
