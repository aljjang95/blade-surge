# 다섯 왕의 마지막 약속

자정마다 어제가 지워지는 세계에서 네브만 일행을 기억한다. 네 영웅은 다섯 지역의 수호자를 해방하며 기억을 되돌린다. 수호자들은 원래 동료였고, 재앙을 막으려고 만든 왕관에 각자의 약속이 뒤틀린 채 속박되었다. 마지막에는 네브를 희생시키는 기존 계약을 거부하고, 사람들이 서로의 기억과 책임을 나누어 순환을 끝낸다.

아트 기준은 별도 제작 작업 `TLL 3D MODEL Blender MCP`의 성인 비율 아르카 원화다. 그 작업에서 확인된 영웅·네브 원화 5장과 무한의 성 키아트를 게임 초상화, 지역 소개, 시작 화면에 연결했다. 원화 기반 전용 GLB는 해당 작업에서 제작 중이다. 현재 전투 모델과 애니메이션은 기존 자산이며, 새 전장 구조·기믹·시나리오와 함께 작동한다.

| 지역 | 중심 인물 | 전장 기믹 | 중간 보스 | 최종 보스 | 되찾는 맹세 |
|---|---|---|---|---|---|
| 1 잊힌 종의 정원 | 아르카 | 동심원 공명 | 애도의 기사 세렌 | 종왕 에일른 | 이름을 부르기 |
| 2 불씨 왕국의 용광로 | 드라칸 | 가로·세로 화염 띠 | 대장장이 이그란 | 화왕 발드 | 온기를 나누기 |
| 3 거꾸로 흐르는 서리 도서관 | 리아 | 위치 기록 후 지연 폭발 | 기록관 오르딘 | 서리왕 이셀 | 진실을 남기기 |
| 4 별이 잠긴 심해 | 카인 | 순차 물결과 밀침 | 등대지기 마렌 | 해왕 네레이스 | 귀환을 믿기 |
| 5 새벽을 먹는 왕관 | 네브와 모두 | 대각선 십자 심판 | 첫 기사 아스텔 | 새벽을 먹는 빈 왕관 | 짐을 나누기 |

각 지역은 열 관문으로 구성한다. 3·7은 약한 보스인 수문장, 5는 중간 보스, 10은 지역 최종 보스다. 나머지는 관문 대장으로 전투 방 정리와 봉인 해제를 익힌다. 모든 50개 관문은 고유한 제목, 출격 장면, 사건의 진실, 네브의 클리어 대사를 갖는다. 모험 기록은 클리어한 장면만 공개한다.

## 런타임 데이터

- `stageDef(ch, st)`: 정수 범위 1–5 / 1–10만 허용하며 잘못된 인수는 RangeError다. 기존 waves, scale, rewards, rosterFor 필드를 보존한다.
- `stage.encounter`: rank, label, name, enemyId, tactic. enemyId는 theme_rank이며 기존 ENEMIES를 보존하면서 지역당 4종, 총 20종을 추가한다.
- `stage.story`: opening, revelation, aftermath. `stage.finale`는 5-10만 true다.
- `chapter`: name, theme, color, boss, tagline, summary, oath, mechanic{name, description}.
- `journalEntries(progress)`: 숫자 별 1개 이상인 스테이지만 code, ch, st, title, text, revelation, aftermath를 반환한다. text는 aftermath와 같다.
- `CAMPAIGN`: title, logline, ending 문자열. 결말 공개 시점은 UI가 최종 관문 클리어로 제한한다.

적의 pattern은 기존 전투 동사 spin/slam/summon/fan/soulrain/dash의 순서다. voiceKey는 기존 보스 보이스 자산만 참조하며 원화 기반 신규 음성 제작을 의미하지 않는다. 전용 외형은 별도 모델 검수 이후 승격한다.

기본 적 체력은 대장 13,000 / 수문장 19,000 / 중간 보스 27,000 / 최종 보스 35,000이다. 1층 배율은 1이며 20층까지 기존 1.12 지수를 사용한다. 이후 층당 20층 배율의 4.5%를 더하여 50층 배율 약 20.24로 제한한다. 이는 종전 30층 배율 약 26.75보다 낮다. 실제 장비 성장에 따른 체감 난이도는 플레이 검증 대상이다.

상세 50개 장면의 단일 원본은 `src/data/campaign-story.js`의 CHAPTER_SCENES다. 이 문서의 서사는 게임 장면을 복제하지 않으며 수정 시 해당 데이터부터 갱신한다.
