# 사용설명서 — 블레이드 서지 (공개용)

> PDF 생성 시 장면 캡처 8~10장(가로 1280x720, 운영 주소 https://blade.tllhouse.com 실제 화면)을 각 절 아래에 넣는다. 파일명 `shots/NN-장면.png`.

## 1. 시작하기
- 인터넷 브라우저(PC 크롬·엣지, 모바일 크롬·사파리·삼성 인터넷)로 https://blade.tllhouse.com 에 접속한다. 설치·회원가입이 필요 없다.
- 첫 화면(부팅)에서 이용약관·청약철회·환불·개인정보처리방침·고객센터·확률 정보 링크를 볼 수 있다. [터치하여 시작]을 누른다.
- [게스트로 시작]을 누르면 **게스트 계정이 자동 발급**되고 시작 영웅을 고른 뒤 바로 플레이할 수 있다. 시작 화면의 [Google로 계속]으로 계정을 연결하면 다른 기기에서 이어서 할 수 있다(선택).
- 캡처: `01-부팅` `02-로비`

## 2. 조작
| 동작 | PC | 모바일 |
|---|---|---|
| 이동 | W A S D | 왼쪽 조이스틱 |
| 공격 | J / 스페이스 | 오른쪽 공격 버튼 |
| 회피 | K / Shift | 회피 버튼 |
| 스킬 | 1~3, R, Q, E (1~6 번호 키도 스킬) | 스킬 버튼 |
| 자동 전투 | AUTO 버튼 | AUTO 버튼 |
- 캡처: `03-전투-조작`

## 3. 게임 진행
로비의 [출격]을 누르고 스테이지 선택에서 [입장]하면 던전에 들어간다. 캠페인 1-1이 첫 전투다. 몬스터를 처치하며 구역을 정화하면 보스 봉인이 풀리고, 보스를 쓰러뜨리면 장비·재료를 얻는다. 캡처: `04-던전전투` `05-보스전`

## 4. 성장·장비
영웅 레벨, 스킬 트리, 장비(무기·방어구·반지·신발) 드랍·강화·제작·세트 효과. 캡처: `06-장비`

## 5. 소환(확률형 아이템)과 상점
하단 [메뉴] → 상점·소환 → [소환]에서 소환권 또는 보석으로 영웅·장비를 소환한다(무료 보석이 먼저 쓰인다). 소환 화면의 [i 확률 정보]에서 등급별 확률·천장 규칙을 볼 수 있고 https://blade.tllhouse.com/odds 에도 같은 내용이 있다. 이용자 간 거래·환전은 없다. 등급분류 결정 전에는 유료 판매를 하지 않는다. 캡처: `07-소환` `08-확률정보` `09-상점`

## 6. 소통
하단 [메뉴] → 시스템 → [커뮤니티]에서 채팅(광장 채널)·친구·파티 모집·명예의 전당을 쓸 수 있다. 채팅은 닉네임을 정한 뒤 이용하며, 금칙어는 별표로 가려지고 인터넷 주소는 [링크]로 바뀌며 차단·신고 기능이 있다. 캡처: `10-채팅`
