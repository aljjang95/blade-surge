## 3. 설계

### 3.1 전설 수련(Legend Rank) — 끝이 없는 성장 축
- 대상: 영웅 Lv.80 이후 EXP. 계정 공통(영웅을 바꿔도 유지 — 8시간 플레이어가 여러 영웅을 키우게 만든다).
- 단계 r → r+1 필요 EXP = `LEGEND.baseExp × (1 + r × LEGEND.growth)`(선형 증가). 상한 없음(저장은 정수 상한 `MAX_COUNTER`로만 막는다).
- 단계마다 점수 1. 점수는 네 갈래 판에 넣는다: **칼날**(공격·치명), **철벽**(체력·방어·회피 회복), **폭풍**(몰이 반경·진공 세기·재사용 대기), **약탈**(골드·드랍 확률, 상한 있음). 갈래마다 노드 6개, 노드는 1~20단계, 단계 효과는 체감 감소(`eff × r / (r + k)`). 5단계마다 갈래 키스톤 하나가 열린다(전투 동사를 바꾸는 것만 — 예: 폭풍 키스톤 "진공 끝에 작은 회오리가 1초 남는다"). 스탯만 늘리는 키스톤 금지.
- 점수는 언제든 무료로 재분배(골드 비용, 재련처럼 골드 싱크).
- 순수 규칙: `src/game/legend-rank.js` — `legendExpFor(rank)`, `grantLegendExp(state, amount)`, `legendStats(state)`, `allocate(state, nodeId)`, `respec(state)`. Economy 정산 트랜잭션 안에서만 상태를 바꾼다. 저장 키 `legend: { rank, exp, points, nodes: {} }`, 마이그레이션은 기본값.
- 서버 권위: `shared/` 정산과 같은 함수를 쓰게 둔다(지금 서버 명령이 없는 로컬 필드는 `endgame`처럼 `PARITY_KEYS`에 넣지 않는다 — CONTENT_90D 5.1 이유 그대로).

### 3.2 고통 단계(Torment) — 에너지 없이 끝없이 도는 난이도
- 지옥 다음 난이도. T1은 아무 지역 지옥 10관문 클리어 시 열리고, T(n+1)은 Tn에서 지역 최종 보스(X-10) 클리어로 열린다. 최대 T50(데이터 상한).
- 배율: 적 체력·공격 = 지옥 × `1.17^n`, 보상 = 지옥 × `(1 + 0.08n)`, EXP = 지옥 × `(1 + 0.1n)`. 단계가 오를수록 상급·전설 강화석·초월석·룬 가중(`loot-tables.js`가 자동 생성하는 구조 재사용).
- **에너지 0**. 대신 보상 감쇠: 하루 첫 N판(`TORMENT.fullRuns`)은 보상 100%, 그 뒤 판은 골드·재료 35%이고 EXP(→전설 수련)는 100%. 그래서 8시간 플레이어는 남는 시간을 전설 수련으로 바꾸고, 짧게 하는 플레이어는 손해가 없다.
- 순수 규칙: `src/game/difficulty.js`에 `torment` 항목과 `tormentScale(n)`; 기록은 `endgame.torment = { best, today: { day, runs } }`.

### 3.4 시뮬레이터 확장(S1~S5 증명)
- `PERSONAS.marathon = { minutes: 480, sessions: 4, skill: .85, enhCap: 20, towerShare: .3 }`.
- 하루 시간 배분 순서: 일일·주간 임무 → 새 캠페인/난이도 관문(에너지) → 탑(주간 상한까지) → 고통 단계 최고 단계 도전 → 남은 시간 고통 단계 반복(감쇠 보상 + EXP→전설 수련). 이 순서에 넣을 것이 없는 분이 `idleMin`.

- 전설 수련·고통 단계 전투력은 진행 판정(`POWER_NEED`)에 넣되 CONTENT_90D 4.5의 '보너스층 제외' 원칙과 충돌하지 않게 S5 몫 밴드로 상·하한을 건다.

## 5. 결정과 다른 선택지
- 끝없는 축을 **전설 수련**(계정 공통 판)으로 고른 이유: 8시간 플레이어의 남는 시간을 확실한 진행으로 바꾸면서, 판 효과에 체감 감소를 걸어 장비·강화가 계속 주력이 된다. 다른 선택지: 영웅 레벨 상한 상향(80→200, 기존 밸런스 전부 재조정 필요라 기각), 무한 강화(+20 이상, 파괴 체감이 커서 기각).
- 고통 단계를 **에너지 0 + 하루 N판 뒤 감쇠**로 고른 이유: 에너지로 막으면 8시간이 불가능하고, 감쇠 없이 열면 재화 인플레이션(CONTENT_90D 4.4)이 깨진다.
- 지역을 **시간 개방**으로 고른 이유: 60관문을 한 번에 열면 8시간 플레이어는 1주 안에 소비한다. MMO_DESIGN 7.5 달력과 같은 주에 맞춘다.
