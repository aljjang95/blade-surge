# 아스트랄 일반 — 네 조율판 후보 계약

통합 기준: `0cf61344eccfa08a05bc77303d7f1c1c87114cda`. 준비 clone의 기준은 `ee010979ac01c94493d35ca37536428081fac300`이었다. 플레이 기록·재도전 개선이 배포된 main에 통합한 예비 전체 검사에서 1,349개 통과·2개 skip·0개 실패를 확인했다. 최종 clean commit 검사는 별도 증거로 남긴다. 실제 자연 레벨 획득·Astral 플레이·작은 화면 가독성·성능·릴리스 승인은 아직 하지 않았다.

## 고정된 범위

`astral_leviathan_spire` / `standard` / solo dungeon에만 네 조율판을 추가한다. 기존 방 구조, 적·보스 수치와 패턴, 입장 조건, 에너지, 보상, 재화, 해금, 깊은 난이도, party/rift/conquest는 바꾸지 않는다. 방 1→3→4→6을 순서대로 복원하며 모든 조율판과 세 선택판은 보스 봉인 밖의 실제 통행 지도에서 도달 가능해야 한다. 네 조율판 방은 중앙 장식 슬롯에서 제외하는 기존 `objectiveProp` 훅을 사용한다.

각 조율판은 번호와 이름, 세 선택판은 도형과 문자로 구분한다: A △ 삼각, B ○ 원, C ◇ 마름모. 색만으로 정답을 구분하지 않는다. 고정 단서 순서는 1번 A △, 2번 C ◇, 3번 B ○, 4번 A △다. 정답은 코드 내부 보상·secret에서 읽지 않고 현장 모래시계 단서 및 기존 HUD에 먼저 보여 준다. 무작위 퍼즐/새 장비/경제는 이 후보 범위가 아니다.

## 실제 입력과 상태 계약

- 기존 방 적, 지연 생성, 증원 영수증이 모두 끝나야 단서·선택이 열린다. 주인공 22m 안의 살아 있는 적(다른 방 추격 적 포함)의 실제 혼전 중에도 단서와 선택판을 숨기고 읽기·선택 시간을 초기화한다.
- 현재 조율판 8m 안에서 공격/스킬/회피/피격 없이 단서를 1초 읽으면 선택 단계가 열린다. 세 선택판 중심은 조율판 기준 좌(-3.5, 0), 전(0, 3.5), 우(3.5, 0)m, 판정 반경 1.2m다. 도형 표시·판정·AUTO 목적지가 같은 좌표를 사용한다.
- 정답 도형 안에서 안정된 상태로 1초 유지하고 다음 유효 프레임까지 행동/피격이 없으면 해당 조율판을 한 번만 복원한다. 마지막 유지 프레임 후반의 피격도 확정을 취소한다. 오답도 같은 1초+다음 프레임 확인 뒤 이유를 표시하고 현재 읽기/선택을 초기화한다. 모든 선택판 밖으로 나와 단서를 다시 읽으면 재시도할 수 있다. 오답은 추가 피해·재화·경험치·보상을 만들지 않는다.
- 판 밖 이동은 선택 유지 시간을 초기화한다. 공격/스킬/회피/피격/일시정지/전투 재개는 현재 읽기와 유지 시간을 초기화한다. 이미 복원한 조율판은 현재 출격 안에서 보존된다. 패배·중단·새 출격은 다른 인스턴스로 시작하며 0/4로 돌아간다.
- 4/4만으로 봉인을 열지 않는다. 시작/보스 외 모든 방 정화도 필요하다. 승리는 기존 보스 처치, 열린 봉인, 보스방 정화 및 위 조건을 모두 확인한다. 기존 `markCleared`/승리/결과 정산 경로를 사용하고 별도 보상·중복 정산 경로를 추가하지 않는다.
- 적 정화가 끝난 미복원 조율판 방은 기존 `ownsHazards` 훅으로 일반 서리 원을 중단하여 선택을 예고 없는 피해 시험으로 만들지 않는다. 기존 AUTO 훅은 현재 미복원 조율판을 유지하고 단서 공개 후 정답 판으로 이동한다. 실제 입력 QA는 키보드 이동/공격/회피와 생산 입력 상태를 사용하며 조율판 상태, 방 정화, 적 생존, 보스 HP를 직접 조작해 통과시켰다고 주장하지 않는다.

## 시각 및 수명 계약

소유한 primitive mesh, 정적인 캔버스 문자와 도형, 모래시계만 사용한다. 카메라 shake, 화면 pulse/noise, 추가 render target, 네트워크/유료 생성 요청은 없다. 미발견 방은 숨긴다. 혼전 중 단서·선택은 숨긴다. 정지/결과/늦은 prepare 이후 잔존 모델·텍스처를 만들지 않으며 소유 geometry/material/texture를 한 번만 dispose한다. 휴대폰 문자/도형 가독성은 실제 화면 검증 전까지 미확인이다.

## 원안의 남은 영역

원래 지역 계획 중 시간 압박·보스와 조율판의 상호작용, 깊은 난이도의 별자리 복원, 다른 지역의 고유 기믹은 이 후보에서 구현하지 않는다. 기존 레비아탄 모래시계 보스 패턴을 새 선택 퍼즐로 설명하지 않는다. docs/content-integrity-status.md에 부분 구현으로 표시하고 금지 instruction 검사는 실제 구현된 일반 난이도의 정확한 문구만 허용한다. 다른 지역 및 깊은 난이도의 금지 regex는 유지한다.

## 검증 준비 / 아직 NOT_RUN

의미 있는 회귀: stage 범위, 네 방/세 판 도달성, 단서 선행, 정답·오답·공격/회피/피격/일시정지 초기화, 지연 생성·인근 혼전 표시 중단, 4/4+전체 정화 봉인/승리, 보고서 불변·중복 방 정산, 모델 상태와 disposal. 실제 입력 helper는 고유 출력 폴더를 요구하고 앱의 일반 던전 입장 및 재출격을 사용한다. 계정 레벨 3의 합법적 저장자료가 필요하며 unlock/레벨을 몰래 올리지 않는다. 타입/회귀/실제 입력/browser/build/formal metrics는 root가 순차로 허용·실행하기 전까지 모두 NOT_RUN이다. ## 세로 화면의 통합 전제 갱신

초기 두 후보는 실제 세로 화면에서 발판·문자·단서가 잘려 시각 반려됐다. 기존 카메라 불변 제한은 `docs/astral-portrait-framing-contract.md`의 정확한 성운 첨탑 기본/solo 세로 aspect 보정으로 대체한다. 다른 경로/깊은 난이도/가로 구도·사용자 방향/설정·판정 좌표·게임 규칙은 유지한다. 이전 시각 반려와 원본은 보존하고 새 후보의 실제 화면·입력·완주·해제·성능을 새로 검증한다. 실제 보기에는 생산 렌더러가 native RAF의 실시간 간격으로 구도를 정착시키되 게임 tick은 진행하지 않고 위치·체력·선택·경과·재화·결과가 그대로인지 검사한다. 이는 고정 게임 상태의 화면 증거이며 물리폰/실시간 전투 성능이나 공격 순간 가독성을 대신하지 않는다. AUTO 기능 검증은 매 50ms 게임 tick을 모두 실행하면서 소프트웨어 GPU 그림만 간격을 두어 그리며, 모든 관찰 시점은 현재 실제 GPU 프레임을 그린다. 정식 성능 측정의 renderEvery=3 및 엄격한 5쌍 게이트는 바꾸지 않는다.

## 기록 외곽 고리 이탈 (BUNDLE-13, 2026-10-16)

원안의 마지막 문장 "기록 파편이 모이면 외곽 고리로 이탈"을 구현했다. 위 네 조율판 계약은 바뀌지 않고, 봉인 조건에 고리 완료가 더해진다.

- 정의: `ROUTE_OBJECTIVES.astral_standard.ring`(방 7, label '기록 외곽 고리', title '외곽 고리 이탈', mark '항로 표지', shard '기록 파편'). 규칙은 심층 성좌 외곽 고리와 같은 공용 엔진 `src/game/astral-ring-constellations.js`(`AstralRingConstellations`, `AstralConstellations` 상속)이고 심층 `AstralDeepConstellations` 는 그 빈 하위 클래스다. 문구는 정의의 낱말을 고정 틀(BUNDLE-13 PLAN 3.1)에 끼워 만든다.
- 4/4 와 시작·보스방을 뺀 모든 구역 정화 뒤 다음 갱신에 보스 앞 정예방(일반 지도 28×28)에 고리가 열린다(그 스텝 clock 0). 방 사각형 안에 들어서면 '외곽 고리 이탈 시작 · 24초'. 항로 표지 4개(방 중심 기준 서·북·동·남 6, 순서 자유, 반경 1.4 안 연속 1초)를 모두 밝히면 '외곽 고리 이탈 · 레비아탄의 봉인이 풀립니다'와 함께 봉인이 풀린다. 같은 스텝이면 완료가 붕괴·집결 피해보다 먼저다.
- 기록 파편 집결: 열린 뒤 1.5초부터 5초 주기로 예고 2초(파편 6개가 중심으로 모이고 주황 경계) → 터짐 .5초(주황빛 빨강 섬광). 터지는 동안 중심 반경 3.2 안(경계 포함)이면 집결마다 한 번 최대 체력 4%(영웅 방어로 줄고, 회피 무적 등으로 흡수되면 피격으로 세지 않음). 시간이 다 되면 고리 붕괴(4%, 표지 0/4, 24초 다시). 어느 실패도 진행을 막지 않는다. 고리가 열린 동안 고리 방의 일반 위험은 멈춘다.
- 심층(성표 4개·20초·예고 1.5초·core 3.4·6%)보다 너그럽다. 처음 정한 반원 3개(서·북·동)는 가장 가까운 표지부터 가는 AUTO 가 반원 양 끝 사이로 중심을 가로질러 모의 1126판 중 108판 피격해, 심층과 같은 정사각 4개로 바꿨다.
- AUTO: 조율판은 기존 AUTO, 고리는 가장 가까운 미점등 표지(같은 거리면 서·북·동·남 순). 단위 모의(실제 일반 Floor, 1/60초, 열린 스텝 바로 다음 걸어서 출발)에서 방 7 안 1m 격자 558점과 방 6·5·4·3·1 중심 × 속도 5.6·7.2 의 1126판이 모두 피격·붕괴 0 으로 완료했다(리뷰가 스프린트·실제 프레임 순서를 넣어 다시 돌려도 통과).
- 결과: 기존 '별자리 복원 4/4 · … · 오답 n회' 줄 + '외곽 고리 이탈 완료|미완료 · 항로 표지 n/4 · 기록 파편 피격 n회 · 붕괴 n회'(aria '외곽 고리 이탈 결과'). 보고에 `ring { purified, marks, collapses, shardHits, seconds }`가 더해진다.
