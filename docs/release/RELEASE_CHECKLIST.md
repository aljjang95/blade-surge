## 대표님 할 일 (순서)
1. 게임위 1377: "웹 브라우저 게임(PC 온라인) 등급분류 신청 기관이 게임위가 맞는지" 확인.
2. 게임위 업체 회원 로그인 → 신청서에 GRAC_APPLICATION.md 내용 입력, 등록증·사업자등록증 첨부, 영상 첨부 → 수수료 확인·납부 → 제출.
3. Play Console → 콘텐츠 등급 → IARC_ANSWERS.md 대로 입력 → 제출.
4. 결정서가 오면 등급분류번호를 알려 주시거나 문서를 Drive에 두면 에이전트가 표시 반영·배포.
