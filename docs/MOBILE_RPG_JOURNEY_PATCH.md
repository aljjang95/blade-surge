# 모바일 RPG 성장 여정 패치

기준 배포: `679136720d24f3b5af42db9a0c3d8bcc8def671e`. 기존 KayKit 모험가 5종, 스켈레톤 4종, Blender MCP 제작 실바, 맵·방어구·Flow 미디어·각인·숙련은 유지한다.

## 조사와 선택

2026-09-10 Codex IAB에서 공식 페이지와 조사 기관의 원문을 확인했다. 모든 역대 RPG의 순이익을 알 수 있다는 의미가 아니다. 공개 매출 성과가 있는 대표작을 조사하고, 브라우저 RPG의 설계 사례를 별도로 참고했다. 매출은 순이익이 아니며, 개별 기능의 매출 상승 인과관계도 이 자료만으로 증명되지 않는다.

세 대안은 콘텐츠 수량 추가, 온라인 길드·경제 확장, 기존 전투와 성장 경로 연결이었다. 현재 저장·전투 구조, 사용 가능한 무료 에셋, 추가 서버 비용을 고려해 세 번째를 선택했다. 기존 기능과 중복하는 엔진 없이 실제 플레이 목적과 반복 편의를 함께 보강한다. 다른 게임의 캐릭터·음원·이미지는 복사하지 않는다.

## 구현 계약

- 영속 성장 여정 6단계: 서약→정원→제작→갑옷 장착→장착 장비 강화→영구 숙련. 실제 저장 상태로 판정하고 순차 1회 수령한다.
- 일일 의뢰 3개, 주간 의뢰 2개: 실전 던전 승리와 지정 지역·서로 다른 지역 방문을 추적한다. 한국 시간 매일 05:00, 매주 월요일 05:00 기준. 소탕·AI 결투·패배는 실전 던전 의뢰에 포함하지 않는다.
- 날짜와 주차는 단조 증가한다. 시작 시점의 기간을 전투 영수증에 묶어 늦은 정산이 다음 날 의뢰로 넘어가지 않게 한다. 현재는 기기 시계 기반 로컬 저장이며 서버 시간·온라인 부정행위 방지를 주장하지 않는다.
- 철갑/맹공/포위 균열: 해당 날짜의 지정 던전에서 선택 가능. 적 체력·공격력에 실제 적용되고 기존 균형 붕괴·회피·각인과 함께 동작한다. 기본 보상 외 골드 200, 해당 재료 2개. AI 결투에 적용하지 않는다.
- 목표 장비 추적: 기존 확정 제작식, 실제 인벤토리 UID, 재료 부족량, 일반 던전 기준 예상 횟수, 골드 부족량, 현재 착용 영웅을 표시한다. 제작과 장착 이후 상태를 재계산한다.
- 재료 소탕 1~3회: 실전에서 클리어한 던전만 가능. 회당 에너지 4·소탕권 1 차감. 미리 표시한 골드·원정 경험치·재료·물약만 지급한다. 원정 레벨업 골드는 기존 규칙에 따라 별도 발생한다. 장비 추첨·영웅 경험치·전투 의뢰·각인/서사 보상은 지급하지 않는다.
- 모든 신규 수령·정산·장착은 공방 거래의 저장·실패 복원·복구 백업을 사용한다. 소탕은 중첩 저장 없이 한 번에 정산한다.
- AUTO 선호를 저장하며 사용자가 전투 중 변경할 수 있다. 각인·서사는 직접 선택해야 한다.
- 세로 화면에서 체력·경험치, 전투 메뉴, 위험 알림과 네브 대화 버튼의 위치를 정리했다. 열린 성장 화면을 자동 팝업이 가리지 않으며 로비의 무작위 스타터 결제 팝업을 제거했다.

## 검증 기록

전체 검사: Bun 1.4.2에서 328 tests / 8,976 assertions / 37 files 통과. TypeScript 검사와 Vite 운영 빌드 통과. 신규 코어·거래·화면 테스트 25개는 기간 경계·중복 수령·저장 실패 복원·정확한 소탕 차감·장비 이전·균열 규칙과 재도전을 검증한다.

Codex IAB에서 저장값 주입 없이 신규 저장으로 기사와 실바를 플레이했다. 성장 여정 6단계를 완료하고 같은 갑옷을 제작·장착·+1 강화한 뒤 기사에서 실바로 이전했다. 소탕 3회는 에너지 12·소탕권 3을 차감하고 표시된 고정 보상과 원정 레벨업 골드만 지급했으며 영웅·장비·실전 의뢰 기록은 변하지 않았다. 재접속 후 성장·장비·AUTO 저장값도 일치했다.

유리 정원의 일반 원정·철갑 균열·균열 재도전과 잿불 금고·별빛 서고에서 실제 7승을 기록하고 일일 3개·주간 2개 보상을 모두 수령했다. 마지막 주간 보상은 골드 3,000과 각 지역 재료 3개씩 정확히 지급했다. 철갑의 적 체력 배율과 재도전 시 균열 보존, 기본 재료 3개에 추가 2개 지급을 확인했다. 화면 검증은 데스크톱 및 390×844 세로 IAB에서 수행했으며 실제 휴대전화의 발열·배터리·장시간 성능 검증으로 간주하지 않는다. 개별 전투 결과·최종 보상 수령·운영 SHA 및 배포 아티팩트 검증은 작업 폴더의 `outputs/mobile-rpg-upgrade/` 릴리즈 기록에 보관한다.
