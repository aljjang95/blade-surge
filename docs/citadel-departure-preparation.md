# Physical gate departure preparation

Walking to a lobby dungeon gate previously offered only a standard departure. Existing deep routes were reachable through a separate expedition menu, and the gate omitted the hero, potion stock and saved personal-goal conditions.

Each physical dungeon gate now offers standard/deep selection using the existing authored definitions and dungeonAccess policy. A locked deep route can be inspected, but its departure stays disabled. The screen shows the actual energy cost, objective, fixed clear rewards, conditional first deep-clear bonus, applicable standard frontier, selected hero/control, shared U/I/O stock and exact personal-goal comparison conditions. The existing journal opens from the gate to inspect or choose a goal. Preparation does not reserve or consume potions, grant rewards, or relax goal comparisons.

Departure still calls only startExpedition('dungeon', id, { depth }); existing ticket, save, refund and settlement authorities remain in place. The dialog preserves native radio/focus state, scrolls its content and keeps its departure controls visible.
