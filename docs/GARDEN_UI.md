# 성채의 정원 UI

2026-10-08 사용자가 실제 성채 화면 기반 시안 적용을 승인했다. 두 번째 시안의 가벼운 옥색 HUD와 원형 메뉴 배치에 첫 번째의 상아색 수첩 질감을 결합한다.

## 구현

- 상단 영웅 정보와 실제 재화를 둥근 작은 패널로 표시한다.
- 하단 메뉴는 중앙의 떠 있는 독으로 만들고, 성장·메뉴에 기존 자체 제작 그림을 연결한다.
- 가까운 입구 안내를 오른쪽에 두고 따뜻한 종이 재질로 표시한다. 세로에서는 하단 너비에 맞춘다.
- 메뉴·출격 준비창의 프레임과 버튼에 같은 옥색·금색 재질을 적용한다.
- 시점·동행·이동 조이스틱과 기존 입구 접근·잠금·정산 조건을 유지한다. 실제 이름과 숫자는 DOM 텍스트다.
- 다른 탭은 새 독 높이만큼 콘텐츠 공간을 확보한다. 화면 중앙의 이동 경로를 장식 패널로 덮지 않는다.

`src/ui/garden-ui.css`가 기존 스타일 다음에 로드되는 표현 계층이다. 신규 모델·배포 이미지·프레임 루프·저장 필드를 추가하지 않는다. 재질은 CSS로 구현하고 기존 그림 원본과 캐릭터 외형을 보존한다.

## 검증과 한계

검증 기록은 `work/dogfood/garden-ui-20261008/`에 보존한다. 동일한 새 저장·자연 프레임 조건에서 데스크톱 1280×720, 가로 터치 844×390, 세로 터치 390×844를 확인하고, 320×740에서 재화 잘림을 추가 확인한다. 일반 입력 QA와 컨셉 이미지는 별도 근거다. 브라우저 크기 및 CDP 터치는 물리 Android·발열·GPU 프레임·음성 품질의 증거가 아니다.

초기 탐색에서 320px 재화 잘림을 수정했다. 독립 검토가 지적한 다른 탭의 하단 콘텐츠 겹침은 breakpoint별 여백으로 보정했다. 장식 아이콘은 포인터 대상에서 제외하고 고정 메뉴 버튼에서는 브라우저 스크롤 제스처를 사용하지 않는다.

초기 가로의 짧은 CDP 이동→해제→즉시 탭에서는 버튼 down/up 이후 click이 빠졌다. 포인터 기본 동작 취소만으로는 조이스틱의 touchstart가 브라우저 탭 인식으로 전달되는 경계를 막지 못했다. 활성 조이스틱이 소유한 취소 가능한 touchstart만 취소하며, 다음 메뉴의 네이티브 click·키보드 활성화는 유지한다. `tools/garden-ui-qa.mjs`는 이동 0.1 초과 직후 바로 해제하고 메뉴를 누르는 원래 조건을 유지하며 터치 화면마다 5회 반복한다. 실제 결과와 이전 실패는 `work/dogfood/garden-release-20261008/`에 기록한다. 브라우저 내부 제스처 인식 원인과 물리 기기의 재현은 별도 한계다.

원격 main의 최신 선택형 출격 계약을 통합했다. 홈에서는 12개 던전 선택·준비를 제공하고, 마을 둘러보기에서만 이동한다. 출격 카드에도 수첩 재질을 적용하고 카드 패널과 하단 독 사이 공간, 마을 복귀 버튼과 위치 안내의 분리를 확보한다. 기존 준비·잠금·소비·저장 서비스와 원본 포털을 보존한다.

스타일 복구는 새 CSS import를 제거하고 성장·메뉴의 장식 아이콘 추가를 되돌리는 두 영역으로 한정된다. 이 문서는 공개 배포·전체 RSI 성능 밴드 통과를 주장하지 않는다.
