# Oath Hall Visual V1 — 로비부터 전투까지

## 이번 적용 범위

기존 SD 영웅과 전투/성장 시스템을 보존한 첫 그래픽 후보다. 전체 RPG 콘텐츠 또는 모든 지역을 새로 만들었다는 뜻은 아니다.

- 실제 Blender 5.2.1 LTS 편집 원본과 8개 재질 배치 GLB를 로비에 연결한다.
- 회녹색 석재 단상, 아치, 절제된 문장 깃발과 조경/원경을 사용한다.
- 로비 영웅을 가리던 버튼들을 메뉴로 묶고 우측 모험/출격과 하단 탐색을 구분한다.
- 원래 메뉴 버튼을 이동하므로 기존 클릭 동작과 결제/해금 정책을 보존한다. 추가 상품 안내도 접힌 영역에서 접근한다.
- React 소유 네브 버튼은 원래 부모에 두고 조작 영역만 정리한다.
- 원본 모델을 고치지 않고 검성 인스턴스의 복제 재질에서만 천/피부/금속 반응을 조정한다.
- HP/MP/EXP, 여섯 스킬과 회피/공격 매핑을 유지한다. 성장 정보와 시점 보조는 펼쳐 볼 수 있다.
- 화면 전체 방사형 블러/색수차 출력을 끄되 전투 시계, 피해, 국소 타격 표현은 바꾸지 않는다.

## 실패/접근성/자원 경계

전당 로딩 실패는 기존 전당으로 대체하고 부팅을 막지 않는다. 원래 소스는 캐시로 보존하고 로비별 복제 지오메트리/재질만 회수한다.
메뉴를 Escape 또는 닫기로 나가면 보이는 트리거로 포커스를 복원한다. 메뉴에서 여는 다른 모달의 포커스를 가로채지 않는다.
원본 영웅 형상/헤어/뼈대/클립 바이트 보존 및 10회 전투↔로비 자원 검사를 실행한다.
