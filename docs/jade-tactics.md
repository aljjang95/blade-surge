# 유리 정원 환경 전투와 공통 전장 표현

## 이번 회전의 계약

기준 공개판은 `ccd41255f58c17b105882260a66dfcf3d97beadc`다. 넓은 단색 타일과 반복되는 중앙 원형 장식 때문에 방의 목적과 영웅의 실루엣이 약하게 읽혔다. 이번 회전은 실제 전투 공간에 선택 가능한 환경 행동을 추가하고, 지형·캐릭터·HUD가 그 행동을 함께 설명하도록 한다.

- 공통 방과 복도에는 실제 이동 구조에 맞는 문턱·동선·방 역할의 표현을 적용한다. 유리 정원은 상아색 석재와 짙은 옥색을 중심으로 구성한다. 이동 마스크와 방 연결을 장식으로 바꾸지 않는다.
- 다섯 영웅에는 기존 얼굴·리그·무기·직업을 보존한 Blender 제작 등·어깨 장식을 맞춘다. 기존 재질 그룹으로 합쳐 영웅의 렌더 제출 수를 늘리지 않는다. CC0 원본과 자체 제작 파생물의 출처를 유지한다.
- 전투 UI는 상태·현재 행동·지도·조작의 우선순위를 분명히 한다. 지도 지형에는 발견한 정보만 표시한다. 기존 보스 방향 단서는 별도 범례로 구별하고 미발견 방의 정확한 위치·거리·구조를 공개하지 않는다. 실제 획득한 각인 선택과 기존 수동 콤보 입력 피드백은 유지한다.
- 기본 유리 정원의 전투방 3에서 `집결`과 `방출` 중 하나를 사용할 수 있다. 장치 근처에서 F 또는 문맥 버튼으로 입력하며, 두 장치는 방당 한 번의 사용 기회를 공유한다. 추가 의무 목표나 보상은 아니다.

## 환경 행동의 권한

`MapTactics`가 선택·사용 기회·입력 가능 구역·단계·실제 제어 대상을 관리한다. 화면과 장치는 읽기 전용 스냅샷을 표시한다. 성공한 수동 입력 순간 사용을 확정한다. AUTO는 사용하지 않는다. 범위 안 대상이 없으면 거절하고 사용 기회를 유지한다.

대상은 표시된 반경 6 안의 같은 방 소속 생존·생성 완료·비보스 적이다. 0.35초 예고 후 집결은 0.6초 동안 조작판에서 방 중심 쪽으로 2m 떨어진 지점으로 끈다. 기존 `Enemy.pull`에 `30 × dt`를 전달하며 중심 0.8m의 정지 영역은 대상에서 제외한다. 방출은 바깥쪽 충격 14를 한 번 전달하고 정예 0.5배·갑옷 0.6배 저항을 유지한다. 기존 벽 충돌을 통한다. 피해·기절·능력치·정화 수·봉인·재화를 추가하지 않는다.

일시정지는 진행을 동결한다. 사망·방 이탈·전투 종료는 남은 효과를 취소하며 이미 사용한 기회는 그 판에서 유지한다. 재도전에서는 초기화한다. 결과의 대상 수는 실제 제어를 받은 적을 뜻하며 이동량이나 추가 처치를 주장하지 않는다. 새 저장 필드는 만들지 않는다.

## 출시 검증

새 후보의 전체 검사, 정확한 clean 빌드의 전체 첫 층 RSI, 기준선 비교, 두 장치의 실제 입력·후속 전투·정산·재도전, 중단·대상 제외·충돌·프레임 간격 검사, 발견 지도와 정지 소유권, 실제 가로·세로 화면 및 다섯 영웅의 시각 검토를 함께 요구한다. 전체 드로우콜 420 이하 등 기존 PRD 밴드를 완화하지 않는다.

초기 같은 호스트 진단 기준선은 평균 JS 스텝 0.96ms로 낮았다. 따라서 정식 상대 성능 검증은 후보 SHA 확정 후 두 빌드 전에 선언한 다섯 개 연속 기준선→후보 쌍을 사용한다. 판정 방식은 실제 기준선 중앙값에 따라 기존 RSI 규칙이 결정한다. 진단 한 번을 중앙값으로 간주하지 않는다. 모든 실패와 원본 표본은 보존한다.

이 회전은 브라우저 게임의 전장 표현과 하나의 환경 전투 선택을 개선한다. 모든 지역의 기믹 완성, 물리 휴대전화의 성능, AAA 완료, 장기 잔존율을 입증하는 범위는 아니다. 머지·보호된 배포 뒤 공개 SHA와 변경된 실제 흐름을 확인하고 회전을 기록한다.
