# 확률형 아이템 정보공개 점검 — 2026-10-30

근거: 게임산업법 제33조 제2항·시행령 제19조의2·별표 3의2(2024-03-22 시행), 제33조의2 확률 조작·거짓 표시 3배 배상(2025-08-01 시행). 출처: [별표 3의2](https://www.law.go.kr/LSW/flDownload.do?flSeq=136417275&bylClsCd=110201), [korea.kr](https://www.korea.kr/news/policyNewsView.do?newsId=148924297), [로앤린](https://www.law-lin.com/ko/newsletter/1624), [ZDNet 2025-08-01](https://zdnet.co.kr/view/?no=20250801144527).

**적용 판단:** 소규모 제외(제작·배급·제공자 **모두** 직전 3년 연평균 매출 1억 원 이하 중소기업)가 있으나 Google Play가 제공자로 끼면 요건이 깨질 수 있고 매출이 늘면 바로 의무가 된다. → **제외를 주장하지 않고 전부 공개**(비용 거의 없음).
