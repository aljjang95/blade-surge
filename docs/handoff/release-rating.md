1. 게임위 1377에 "웹 브라우저 게임 등급분류 담당 기관" 확인(전화 한 통).
2. 게임위 업체 회원 로그인 → GRAC_APPLICATION.md 내용 입력, 사업자등록증·게임제작/배급업 등록증 첨부, 영상 첨부 → 수수료(추정 108만 원 감면 시, 모의 계산기로 확정) 납부 → 제출.

4. 결정서가 나오면 등급분류번호를 알려 주시면 표시 반영·배포.
