# 전투 알림 QA — 2026-09-13

보스 봉인 해제에서는 경고와 포탈 안내가 같은 tick에 발생한다. 기존 UI는 알림을 쌓고 세로 화면에서 일반 안내를 숨겨, 포탈 안내가 표시되기 전에 만료될 수 있었다.

전투 중 한 개의 알림을 표시하고 위험 알림을 우선한다. 중단된 일반 안내에는 다시 표시할 때 2.2초 수명을 부여한다. 중복 제거, 대기 상한 4개, 전투 전환 시 큐와 타이머 정리를 적용했다.

실제 IAB 검증에서 후보의 기본 setTimeout/clearTimeout을 큐 메서드로 호출할 때 Illegal invocation이 발생해 포탈 생성까지 중단되는 오류를 발견했다. 기본 타이머를 전역 호출 래퍼로 수정했다. 브라우저 receiver 회귀는 수정 전 실패, 수정 후 통과했다.

740×360 화면에서 경고와 중앙 배너가 약 6px 겹치는 것도 확인했다. ResizeObserver로 실제 알림 하단을 측정하고 배너와 최소 14px 간격을 둔다. 수정 후 측정 간격은 가로 약 15.94px, 390×844 세로 약 57.13px였다. 각인 대기 버튼은 각인 +N으로 축약하고 전체 의미는 aria-label로 보존하며, 넘치는 HUD 문구는 셀 안에서 처리한다.

검증:
- 전체 421개 테스트 / 18,533 assertions, 타입 검사와 웹 빌드 통과. 관련 알림 회귀 7개 / 34 assertions 통과.
- 독립 코드 리뷰 두 차례에서 새 P1/P2 없음.
- IAB에서 법사 저장 유지, 실제 화염구 사용과 쿨다운, 일시정지·재개 확인.
- 실제 봉인 해제 호출 후 포탈 생성 확인. 경고는 2202ms에 포탈 안내로 전환되고 4402ms에 비워졌다. 동시에 보인 알림은 최대 1개였다.
- 가로/세로 알림 배치는 시뮬레이션 정지 및 CSS animation 500ms 고정 캡처로 확인했다. 표시 수명은 별도의 실제 타이머 기록이다.
- 최종 메뉴 축약 빌드의 화면 확인 및 던전 완주 결과는 아직 대기 중이다. 새 로컬 주소 53179의 빈 저장소를 먼저 확인한 뒤 초기 기사·시드 20260905로 진행했으며, 마지막 확인 지점은 120초 / 12구역 / 195킬 / 드랍31개다. 성장 선택 7개는 기준선과 일치한다. 최종 IAB 요청들이 자동 승인 검토 시간 초과로 돌아와 이 표본의 완주·전체 밴드 통과를 주장하지 않는다.

현재 PR23은 초안이며 병합·배포 전 최종 IAB 결과를 확인한다. 현재 운영은 PR22의 0b0d8c86이다. Android 빌드·기기·스토어 검증은 이 웹 패치의 선행조건이 아니다.
