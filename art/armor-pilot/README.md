# 검성 장비 생산 시험 · 2026-09-20

기존 서리결정 R2 원본을 공통 기반으로 삼은 5종 제작 후보입니다.
얼굴·머리·원래 리그·아이템 능력치·가격·획득 확률은 변경하지 않습니다.

## 생성된 외형
| 기존 아이템 | 부품 구성 |
|---|---|
| a_leather / 가죽 갑옷 | 작은 흉갑, 어깨 판금·결정·각인 제외 |
| a_bronze / 청동 흉갑 | 어깨 1단, 청동 테두리·복부 판금 |
| a_knight / 기사의 판금 | 어깨 2단, 은색 테두리·각인, 결정 제외 |
| a_rime / 결정 갑주 | 어깨 3단, 가슴·어깨 결정, 원본 UV 이미지 재질 |
| a_king / 왕의 갑주 | 어깨 3단, 가넷·금속, 추가 입체 문장 6개 |

각 외형의 GLB는 `public/models/armor-pilot/v1`에, 편집 원본은 이 폴더의 `v1`에 있습니다.
`recipes.json`이 부품 포함 조건과 재질을 정의합니다. 무작위 생성이 아닙니다.
`source-r2.blend`는 이전 작업의 고정 복사본이며 이전 원본은 수정하지 않았습니다.

## 재현
Blender 5.2.1에서 아래 스크립트를 실행합니다. 같은 결과 폴더는 덮어쓰지 않습니다.
```text
blender --background --disable-autoexec --python-exit-code 1 --python tools/art/build-armor-pilot.py -- --out <repo>/public/models/armor-pilot/<새-revision>
bun test test/armor-pilot.test.ts
bun run check
```
한 번에 최대 5개, 등록된 아이템 ID·색상 범위·본 이름·형상 예산 안에서만 생성합니다.
새 장비에 대한 새 미술 설계는 별도의 작업입니다. 실행시간을 신규 설계 시간으로 바꾸어 말하지 않습니다.

## 확인한 범위
- 5종의 GLB 규격 오류 0. 결정 갑주는 암묵적 탄젠트 생성 경고 16개가 남습니다.
- 같은 레시피 재실행에서 5개 GLB의 SHA-256이 모두 동일했습니다.
- 첫 일괄 생성 1.702초, 재실행 1.069초는 Blender 내부의 생성·파일 저장 시간입니다.
- 레시피 작성·기본형 제작·검증·이전 작업의 미술 설계 시간은 이 숫자에서 제외됩니다.
- 각 외형을 기존 검성 리그에 시험 연결해 필수 클립 17개 × 12위상 = 204포즈의 모든 의상 정점을 검사했습니다.
- 전체 1,020포즈에서 비유한 좌표·비정상 범위가 없고, 얼굴 객체와 40개 원래 클립이 유지됐습니다.
- 이 수치 검사는 기존 `assembleHeroIdentity`를 사용하므로 원본 PBR 재질 표현·관통 없는 자연스러움을 보증하지 않습니다.

## 현재 차단·미검증
게임 연결 파일 `src/engine/equipment-appearance.js`의 작성이 같은 도구 보안 판정 오류로 2회 차단됐습니다.
별도 동등조건 렌더 스크립트 작성도 같은 오류로 2회 차단됐습니다. 두 파일 모두 포함되지 않습니다.
등록 데이터 `src/data/armor-visuals.js`만 있으며, 현재 게임 부트·장착 함수는 이 데이터를 읽지 않습니다.
기존 의상 로더가 UV·재질을 재구성하는 문제는 해결 완료가 아닙니다.
따라서 실제 득템→장착, 새 PBR 재질의 게임 렌더, 교차 동작·관통, 모바일 실기기 검증은 미완료입니다.
새 5종의 미술 품질·등급 식별성은 이번 수치 검사로 승인하지 않습니다.
운영 배포·main 병합·독립 리뷰·서명 Proof는 하지 않았습니다.

## 남은 작업
1. 허용된 실행 표면에서 기존 장착 경로에 재질 보존 의상 교체를 구현합니다.
2. 같은 실제 게임 카메라에서 5종 장착, 이동·공격·회피·전환을 재생하고 관통과 작은 화면 가독성을 검토합니다.
3. 공유 형상·재질·본 텍스처의 교체/해제 수명주기와 부하를 측정합니다.
4. 독립 검토와 exact-tree 검증 뒤 채택합니다. 동률·회귀는 기존 외형을 유지합니다.

## 2026-09-20 실제 장착 경로 연결 후속

`src/engine/equipment-appearance.js`를 추가하고 기존 `preloadAll`, `applyLook`,

다운로드는 8초로 제한한다. 실패 시 기존 모습을 유지하고 로비에 안내한다.
검성의 expedition-v3 의상만 교체하며 얼굴, 기존 뼈대와 애니메이션은 유지한다.
원래 UV·재질·텍스처를 보존하고 같은 재질의 메시를 묶는다.
장비 교체·해제·캐릭터 정리 시 인스턴스 재질만 해제하고 공유 형상과 리그는 보존한다.
아이템 수치·드랍 확률·가격·플레이어 저장 형식·결제 연결은 변경하지 않았다.
