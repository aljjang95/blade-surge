# 던전 우선 로비 (2026-10-15)

사용자 지시: 로비 입구를 대폭 줄이고, 2015 넥슨/콘컴 **용사X용사** 실스크린샷의 화면 문법을 모티브로 던전 선택 → 준비 → 정산 → 장비 → 재출격 동선을 만든다. 이 문서는 `docs/selection-first-lobby.md`의 선택형 출격 계약을 이어받아 기본 화면을 더 단순하게 바꾼 내용이다. 준비창 · 입장 · 저장 · 환급 · 정산 서비스는 그대로이며 저장 형식은 바꾸지 않았다.

## 사용자 작업과 최상위 목적지

사용자 작업은 영웅 확인 → 던전 · 단계 → 출격 준비와 비용 → 전투 → 정산 → 장비 확인 → 재도전이다. 로비 하단에는 목적지 3개만 둔다.

| 목적지 | 내용 |
|---|---|
| 던전 (기본 도착 화면) | 장면 중앙의 실제 3D 영웅, 추천/최근 던전 한 장, 입장 에너지와 보유량, 주요 보상, 단일 강조 버튼 '출격 준비' |
| 영웅·장비 | 기존 영웅 탭(착용 칸 · 가방 · 성장 · 스킬 · 세트). 머리글의 '출격 준비'는 같은 추천 던전의 준비창으로 돌아간다 |
| 메뉴 | 모험(캠페인, 야외 필드) · 성장 · 정비(성장 · 각인, 전투 설계, 도감, 성장 여정, 제작 공방, 보급 상점) · 보상 · 임무 · 상점 · 소환 · 시스템(동행, 안내, 설정, 앱 설치) |

'다른 던전'과 '마을 둘러보기'는 착지 패널 안의 보조 링크다. 마을 이동은 계속 선택 사항이다.

## 추천 정책 (`src/ui/dungeon-landing.js`)

읽기 전용이다. 저장된 `eco.s.masterworks.history`의 마지막 던전 경로를 `normalizeRunRoute`로 검증해 읽는다.

1. 최근 실제 원정 경로(던전 · 기본/심층)가 지금 입장 가능하면 그것을 '최근 원정 · 승리/패배'로 보여 준다.
2. 아니면 던전 여정(`dungeonJourney`)의 다음 던전을 '추천 던전'으로 보여 주고, 최근 경로가 잠겼다면 이유를 한 줄 남긴다.
3. 열린 던전이 없어도 첫 미정복 던전과 잠금 사유를 보여 준다.

에너지가 부족하거나 잠겨 있어도 준비창은 열린다. 최종 '원정 시작 · 에너지 N'만 기존 `citadelPreparation` 판정과 `startExpedition`이 처리하며 그 버튼에서만 에너지를 1회 쓴다. 준비창 열기 · 취소 · ESC는 비용이 없고 초점은 '출격 준비'로 돌아온다. `CitadelHubUI.openDestination`은 최근 원정이 심층이면 같은 단계로 연다.

## 줄인 입구와 보존

| 이전 기본 화면 | 지금 |
|---|---|
| 하단 독 5개(출격 · 영웅 · 모험 · 성장 · 메뉴) | 3개(던전 · 영웅·장비 · 메뉴). 모험 탭은 메뉴의 '캠페인', 성장은 메뉴의 '성장 · 각인' |

마을 둘러보기 중 물리 결투장 안내인과 포털은 기존 그대로다(선택형 탐험 공간).

## 화면 배치

- 가로 데스크톱: 영웅은 장면 중앙, 오른쪽에 폭 320~400px 패널. 상단은 프로필 · 에너지 · 골드 · 보석.
- 짧은 가로(휴대폰 가로): 왼쪽 세로 독, 오른쪽 패널. 설명만 접고 버튼과 비용은 항상 보인다. 패널 본문만 내부 스크롤.
- 세로: 영웅 위, 패널은 하단 독 위. 가로 스크롤 없음. 기존 회전 안내와 '세로로 계속하기'는 유지.
- 결과 화면은 하단 독을 가린다. 결과의 '로비' → 던전 착지(최근 원정으로 표시) → 영웅·장비 → '출격 준비'가 현재 실제 경로다. 결과 화면 버튼 자체의 '장비 정비' 연결은 `src/expansion/hub.jsx` 소유 범위라 root 요청으로 남겼다.

## 용사X용사 참고 범위

연구 폴더 `/workspace/scratch/blade-playability-20261015/ux-research/`의 R1 · R2(실제 전투), R4 · R6(홍보 합성 안의 UI), R7(실제 로비 가이드)을 직접 열어 확인했다. 가져온 원리는 (1) 월드 위 영웅을 가운데 두고 상태 · 행동을 가장자리에 모으는 배치, (2) 하단 오른쪽 끝에 던전 행동을 두는 위계, (3) 장비 칸과 착용 캐릭터를 한 화면에서 연결하는 장비 화면이다. 원작 로비도 메뉴가 23곳이라 메뉴 수는 따르지 않았다. 원작 그래픽 · 아이콘 · 로고 · 문구는 복사하지 않았고 HIT/던파 모바일 화면은 근거로 쓰지 않았다.

## 타이포그래피

UI 서체는 자체 호스트 **Blade Sans KR** 한 벌(400 / 700)이고 제목은 같은 서체의 Bold다(`--font-title`). 둥근 장식 서체와 Google Fonts 의존은 제거했다. 파일을 못 받으면 `font-display: swap`으로 OS 한국어 서체(Apple SD Gothic Neo · 맑은 고딕 · Noto Sans KR/CJK)가 같은 정보를 그린다. 토큰은 `src/platform/typography.css`에 있다.

| 토큰 | 값 | 용도 |
|---|---|---|
| --type-xs | 12px / 1.45 | 부차 메타만 |
| --type-sm | 14px / 1.45 | 보조 설명 · 탭 · 비용 표기 최소 |
| --type-body | 16px / 1.5 · 500 | 본문 · 주요 상태 |
| --type-label | 16px / 1.25 · 700 | 버튼 · 장비명 |
| --type-title | 22px / 1.25 · 800 | 화면 제목 · 주요 버튼 |
| --type-hero | clamp(24px, 3vw, 32px) / 1.15 · 800 | 던전 이름 |

숫자는 `font-variant-numeric: tabular-nums`, 줄바꿈은 `word-break: keep-all; overflow-wrap: anywhere`.

출처와 라이선스: Debian 패키지 `fonts-noto-cjk 1:20240730+repack1-1`의 `NotoSansCJK-Regular.ttc`(sha256 `b76b0433203017ca80401b2ee0dd69350349871c4b19d504c34dbdd80541690a`) · `NotoSansCJK-Bold.ttc`(sha256 `faa5f3656a78b2e2d450d27fe8382c778bc2b6bb5ea29c986664a6a435056ceb`)의 KR 면(index 1), Noto Sans CJK KR 2.004, SIL OFL 1.1. 'Noto'는 Google 상표라 서브셋의 패밀리 이름을 Blade Sans KR로 바꾸고 원본 저작권 · 라이선스 이름 레코드는 유지했다. 라이선스 전문: `public/fonts/OFL-blade-sans-kr.txt`.

글리프 범위: KS X 1001 한글 2,350자 + ASCII · Latin-1 · 호환 자모 + 저장소 문자열이 쓰는 기호(총 2,635 코드포인트, 2,674 글리프). 2026-10-15 소스의 게임 문자열 한글 939자는 모두 KS X 1001 안에 있다. 범위 밖 글자(예: 사용자가 입력한 드문 음절)는 브라우저가 글자 단위로 OS 서체를 쓴다.

| 파일 | 바이트 | sha256 |
|---|---|---|
| public/fonts/blade-sans-kr-400.woff2 | 156,432 | 03bd4008ba4e6c249351482192508e3244b139a113597a338816e8172bca3855 |
| public/fonts/blade-sans-kr-700.woff2 | 159,636 | f6ce00bfe60c3e9e2bec95b087e40db8e38d89ebf8ce37bbbbe51f5cc7c63e1e |

재현: 저장소 의존성과 별개인 venv에 `fonttools==4.61.1`과 `brotli`를 설치하고, 저장소 `index.html`과 `src/**/*.{js,jsx,ts,tsx,css,json,mjs}`의 문자 + 위 범위로 코드포인트 목록을 만든 뒤 `pyftsubset <ttc> --font-number=1 --unicodes-file=<목록> --layout-features=kern,liga,calt,ccmp,locl,mark,mkmk,tnum,pnum,palt --flavor=woff2 --name-IDs='*' --name-languages='*' --no-hinting --desubroutinize`를 실행하고 이름 레코드 1/3/4/6/10과 CFF 이름을 Blade Sans KR로 바꾼다. 이번 실행 스크립트는 `/workspace/scratch/blade-playability-20261015/ux-work/{font-unicodes.py,build-blade-sans.py}`에 있다.

## 검증 도구

`node tools/lobby-dungeon-first-qa.mjs <origin> <out> --profiles=desktop-1440,land-844x390,port-390x844 [--items] [--flow]`는 새 브라우저 프로필에서 실제 클릭/탭/키 입력으로 착지 화면 · 준비 열기/취소/ESC · 메뉴 · 영웅·장비 재진입 · (--flow) 실제 출격 1회 차감 → 포기 → 결과 → 로비 → 영웅·장비 → 같은 준비창 · (--items) 같은 장비 그림 일치와 3D 미리보기를 검사한다. viewport 에뮬과 SwiftShader 결과이며 실기기 · GPU 프레임 · 발열 증거가 아니다.
